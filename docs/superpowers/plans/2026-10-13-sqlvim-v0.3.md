# sqlvim v0.3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 sqlvim v0.3「远程与安全」：SSH 隧道（ssh-agent / 密钥文件 / 带口令的密钥 / ProxyJump 多跳 / known_hosts 校验与首次信任）；`env = "prod"` 的红色边框与状态栏、写操作确认框、`:set noreadonly` / `:set readonly` 会话级解锁；控制台事务模式（`<Space>t` 手动提交、状态栏 `TX n`、`:commit` / `:rollback`、带未提交事务退出时询问）。

**Architecture:** 新增 `internal/db/tunnel`：解析 `~/.ssh/config` 得到跳板链，用 `golang.org/x/crypto/ssh` 逐跳建立客户端，按 ssh_config 别名缓存并在断开后自动重连，向驱动提供 `db.DialFunc`（不监听本地端口）。`db.ConnConfig` 增加 `Dial`，PG 设置 pgconn 的 `DialFunc`/`LookupFunc`，MySQL 设置 `Config.DialFunc`。`session.Manager` 在打开带 `ssh` 的连接前先拿到隧道，并提供会话级只读覆盖。`sqlx` 增加事务语句分类，`runner.Guard` 改为接受 `Policy{ReadOnly, Prod}` 并对 prod 写操作要求确认。控制台 tab 维护事务状态机（手动模式下自动插入 BEGIN，按执行结果跟踪 BEGIN/COMMIT/ROLLBACK、MySQL DDL 隐式提交、PG 失败事务、断线丢失事务）。根 Model 负责 `:set`、`:commit`、`:rollback`、退出确认、SSH 口令与主机指纹弹框、prod 配色。

**Tech Stack:** v0.2 全部依赖，另加 github.com/kevinburke/ssh_config v1.6.0 · golang.org/x/crypto v0.54.0（`ssh`、`ssh/agent`、`ssh/knownhosts`；已在 go.sum 中，由间接依赖变为直接依赖）

**Spec:** `docs/superpowers/specs/2026-10-13-sqlvim-design.md`（§1.1、§2、§4.2、§5.1、§5.2、§5.3、§5.4 事务模式、§8 连接断开、§10 v0.3 行）；前两版计划 `docs/superpowers/plans/2026-10-13-sqlvim-v0.1.md`、`docs/superpowers/plans/2026-10-13-sqlvim-v0.2.md`（其中的约定继续有效）。

## Global Constraints

- v0.1、v0.2 计划的 Global Constraints 全部继续有效（模块路径 `github.com/shepherd-yun/sqlvim`、XDG 目录、密码不落盘、日志不含密码、英文 UI 文案、UI 层不做 IO、Conventional Commits + attribution、集成测试 build tag `integration`、`Ctrl-c` 不退出）。
- 新增依赖只允许：`github.com/kevinburke/ssh_config v1.6.0`；`golang.org/x/crypto v0.54.0` 改为直接依赖（不升级版本）。
- SSH 隧道以 `db.DialFunc` 注入驱动，**不监听本地端口**，不启动外部 `ssh` 进程。
- ssh_config 路径固定为 `~/.ssh/config`（OpenSSH 的位置，不走 XDG）；文件不存在视为空配置。支持的键：`HostName`（含 `%h`）、`Port`、`User`、`IdentityFile`（可多个）、`ProxyJump`（逗号分隔多跳、`none`）、`UserKnownHostsFile`。`ProxyCommand` 不支持：报错并建议改用 `ProxyJump`。
- 认证顺序：ssh-agent（`$SSH_AUTH_SOCK`）的全部密钥 → `IdentityFile` 列出的密钥（没写时依次为 `~/.ssh/id_ed25519`、`~/.ssh/id_ecdsa`、`~/.ssh/id_rsa`）。只有在没有其他密钥能登录时，才为带口令的密钥弹框要口令。不支持密码 / keyboard-interactive 认证。
- 密钥口令只保存在内存中，本次运行有效；不写 Keychain、不写日志、不出现在错误信息里。
- known_hosts：默认 `~/.ssh/known_hosts`（或 `UserKnownHostsFile` 指定的文件，写入第一个）。未知主机弹框显示 SHA256 指纹，**必须输入 `yes`** 才写入（文件权限 `0600`，目录 `0700`）；主机密钥与记录不符时报错，**永不提供覆盖**。
- 每一跳 SSH 连接（TCP + 握手）超时 15 秒；隧道空闲时每 30 秒发送一次 `keepalive@openssh.com`，失败即关闭隧道，下次使用时自动重连。
- `:set noreadonly` / `:set readonly`（别名 `noro` / `ro`）作用于当前上下文的连接，只对本次运行有效，**不改 connections.toml**；切换时关闭该连接的连接池，控制台在下次执行前重开会话，使数据库端只读兜底与之一致。该连接上有未提交事务时拒绝切换。
- `env = "prod"`：当前 tab 属于 prod 连接时 tab 区边框为红色；状态栏模式块为红底并显示 `[PROD]`；连接只读时状态栏显示 `RO`。prod 上的写语句（DML）和 DDL 弹确认框，按 `y` 继续；缺失 WHERE 仍须输入表名（标题带 `PROD`）。
- 事务模式按控制台 tab 生效：`<Space>t` 切换手动提交；手动模式下第一条语句前自动执行 PG `BEGIN` / MySQL `START TRANSACTION`（不记入 SQL 历史）；`:commit` / `:rollback` 结束事务；状态栏显示 `TX`（手动模式、无事务）或 `TX n`（事务中，n 为未提交的写语句数）或 `TX failed · :rollback`（PG 事务已失败）。事务未结束时 `:q` / `:qa` 弹框询问，`:q!` / `:qa!` 不问；事务中检测到断线时**不自动重连**，报告事务已丢失。

### v0.3 明确不做

`<Space>o` 切换连接 / 数据库（后续版本）；SSH 密码与 keyboard-interactive 认证、`ProxyCommand`、`ControlMaster`、用户证书；错误定位跳转到编辑器行列（v0.4 与补全一起做）；数据编辑的提交流程（v0.6）；用户在控制台里手动执行 `SET autocommit = 0` 时的状态跟踪（文档说明请改用 `<Space>t`）。

## Review Focus

1. **经 SSH 隧道连 PostgreSQL 时按 `Ctrl-c` 取消长查询** → 1–2 秒内取消、会话（临时表）保留。pgx 把 cancel request 发往 `conn.RemoteAddr()`，而 SSH 通道连接的 RemoteAddr 是 `0.0.0.0:0`；隧道返回的连接必须报告拨号时的地址（Task 4 单元测试 `TestTunnelConnReportsDialedAddress`，Task 13 集成测试）。
2. **known_hosts 已有该主机的另一种密钥类型**（记录了 ed25519，服务器优先给 ecdsa）、**非 22 端口的 `[host]:port` 写法**、**`HashKnownHosts yes` 的哈希条目** → 都不应误报「主机密钥已变更」；信任新主机时写入的格式 OpenSSH 能识别（Task 3 测试）。
3. **隧道在空闲时断开**（笔记本休眠、跳板机重启） → 下一次操作透明重连隧道；如果此时控制台处在手动事务中，报告事务已丢失，而不是悄悄在自动提交模式下继续执行（Task 4 `TestTunnelReconnectsAfterDrop`，Task 10 `TestConsoleTransactionLostOnDisconnect`）。
4. **事务状态被语句隐式或手动改变**：手打 `COMMIT` / `ROLLBACK`、`ROLLBACK TO SAVEPOINT`、`COMMIT AND CHAIN`、PG `PREPARE TRANSACTION`、MySQL DDL 隐式提交、PG 语句失败后事务进入 aborted 状态 → 状态栏的 `TX` 始终如实（Task 7 `TestTransactionEffect`，Task 10 测试）。
5. **在控制台会话已打开（数据库端只读）时 `:set noreadonly`** → 下一次执行自动以读写方式重开会话；`:set readonly` 重新上锁；该连接有未提交事务时拒绝切换（Task 9 `TestConsoleReopensSessionWhenReadOnlyChanges`，Task 11 `TestSetReadOnlyBlockedByOpenTransaction`）。

```go
// DialFunc opens the network connection to a server. SSH tunnels provide
// one; nil dials directly.
type DialFunc func(ctx context.Context, network, addr string) (net.Conn, error)

// ConnConfig is what a driver needs to open a connection.
type ConnConfig struct {
	Host     string
	Port     int
	User     string
	Password string
	Database string
	Params   map[string]string
	// ReadOnly makes the server reject writes for every connection opened.
	ReadOnly bool
	// Dial, if set, opens every network connection (including PostgreSQL
	// cancel requests and MySQL KILL QUERY connections).
	Dial DialFunc
}
```

```go
func TestResolve(t *testing.T) {
	cfg := decode(t, testSSHConfig)
	kh := []string{"/home/me/.ssh/known_hosts"}
	bastion := Hop{
		Alias: "bastion", Host: "bastion.example.com", Port: 2222, User: "ops",

		}
	}
}
```

```go
// Package tunnel opens SSH tunnels described by ~/.ssh/config and gives the
// database drivers a dial function that connects through them.
package tunnel

import (
	"errors"
	"fmt"
	"io/fs"
	"net"
	"os"
	"path/filepath"
	"strconv"
	"strings"

	"github.com/kevinburke/ssh_config"
)

// Hop is one SSH server on the way to the database.
type Hop struct {
	Alias      string // the name looked up in ssh_config
	Host       string // HostName, or the alias itself
	Port       int
	User       string
	Identities []string // IdentityFile values, expanded; empty means the defaults
	KnownHosts []string // UserKnownHostsFile values, expanded
}

// Addr is host:port, as dialed and as recorded in known_hosts.
func (h Hop) Addr() string { return net.JoinHostPort(h.Host, strconv.Itoa(h.Port)) }

// Env is what ssh_config tokens expand to.
type Env struct {
	Home string // ~ and %d
	User string // %u, and the default User
}

// maxHops bounds ProxyJump chains (and catches loops).
const maxHops = 8

// LoadConfig parses an ssh_config file; a missing file is an empty config.
func LoadConfig(path string) (*ssh_config.Config, error) {
	data, err := os.ReadFile(path)
	if errors.Is(err, fs.ErrNotExist) {
		return &ssh_config.Config{}, nil
	}
	if err != nil {
		return nil, err
	}
	cfg, err := ssh_config.DecodeBytes(data)
	if err != nil {
		return nil, fmt.Errorf("%s: %w", path, err)
	}
	return cfg, nil
}

// Resolve returns the hops that reach alias: ProxyJump hosts first, alias last.
func Resolve(cfg *ssh_config.Config, alias string, env Env) ([]Hop, error) {
	hops, err := resolve(cfg, alias, env, 0)
	if err != nil {
		return nil, err
	}
	if len(hops) > maxHops {
		return nil, fmt.Errorf("ssh host %q: more than %d ProxyJump hops", alias, maxHops)
	}
	return hops, nil
}

func resolve(cfg *ssh_config.Config, alias string, env Env, depth int) ([]Hop, error) {
	if depth > maxHops {
		return nil, fmt.Errorf("ssh host %q: ProxyJump loop or more than %d hops", alias, maxHops)
	}
	h, jumps, err := lookup(cfg, alias, env)
	if err != nil {
		return nil, err
	}
	if len(jumps) == 0 {
		return []Hop{h}, nil
	}
	// Like ssh -J a,b: a is reached with its own ProxyJump, b through a.
	chain, err := resolve(cfg, jumps[0].host, env, depth+1)
	if err != nil {
		return nil, err
	}
	jumps[0].apply(&chain[len(chain)-1])
	for _, j := range jumps[1:] {
		next, _, err := lookup(cfg, j.host, env)
		if err != nil {
			return nil, err
		}
		j.apply(&next)
		chain = append(chain, next)
	}
	return append(chain, h), nil
}

func lookup(cfg *ssh_config.Config, alias string, env Env) (Hop, []jump, error) {
	get := func(key string) string {
		v, _ := cfg.Get(alias, key)
		return strings.TrimSpace(v)
	}
	if pc := get("ProxyCommand"); pc != "" && !strings.EqualFold(pc, "none") {
		return Hop{}, nil, fmt.Errorf("ssh host %q uses ProxyCommand, which sqlvim does not support; use ProxyJump instead", alias)
	}
	h := Hop{Alias: alias, Host: alias, Port: 22, User: env.User}
	if v := get("HostName"); v != "" {
		h.Host = strings.ReplaceAll(v, "%h", alias)
	}
	if v := get("Port"); v != "" {
		p, err := strconv.Atoi(v)
		if err != nil || p < 1 || p > 65535 {
			return Hop{}, nil, fmt.Errorf("ssh host %q: bad Port %q", alias, v)
		}
		h.Port = p
	}
	if v := get("User"); v != "" {
		h.User = v
	}
	ids, _ := cfg.GetAll(alias, "IdentityFile")
	for _, id := range ids {
		h.Identities = append(h.Identities, expand(strings.TrimSpace(id), env, h))
	}
	known := get("UserKnownHostsFile")
	if known == "" {
		known = "~/.ssh/known_hosts"
	}
	for _, f := range strings.Fields(known) {
		h.KnownHosts = append(h.KnownHosts, expand(f, env, h))
	}
	jumps, err := parseJumps(get("ProxyJump"))
	if err != nil {
		return Hop{}, nil, fmt.Errorf("ssh host %q: %w", alias, err)
	}
	return h, jumps, nil
}

// jump is one entry of ProxyJump: [user@]host[:port].
type jump struct {
	user, host string
	port       int
}

func (j jump) apply(h *Hop) {
	if j.user != "" {
		h.User = j.user
	}
	if j.port != 0 {
		h.Port = j.port
	}
}

func parseJumps(v string) ([]jump, error) {
	if v == "" || strings.EqualFold(v, "none") {
		return nil, nil
	}
	var out []jump
	for _, part := range strings.Split(v, ",") {
		part = strings.TrimPrefix(strings.TrimSpace(part), "ssh://")
		var j jump
		if at := strings.LastIndex(part, "@"); at >= 0 {
			j.user, part = part[:at], part[at+1:]
		}
		j.host = part
		if host, port, err := net.SplitHostPort(part); err == nil {
			p, err := strconv.Atoi(port)
			if err != nil || p < 1 || p > 65535 {
				return nil, fmt.Errorf("bad ProxyJump port in %q", part)
			}
			j.host, j.port = host, p
		}
		if j.host == "" {
			return nil, fmt.Errorf("bad ProxyJump %q", v)
		}
		out = append(out, j)
	}
	return out, nil
}

// expand handles ~ and the %d %u %h %r %% tokens.
func expand(s string, env Env, h Hop) string {
	if s == "~" {
		return env.Home
	}
	if rest, ok := strings.CutPrefix(s, "~/"); ok {
		s = filepath.Join(env.Home, rest)
	}
	return strings.NewReplacer("%%", "%", "%d", env.Home, "%u", env.User, "%h", h.Host, "%r", h.User).Replace(s)
}
```

```go
package tunnel

import (
	"crypto/ed25519"
	"crypto/rand"
	"errors"
	"fmt"
	"net"
	"os"
	"path/filepath"

	"golang.org/x/crypto/ssh"
	"golang.org/x/crypto/ssh/knownhosts"
)

// UnknownHostError means the server's key is not in known_hosts yet. The UI
// shows the fingerprint and calls Trust once the user accepts it.
type UnknownHostError struct {
	Host string // known_hosts form: host, or [host]:port
	Key  ssh.PublicKey
	File string // the known_hosts file Trust appends to
}

func (e *UnknownHostError) Error() string {
	return fmt.Sprintf("ssh: the authenticity of host %s can't be established (%s key fingerprint %s)",
		e.Host, e.Key.Type(), e.Fingerprint())
}

// Fingerprint is the key's SHA256 fingerprint as OpenSSH prints it.
func (e *UnknownHostError) Fingerprint() string { return ssh.FingerprintSHA256(e.Key) }

// HostKeyChangedError means known_hosts holds a different key for the host,
// which may be a man-in-the-middle attack. sqlvim never offers to overwrite it.
type HostKeyChangedError struct {
	Host  string
	Key   ssh.PublicKey
	Known []knownhosts.KnownKey
}

func (e *HostKeyChangedError) Error() string {
	k := e.Known[0]
	return fmt.Sprintf("ssh: REMOTE HOST IDENTIFICATION HAS CHANGED for %s: the server sent %s key %s but %s:%d records another key; if the change is expected, remove that line",
		e.Host, e.Key.Type(), ssh.FingerprintSHA256(e.Key), k.Filename, k.Line)
}

// hostKeys checks server keys against a hop's known_hosts files.
type hostKeys struct {
	files []string // configured files, in order; the first receives new hosts
}

func newHostKeys(files []string) hostKeys { return hostKeys{files: files} }

// check returns the host key callback for addr and the key algorithms to ask
// for. Asking only for the types already recorded keeps a host that has, say,
// an ed25519 entry from being reported as changed because it offered ecdsa.
// The files are read on every call so hosts trusted a moment ago are known.
func (k hostKeys) check(addr string) (ssh.HostKeyCallback, []string, error) {
	var existing []string
	for _, f := range k.files {
		if _, err := os.Stat(f); err == nil {
			existing = append(existing, f)
		}
	}
	known, err := knownhosts.New(existing...)
	if err != nil {
		return nil, nil, err
	}
	write := ""
	if len(k.files) > 0 {
		write = k.files[0]
	}
	host := knownhosts.Normalize(addr)
	cb := func(hostname string, remote net.Addr, key ssh.PublicKey) error {
		err := known(hostname, remote, key)
		var ke *knownhosts.KeyError
		switch {
		case errors.As(err, &ke) && len(ke.Want) == 0:
			return &UnknownHostError{Host: host, Key: key, File: write}
		case errors.As(err, &ke):
			return &HostKeyChangedError{Host: host, Key: key, Known: ke.Want}
		}
		return err
	}
	return cb, knownAlgorithms(known, addr), nil
}

// probeKey never matches a recorded key, so checking it lists them all.
var probeKey = func() ssh.PublicKey {
	pub, _, err := ed25519.GenerateKey(rand.Reader)
	if err != nil {
		panic(err)
	}
	k, err := ssh.NewPublicKey(pub)
	if err != nil {
		panic(err)
	}
	return k
}()

func knownAlgorithms(known ssh.HostKeyCallback, addr string) []string {
	var ke *knownhosts.KeyError
	if err := known(addr, &net.TCPAddr{IP: net.IPv4zero}, probeKey); !errors.As(err, &ke) {
		return nil
	}
	var out []string
	seen := map[string]bool{}
	add := func(algos ...string) {
		for _, a := range algos {
			if !seen[a] {
				seen[a] = true
				out = append(out, a)
			}
		}
	}
	for _, w := range ke.Want {
		if t := w.Key.Type(); t == ssh.KeyAlgoRSA {
			add(ssh.KeyAlgoRSASHA512, ssh.KeyAlgoRSASHA256, ssh.KeyAlgoRSA)
		} else {
			add(t)
		}
	}
	return out
}

// Trust appends the host's key to its known_hosts file, creating the file
// (0600) and its directory (0700) when needed.
func Trust(e *UnknownHostError) error {
	if e.File == "" {
		return errors.New("ssh: no known_hosts file configured")
	}
	if err := os.MkdirAll(filepath.Dir(e.File), 0o700); err != nil {
		return err
	}
	line := knownhosts.Line([]string{e.Host}, e.Key) + "\n"
	if data, err := os.ReadFile(e.File); err == nil && len(data) > 0 && data[len(data)-1] != '\n' {
		line = "\n" + line
	}
	f, err := os.OpenFile(e.File, os.O_CREATE|os.O_APPEND|os.O_WRONLY, 0o600)
	if err != nil {
		return err
	}
	if _, err := f.WriteString(line); err != nil {
		_ = f.Close()
		return err
	}
	return f.Close()
}
```

```go
func startServer(t *testing.T, authorized ...ssh.PublicKey) *testServer {
	t.Helper()
	cfg := &ssh.ServerConfig{
		PublicKeyCallback: func(_ ssh.ConnMetadata, key ssh.PublicKey) (*ssh.Permissions, error) {
			for _, k := range authorized {
				if bytes.Equal(k.Marshal(), key.Marshal()) {
					return &ssh.Permissions{}, nil
				}
			}
			return nil, errors.New("unknown key")
		},

func (s *testServer) serve(cfg *ssh.ServerConfig) {
	for {
		nc, err := s.ln.Accept()
		if err != nil {
			return
		}
		// Counted before the handshake can finish, so a client that has
		// connected is always counted.
		s.mu.Lock()
		s.accepted++
		s.mu.Unlock()
		go s.handle(nc, cfg)
	}
}

func (s *testServer) handle(nc net.Conn, cfg *ssh.ServerConfig) {
	sc, chans, reqs, err := ssh.NewServerConn(nc, cfg)
	if err != nil {
		_ = nc.Close()
		return
	}
	s.mu.Lock()
	s.conns = append(s.conns, sc)
	s.mu.Unlock()
	go ssh.DiscardRequests(reqs) // answers keepalives with "not understood", like OpenSSH
	for nch := range chans {
		if nch.ChannelType() != "direct-tcpip" {
			_ = nch.Reject(ssh.UnknownChannelType, "only direct-tcpip")
			continue
		}
		var req struct {
			Host     string
			Port     uint32
			OrigHost string
			OrigPort uint32
		}
		if err := ssh.Unmarshal(nch.ExtraData(), &req); err != nil {
			_ = nch.Reject(ssh.ConnectionFailed, err.Error())
			continue
		}
		target := net.JoinHostPort(req.Host, strconv.Itoa(int(req.Port)))
		s.mu.Lock()
		s.dials = append(s.dials, target)
		s.mu.Unlock()
		out, err := net.Dial("tcp", target)
		if err != nil {
			_ = nch.Reject(ssh.ConnectionFailed, err.Error())
			continue
		}
		ch, creqs, err := nch.Accept()
		if err != nil {
			_ = out.Close()
			continue
		}
		go ssh.DiscardRequests(creqs)
		go func() { defer func() { _ = ch.Close() }(); _, _ = io.Copy(ch, out) }()
		go func() { defer func() { _ = out.Close() }(); _, _ = io.Copy(out, ch) }()
	}
}

// dropClients disconnects every client, as a restarted server would.
func (s *testServer) dropClients() {
	s.mu.Lock()
	conns := s.conns
	s.conns = nil
	s.mu.Unlock()
	for _, c := range conns {
		_ = c.Close()
	}
}

// startEcho runs a TCP server that echoes everything back.

	t.Helper()
	ln, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		t.Fatal(err)
	}
	t.Cleanup(func() { _ = ln.Close() })
	go func() {
		for {
			c, err := ln.Accept()
			if err != nil {
				return
			}
			go func() { defer func() { _ = c.Close() }(); _, _ = io.Copy(c, c) }()
		}
	}()
	return ln.Addr().String()
}

// startAgent serves an ssh-agent holding keys and returns its socket path.
func startAgent(t *testing.T, keys ...ed25519.PrivateKey) string {
	t.Helper()
	// Unix socket paths are limited to about 104 bytes on macOS, and
	// t.TempDir() paths there are long.
	dir, err := os.MkdirTemp("", "sqlvim-agent")
	if err != nil {
		t.Fatal(err)
	}
	t.Cleanup(func() { _ = os.RemoveAll(dir) })
	kr := agent.NewKeyring()
	for _, k := range keys {
		if err := kr.Add(agent.AddedKey{PrivateKey: k}); err != nil {
			t.Fatal(err)
		}
	}
	sock := filepath.Join(dir, "agent.sock")
	ln, err := net.Listen("unix", sock)
	if err != nil {
		t.Fatal(err)
	}
	t.Cleanup(func() { _ = ln.Close() })
	go func() {
		for {
			c, err := ln.Accept()
			if err != nil {
				return
			}
			go func() { defer func() { _ = c.Close() }(); _ = agent.ServeAgent(kr, c) }()
		}
	}()
	return sock
}
```

```go
	"crypto/x509"

// PassphraseError means a key needs a passphrase sqlvim does not know yet,
// or the one given was wrong. The UI asks for it and calls SetPassphrase.
type PassphraseError struct {
	Path  string
	Wrong bool
}

func (e *PassphraseError) Error() string {
	if e.Wrong {
		return "ssh: wrong passphrase for key " + e.Path
	}
	return "ssh: key " + e.Path + " needs a passphrase"
}

var defaultIdentities = []string{"id_ed25519", "id_ecdsa", "id_rsa"}

// keys are the signers offered to one hop.
type keys struct {
	signers []ssh.Signer
	locked  string   // the first encrypted key skipped for lack of a passphrase
	agent   net.Conn // kept open until the handshake is over
}

func (k *keys) close() {
	if k.agent != nil {
		_ = k.agent.Close()
	}
}

// loadKeys collects the agent's keys, then the identity files. An encrypted
// key without a known passphrase is skipped and remembered in locked, so the
// user is asked for it only when nothing else logs in.
func (p *Pool) loadKeys(h Hop) (*keys, error) {
	k := &keys{}
	if sock := p.opts.AgentSocket; sock != "" {
		c, err := net.Dial("unix", sock)
		if err != nil {
			slog.Debug("ssh-agent unavailable", "err", err)
		} else if s, err := agent.NewClient(c).Signers(); err != nil {
			_ = c.Close()
			slog.Debug("ssh-agent keys unavailable", "err", err)
		} else {
			k.agent, k.signers = c, s
		}
	}
	files := h.Identities
	if len(files) == 0 {
		for _, n := range defaultIdentities {
			files = append(files, filepath.Join(p.opts.Env.Home, ".ssh", n))
		}
	}
	for _, path := range files {
		s, err := p.parseKey(path)
		var pe *PassphraseError
		switch {
		case errors.As(err, &pe) && pe.Wrong:
			k.close()
			return nil, err
		case errors.As(err, &pe):
			if k.locked == "" {
				k.locked = path
			}
		case errors.Is(err, fs.ErrNotExist):
		case err != nil:
			slog.Warn("ssh: skipping unreadable key", "path", path, "err", err)
		default:
			k.signers = append(k.signers, s)
		}
	}
	return k, nil
}

// parseKey reads a private key, decrypting it with a passphrase given
// earlier when it is encrypted.
func (p *Pool) parseKey(path string) (ssh.Signer, error) {
	data, err := os.ReadFile(path)
	if err != nil {
		return nil, err
	}
	s, err := ssh.ParsePrivateKey(data)
	var missing *ssh.PassphraseMissingError
	if !errors.As(err, &missing) {
		return s, err
	}
	pass, ok := p.passphrase(path)
	if !ok {
		return nil, &PassphraseError{Path: path}
	}
	s, err = ssh.ParsePrivateKeyWithPassphrase(data, pass)
	if errors.Is(err, x509.IncorrectPasswordError) {
		p.forgetPassphrase(path)
		return nil, &PassphraseError{Path: path, Wrong: true}
	}
	return s, err
}
```

```go
package tunnel

import (
	"context"
	"errors"
	"fmt"
	"log/slog"
	"net"
	"strings"
	"sync"
	"time"

	"golang.org/x/crypto/ssh"

	"github.com/shepherd-yun/sqlvim/internal/db"
)

// Options configures a Pool.
type Options struct {
	ConfigFile  string        // ssh_config, normally ~/.ssh/config
	Env         Env           // home directory and local user
	AgentSocket string        // $SSH_AUTH_SOCK; empty skips the agent
	DialTimeout time.Duration // per hop, TCP connect and handshake; default 15s
	Keepalive   time.Duration // keepalive interval; default 30s
}

// Pool keeps one SSH connection chain per ssh_config alias, shared by every
// database connection that uses it, and reconnects it after it dies.
// Safe for concurrent use.
type Pool struct {
	opts Options

	mu          sync.Mutex
	chains      map[string]*chain
	locks       map[string]*sync.Mutex
	passphrases map[string][]byte
}

// NewPool builds a Pool; nothing is dialed until Connect.
func NewPool(o Options) *Pool {
	if o.DialTimeout == 0 {
		o.DialTimeout = 15 * time.Second
	}
	if o.Keepalive == 0 {
		o.Keepalive = 30 * time.Second
	}
	return &Pool{
		opts:        o,
		chains:      map[string]*chain{},
		locks:       map[string]*sync.Mutex{},
		passphrases: map[string][]byte{},
	}
}

// Connect makes sure the tunnel for alias is up and returns a dial function
// that opens connections from its last hop. The dial function reconnects
// the tunnel if it has died in the meantime.
func (p *Pool) Connect(ctx context.Context, alias string) (db.DialFunc, error) {
	if _, err := p.live(ctx, alias); err != nil {
		return nil, err
	}
	return func(ctx context.Context, network, addr string) (net.Conn, error) {
		ch, err := p.live(ctx, alias)
		if err != nil {
			return nil, err
		}
		conn, err := ch.last().DialContext(ctx, network, addr)
		if err != nil {
			var refused *ssh.OpenChannelError
			if !errors.As(err, &refused) && ctx.Err() == nil {
				p.drop(alias, ch) // the tunnel itself failed; reconnect next time
			}
			return nil, fmt.Errorf("ssh %s: open %s: %w", alias, addr, err)
		}
		return &tunnelConn{Conn: conn, remote: tunnelAddr{network: network, addr: addr}}, nil
	}, nil
}

// SetPassphrase remembers a key's passphrase for this run only.
func (p *Pool) SetPassphrase(path, passphrase string) {
	p.mu.Lock()
	defer p.mu.Unlock()
	p.passphrases[path] = []byte(passphrase)
}

// TrustHost records an unknown host's key in known_hosts.
func (p *Pool) TrustHost(e *UnknownHostError) error { return Trust(e) }

// Close closes every tunnel.
func (p *Pool) Close() {
	p.mu.Lock()
	chains := p.chains
	p.chains = map[string]*chain{}
	p.mu.Unlock()
	for _, ch := range chains {
		ch.close()
	}
}

func (p *Pool) passphrase(path string) ([]byte, bool) {
	p.mu.Lock()
	defer p.mu.Unlock()
	pass, ok := p.passphrases[path]
	return pass, ok
}

func (p *Pool) forgetPassphrase(path string) {
	p.mu.Lock()
	defer p.mu.Unlock()
	delete(p.passphrases, path)
}

// lock serialises connecting per alias, so concurrent users share one tunnel.
func (p *Pool) lock(alias string) *sync.Mutex {
	p.mu.Lock()
	defer p.mu.Unlock()
	l, ok := p.locks[alias]
	if !ok {
		l = &sync.Mutex{}
		p.locks[alias] = l
	}
	return l
}

// live returns the tunnel for alias, connecting it if there is none or the
// previous one died.
func (p *Pool) live(ctx context.Context, alias string) (*chain, error) {
	l := p.lock(alias)
	l.Lock()
	defer l.Unlock()
	p.mu.Lock()
	ch := p.chains[alias]
	p.mu.Unlock()
	if ch != nil && ch.alive() {
		return ch, nil
	}
	ch, err := p.connect(ctx, alias)
	if err != nil {
		return nil, err
	}
	p.mu.Lock()
	p.chains[alias] = ch
	p.mu.Unlock()
	go p.keepalive(ch)
	return ch, nil
}

func (p *Pool) drop(alias string, ch *chain) {
	p.mu.Lock()
	if p.chains[alias] == ch {
		delete(p.chains, alias)
	}
	p.mu.Unlock()
	ch.close()
}

// connect dials every hop of alias in turn, each through the previous one.
func (p *Pool) connect(ctx context.Context, alias string) (*chain, error) {
	cfg, err := LoadConfig(p.opts.ConfigFile)
	if err != nil {
		return nil, err
	}
	hops, err := Resolve(cfg, alias, p.opts.Env)
	if err != nil {
		return nil, err
	}
	ch := &chain{dead: make(chan struct{})}
	var prev *ssh.Client
	for _, h := range hops {
		c, err := p.dialHop(ctx, prev, h)
		if err != nil {
			ch.close()
			return nil, err
		}
		ch.clients = append(ch.clients, c)
		prev = c
	}
	for _, c := range ch.clients {
		go func() { _ = c.Wait(); ch.kill() }()
	}
	slog.Info("ssh tunnel up", "alias", alias, "hops", len(hops))
	return ch, nil
}

func (p *Pool) dialHop(ctx context.Context, via *ssh.Client, h Hop) (*ssh.Client, error) {
	ctx, cancel := context.WithTimeout(ctx, p.opts.DialTimeout)
	defer cancel()
	addr := h.Addr()
	fail := func(err error) error { return fmt.Errorf("ssh %s (%s@%s): %w", h.Alias, h.User, addr, err) }

	known, algos, err := newHostKeys(h.KnownHosts).check(addr)
	if err != nil {
		return nil, fail(err)
	}
	k, err := p.loadKeys(h)
	if err != nil {
		return nil, err
	}
	defer k.close()

	var hostErr error
	cfg := &ssh.ClientConfig{
		User: h.User,
		Auth: []ssh.AuthMethod{ssh.PublicKeysCallback(func() ([]ssh.Signer, error) { return k.signers, nil })},
		HostKeyCallback: func(hostname string, remote net.Addr, key ssh.PublicKey) error {
			hostErr = known(hostname, remote, key)
			return hostErr
		},
		HostKeyAlgorithms: algos,
	}

	var conn net.Conn
	if via == nil {
		conn, err = (&net.Dialer{}).DialContext(ctx, "tcp", addr)
	} else {
		conn, err = via.DialContext(ctx, "tcp", addr)
	}
	if err != nil {
		return nil, fail(err)
	}
	// The handshake takes no context: bound it with a deadline and close the
	// connection if ctx ends first.
	if dl, ok := ctx.Deadline(); ok {
		_ = conn.SetDeadline(dl)
	}
	stop := context.AfterFunc(ctx, func() { _ = conn.Close() })
	defer stop()
	c, chans, reqs, err := ssh.NewClientConn(conn, addr, cfg)
	if err != nil {
		_ = conn.Close()
		switch {
		case hostErr != nil:
			return nil, fail(hostErr)
		case k.locked != "" && strings.Contains(err.Error(), "unable to authenticate"):
			return nil, &PassphraseError{Path: k.locked}
		}
		return nil, fail(err)
	}
	_ = conn.SetDeadline(time.Time{})
	return ssh.NewClient(c, chans, reqs), nil
}

// keepalive pings the tunnel and closes it when the server stops answering,
// so the next use reconnects instead of hanging on a dead TCP connection.
func (p *Pool) keepalive(ch *chain) {
	t := time.NewTicker(p.opts.Keepalive)
	defer t.Stop()
	for {
		select {
		case <-ch.dead:
			return
		case <-t.C:
		}
		if err := ping(ch.last(), p.opts.Keepalive); err != nil {
			slog.Info("ssh tunnel lost", "err", err)
			ch.close()
			return
		}
	}
}

func ping(c *ssh.Client, timeout time.Duration) error {
	done := make(chan error, 1)
	go func() {
		_, _, err := c.SendRequest("keepalive@openssh.com", true, nil)
		done <- err
	}()
	select {
	case err := <-done:
		return err
	case <-time.After(timeout):
		return errors.New("keepalive timed out")
	}
}

// chain is the SSH clients of one tunnel, first hop first.
type chain struct {
	clients []*ssh.Client
	dead    chan struct{} // closed once any hop disconnects
	once    sync.Once
}

func (c *chain) last() *ssh.Client { return c.clients[len(c.clients)-1] }

func (c *chain) alive() bool {
	select {
	case <-c.dead:
		return false
	default:
		return true
	}
}

func (c *chain) kill() { c.once.Do(func() { close(c.dead) }) }

func (c *chain) close() {
	c.kill()
	for i := len(c.clients) - 1; i >= 0; i-- {
		_ = c.clients[i].Close()
	}
}

// tunnelConn reports the address it was dialed with as its remote address.
// SSH channels report 0.0.0.0:0, and pgx sends cancel requests to
// RemoteAddr(): without this, Ctrl-c could not reach PostgreSQL.
type tunnelConn struct {
	net.Conn
	remote net.Addr
}

func (c *tunnelConn) RemoteAddr() net.Addr { return c.remote }

type tunnelAddr struct{ network, addr string }

func (a tunnelAddr) Network() string { return a.network }
func (a tunnelAddr) String() string  { return a.addr }
```

```go
type TxEffect int

	TxNone   TxEffect = iota
	TxBegin           // a fresh transaction is open afterwards: BEGIN, START TRANSACTION, COMMIT AND CHAIN
	TxEnd             // the transaction is over: COMMIT, ROLLBACK, END, ABORT, PREPARE TRANSACTION
	TxResume          // ROLLBACK TO SAVEPOINT: still open, and usable again after an error
)

// TransactionEffect classifies transaction-control statements; every other
// statement is TxNone. SAVEPOINT and RELEASE leave the transaction as it is.
func TransactionEffect(stmt string, d Dialect) TxEffect {
	toks := codeTokens(stmt, d)
	if len(toks) == 0 || toks[0].kind != tokWord {
		return TxNone
	}
	switch upper(toks[0]) {
	case "BEGIN":
		return TxBegin
	case "START":
		if len(toks) > 1 && isWord(toks[1], "TRANSACTION") {
			return TxBegin
		}
	case "PREPARE":
		if len(toks) > 1 && isWord(toks[1], "TRANSACTION") {
			return TxEnd
		}
	case "ROLLBACK":
		if indexWord(toks, 1, "TO") >= 0 {
			return TxResume
		}
		return endEffect(toks)
	case "COMMIT", "END", "ABORT":
		return endEffect(toks)
	}
	return TxNone
}

func endEffect(toks []token) TxEffect {
	if indexWord(toks, 1, "PREPARED") >= 0 {
		return TxNone // two-phase commit of another, already prepared transaction
	}
	if k := indexWord(toks, 1, "CHAIN"); k > 0 && !isWord(toks[k-1], "NO") {
		return TxBegin
	}
	return TxEnd
}
```

```go
// Policy is what the guard knows about the connection.
type Policy struct {
	ReadOnly bool // writes and DDL are rejected
	Prod     bool // writes and DDL need confirming
}

// Check is the guard's decision for a batch of statements.
type Check struct {
	Verdict Verdict
	Reason  string   // Reject: why; Confirm: what is risky
	SQL     string   // the statement that triggered the check
	Title   string   // Confirm: dialog title
	Body    []string // Confirm: dialog text
	Expect  string   // Confirm: the text the user must type; empty means pressing y
}

// Guard applies the safety rules of spec §5.3. A rejection wins over any
// confirmation, and a missing WHERE (type the table name) wins over the prod
// confirmation (press y).
func Guard(stmts []sqlx.Statement, d sqlx.Dialect, p Policy) Check {
	var missing *Check
	var writes []string
	firstWrite := ""
	for _, s := range stmts {
		info := sqlx.Analyze(s.Text, d)
		write := info.Kind == sqlx.Write || info.Kind == sqlx.DDL
		if p.ReadOnly && write {
			return Check{
				Verdict: Reject, SQL: s.Text,
				Reason: fmt.Sprintf("read-only connection: %s statements are blocked (:set noreadonly allows them for this session)", info.Kind),
			}
		}
		if p.ReadOnly && sqlx.UnlocksReadOnly(s.Text, d) {
			return Check{
				Verdict: Reject, SQL: s.Text,
				Reason: "read-only connection: switching the session to read-write is blocked (use :set noreadonly)",
			}
		}
		if info.MissingWhere && missing == nil {
			target, expect := info.Target, info.Target
			if target == "" {
				target, expect = "the table", "yes"
			}
			reason := fmt.Sprintf("This statement has no WHERE clause and changes every row of %s.", target)
			missing = &Check{
				Verdict: Confirm, SQL: s.Text, Expect: expect, Reason: reason,
				Title: "Statement has no WHERE clause", Body: []string{reason, "", s.Text},
			}
		}
		if p.Prod && write {
			if firstWrite == "" {
				firstWrite = s.Text
			}
			writes = append(writes, summary(s.Text, info))
		}
	}
	switch {
	case missing != nil && p.Prod:
		missing.Title = "PROD · " + missing.Title
		missing.Body = append(missing.Body, "", "This is a PROD connection.")
		return *missing
	case missing != nil:
		return *missing
	case len(writes) > 0:
		reason := fmt.Sprintf("%d statement(s) will change a PROD database:", len(writes))
		return Check{
			Verdict: Confirm, SQL: firstWrite, Reason: reason, Title: "Write to PROD",
			Body: append([]string{reason, ""}, writes...),
		}
	}
	return Check{Verdict: Allow}
}

// summary is one line of the prod confirmation: kind, table and statement.
func summary(sql string, info sqlx.Info) string {
	s := strings.Join(strings.Fields(sql), " ")
	if r := []rune(s); len(r) > 60 {
		s = string(r[:59]) + "…"
	}
	if info.Target != "" {
		return fmt.Sprintf("%s %s: %s", info.Kind, info.Target, s)
	}
	return fmt.Sprintf("%s: %s", info.Kind, s)
}
```

```go
func Frame(title, body string, width, height int, focused, danger bool) string {
	if width < 2 || height < 2 {
		return ""
	}
	inner := width - 2
	border := lipgloss.NewStyle().Foreground(ColorBorder)
	switch {
	case danger:
		border = border.Foreground(ColorError)
	case focused:
		border = border.Foreground(ColorFocus)
	}

	head := ""
	if title != "" {
		head = ansi.Truncate(" "+title+" ", inner, "…")
	}
	rest := inner - ansi.StringWidth(head)
	lines := make([]string, 0, height)
	lines = append(lines, border.Render("┌")+Title.Render(head)+border.Render(strings.Repeat("─", rest)+"┐"))

	bodyLines := strings.Split(body, "\n")
	for i := range height - 2 {
		l := ""
		if i < len(bodyLines) {
			l = bodyLines[i]
		}
		lines = append(lines, border.Render("│")+textutil.Fit(l, inner)+border.Render("│"))
	}
	lines = append(lines, border.Render("└"+strings.Repeat("─", inner)+"┘"))
	return strings.Join(lines, "\n")
}
```

```go
	ctx, cancel := context.WithCancel(context.Background())
	t.gen++

		if s != nil && sessRO != ro {
			// :set [no]readonly changed the connection: the session's
			// server-side read-only setting no longer matches.
			_ = s.Close()
			s = nil
			msg.reopened = true
		}
		sess, reconnected, err := ensureSession(ctx, b, conn, ns, s)
		msg.reconnected = reconnected
		if err != nil {

			return msg
		}

		if n := len(msg.results); n > 0 && db.IsConnLost(msg.results[n-1].Err) {
			_ = sess.Close()
			sess = nil
		}
		msg.session = sess
		return msg
	}
	return tea.Batch(run, t.tick(gen))
```
```go
}

// toggleTx switches between autocommit and manual commit.
func (t *consoleTab) toggleTx() tea.Cmd {
	if t.manualTx && t.inTx {
		t.setStatus("a transaction is open · :commit or :rollback first", true)
		return nil
	}
	t.manualTx = !t.manualTx
	if t.manualTx {

	} else {
		t.setStatus("autocommit", false)
	}
	return nil

// endTx runs COMMIT or ROLLBACK for :commit and :rollback.
func (t *consoleTab) endTx(commit bool) tea.Cmd {
	switch {
	case t.running:
		t.setStatus("a query is already running · ctrl+c to cancel", true)
	case !t.inTx:
		t.setStatus("no open transaction", true)
	case commit && t.txAborted:
		t.setStatus("the transaction failed and cannot be committed · :rollback", true)
	default:
		sql := "ROLLBACK"
		if commit {
			sql = "COMMIT"
		}
		return t.execute([]sqlx.Statement{{Text: sql}}, t.maxRows, false)
	}
	return nil
}

// TxStatus is the status bar badge for the console's transaction.
func (t *consoleTab) TxStatus() string {
	switch {
	case t.txAborted:
		return "TX failed · :rollback"
	case t.inTx:
		return fmt.Sprintf("TX %d", t.txWrites)
	case t.manualTx:
		return "TX"
	}
	return ""
}

func (t *consoleTab) openTx() bool { return t.inTx }

func (t *consoleTab) clearTx() { t.inTx, t.txWrites, t.txAborted = false, 0, false }

// trackTx follows the transaction through the statements that ran.
// sessionLost means the session died during the run.
func (t *consoleTab) trackTx(results []runner.Result, sessionLost bool) {
	for _, r := range results {
		if r.Err != nil {
			// PostgreSQL refuses everything but ROLLBACK after an error in a transaction.
			if t.inTx && t.dialect == sqlx.Postgres && !db.IsConnLost(r.Err) {
				t.txAborted = true
			}
			continue
		}
		switch sqlx.TransactionEffect(r.SQL, t.dialect) {
		case sqlx.TxBegin:
			t.inTx, t.txWrites, t.txAborted = true, 0, false
			continue
		case sqlx.TxEnd:
			t.clearTx()
			continue
		case sqlx.TxResume:
			t.txAborted = false
			continue
		}
		if !t.inTx {
			continue
		}
		switch sqlx.Analyze(r.SQL, t.dialect).Kind {
		case sqlx.Write:
			t.txWrites++
		case sqlx.DDL:
			if t.dialect == sqlx.MySQL {
				t.log("MySQL committed the open transaction implicitly before " + oneLine(r.SQL))
				t.clearTx()
			} else {
				t.txWrites++
			}
		}
	}
	if sessionLost && t.inTx {
		t.log("✗ " + errTxLost.Error())
		t.clearTx()
	}
}
```

`ensureSession` 替换为：

```go
// ensureSession returns a live session: s if it still answers a ping,
// otherwise a newly opened one (reconnected reports that). Statements are
// never retried here. Inside a transaction a dead session is not replaced:
// the transaction is gone, and the caller reports errTxLost.
func ensureSession(ctx context.Context, b Backend, conn string, ns db.Namespace, s db.Session, inTx bool) (db.Session, bool, error) {
	if s != nil {
		pctx, cancel := context.WithTimeout(ctx, pingTimeout)
		err := s.Ping(pctx)
		cancel()
		if err == nil {
			return s, false, nil
		}
		slog.Info("console session lost", "conn", conn, "in_transaction", inTx, "err", err)
		_ = s.Close()
		if inTx {
			return nil, false, errTxLost
		}
	}
	reconnected := s != nil
	ns2, err := openSession(ctx, b, conn, ns)
	if db.IsConnLost(err) {
		b.Reset(conn)
		ns2, err = openSession(ctx, b, conn, ns)
		reconnected = true
	}
	return ns2, reconnected, err
}
```

```go
			return c.endTx(cmd == "commit")
		}
		m.setStatus("no open transaction: the active tab is not a console", true)
	default:
		m.setStatus("unknown command: "+cmd, true)
	}
	return nil
}

// requestClose closes the active tab, asking first when it holds an open
// transaction (unless force). With no tabs it quits, like vim.
func (m *Model) requestClose(force bool) tea.Cmd {
	t := m.activeTab()
	if t == nil {
		return m.requestQuit(force)
	}
	if c, ok := t.(*consoleTab); ok && c.openTx() && !force {
		m.overlay = overlay.NewConfirm("Open transaction", []string{
			c.Title() + " has an open transaction (" + c.TxStatus() + ").",
			"Closing the console rolls it back.",
		}, "", closeTabConfirmedMsg{tabID: t.ID()})
		return nil
	}
	return m.closeTab(m.active)
}

// requestQuit quits, asking first when consoles hold open transactions
// (unless force).
func (m *Model) requestQuit(force bool) tea.Cmd {
	if open := m.openTransactions(); len(open) > 0 && !force {
		m.overlay = overlay.NewConfirm("Open transactions", []string{
			"Uncommitted transactions in: " + strings.Join(open, ", ") + ".",
			"Quitting rolls them back.",
		}, "", quitConfirmedMsg{})
		return nil
	}
	return m.quit()
}

// openTransactions names the consoles with an uncommitted transaction.
func (m *Model) openTransactions() []string {
	var out []string
	for _, t := range m.tabs {
		if c, ok := t.(*consoleTab); ok && c.openTx() {
			out = append(out, c.Title())
		}
	}
	return out
}

// setOption handles :set readonly / noreadonly for the connection in context.
func (m *Model) setOption(opt string) tea.Cmd {
	var ro bool
	switch opt {
	case "readonly", "ro":
		ro = true
	case "noreadonly", "noro":
	default:
		m.setStatus("unknown option: "+opt+" (readonly, noreadonly)", true)
		return nil
	}
	cfg, ok := m.contextConfig()
	if !ok {
		m.setStatus("select a connection first", true)
		return nil
	}
	if cfg.IsReadOnly() == ro {
		state := "read-write"
		if ro {
			state = "read-only"
		}
		m.setStatus(cfg.Name+" is already "+state, false)
		return nil
	}
	for _, t := range m.tabs {
		if c, ok := t.(*consoleTab); ok && c.conn == cfg.Name && c.openTx() {
			m.setStatus("a console on "+cfg.Name+" has an open transaction · :commit or :rollback first", true)
			return nil
		}
	}
	if err := m.backend.SetReadOnly(cfg.Name, ro); err != nil {
		m.setStatus(err.Error(), true)
		return nil
	}
	switch {
	case ro:
		m.setStatus(cfg.Name+" is read-only again", false)
	case cfg.Env == config.EnvProd:
		m.setStatus(cfg.Name+" is read-write for this session · writes still ask for confirmation", false)
	default:
		m.setStatus(cfg.Name+" is read-write for this session", false)
	}
	return nil
}
```

```go
import (
	"errors"

	tea "charm.land/bubbletea/v2"

	"github.com/shepherd-yun/sqlvim/internal/db/tunnel"
	"github.com/shepherd-yun/sqlvim/internal/ui/overlay"
)

type (
	passphraseMsg  struct{ path, passphrase string }
	hostTrustedMsg struct{ host *tunnel.UnknownHostError }
)

// sshPrompt returns the popup that resolves err when err needs the user: a
// key passphrase, or accepting an unknown host key. Otherwise nil.
func sshPrompt(err error) overlay.Overlay {
	var pe *tunnel.PassphraseError
	var ue *tunnel.UnknownHostError
	switch {
	case errors.As(err, &pe):
		label := "Passphrase for " + pe.Path + ":"
		if pe.Wrong {
			label = "Wrong passphrase. Passphrase for " + pe.Path + ":"
		}
		path := pe.Path
		return overlay.NewSecret("SSH key", label, func(s string) tea.Msg {
			return passphraseMsg{path: path, passphrase: s}
		})
	case errors.As(err, &ue):
		return overlay.NewConfirm("Unknown SSH host", []string{
			"The authenticity of host " + ue.Host + " can't be established.",
			ue.Key.Type() + " key fingerprint:",
			ue.Fingerprint(),
			"",
			"Compare it with the server's real key before you continue.",
			"Accepting adds the key to " + ue.File + ".",
		}, "yes", hostTrustedMsg{host: ue})
	}
	return nil
}

func (m *Model) passphraseEntered(msg passphraseMsg) tea.Cmd {
	m.backend.SetPassphrase(msg.path, msg.passphrase)
	return m.retryLoad()
}

func (m *Model) hostTrusted(msg hostTrustedMsg) tea.Cmd {
	if err := m.backend.TrustHost(msg.host); err != nil {
		m.setStatus("cannot update known_hosts: "+err.Error(), true)
		return nil
	}
	m.setStatus("added "+msg.host.Host+" to "+msg.host.File, false)
	return m.retryLoad()
}

// retryLoad reloads the tree node whose load needed the user's answer.
// Other operations are simply run again by the user.
func (m *Model) retryLoad() tea.Cmd {
	node := m.retryNode
	m.retryNode = nil
	if node == nil {
		if m.status == "" {
			m.setStatus("ssh ready · run it again", false)
		}
		return nil
	}
	m.tree.StartLoad(node)
	return loadChildren(m.backend, node)
}
```

```go
// cancelThroughTunnel cancels a long statement on a session and checks that
```

```go
// newManager builds the session manager; connections added in the UI are
// appended to dir/connections.toml, and ssh connections use tunnels.
func newManager(cfg *config.Config, dir string, tunnels session.Tunneler) *session.Manager {
	mgr := session.NewManager(cfg.Connections, secret.Keyring{}, mysql.Driver{}, postgres.Driver{})
	mgr.Persist = func(c config.Connection) error {
		_, err := config.AppendConnection(dir, c)
		return err
	}
	mgr.Tunnels = tunnels
	return mgr
}

// localUser is the default SSH user, as for ssh(1).
func localUser() string {
	if u, err := user.Current(); err == nil && u.Username != "" {
		return u.Username
	}
	return os.Getenv("USER")
}
```

~~~markdown
## SSH tunnels

Set `ssh` to a `Host` alias from `~/.ssh/config`; `host` is then resolved by the SSH server:

```toml

name     = "prod-pg"
driver   = "postgres"
host     = "10.0.1.5"   # as seen from the bastion

database = "app"

```

sqlvim reads `HostName`, `Port`, `User`, `IdentityFile`, `ProxyJump` (any number of hops)
and `UserKnownHostsFile`. It tries ssh-agent first, then your identity files, and asks
for a key's passphrase only when nothing else works (passphrases are kept in memory).
Unknown hosts show their fingerprint and are added to `known_hosts` once you type `yes`;
a changed host key is an error. `ProxyCommand` is not supported.
~~~

```markdown
## Safety

- `readonly = true` (the default for `env = "prod"`) blocks INSERT/UPDATE/DELETE and DDL
  in the console, and the database session itself is read-only as a second line of defence.
  `:set noreadonly` unlocks the connection until sqlvim exits; `connections.toml` is not changed.
- `env = "prod"` frames the tab area in red and shows `[PROD]` in the status bar; every
  write or DDL statement on a prod connection asks for `y` first.
- `UPDATE` / `DELETE` without `WHERE` asks you to type the table name before it runs.
- In manual commit mode (`<Space>t`) quitting or closing a console with an open transaction
  asks first. If the connection drops during a transaction, sqlvim says the transaction is
  lost instead of reconnecting silently. Use `<Space>t` rather than `SET autocommit = 0`.
```
