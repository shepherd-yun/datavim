# sqlvim v0.4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 sqlvim v0.4「DataGrip 核心体验」：元数据缓存（连接时后台加载、`<Space>r` 刷新、控制台执行 DDL 后自动失效）；`<Space><Space>` 全局搜索（库 / schema / 表 / 视图 / 列 / 函数，`@` 前缀搜所有已连接的连接）；`<Space>e` 最近打开（跨会话保存）；控制台 INSERT 模式自动补全（表名、列名、别名、关键字）；Chroma 语法高亮（控制台编辑器与结构视图 DDL）；以及 v0.2/v0.3 计划推迟到本版的「执行出错时跳到编辑器中的出错位置」。

**Architecture:** `db.MetaReader` 新增批量读取的 `Catalog` 和 `RoutineDDL`（PG 每个数据库一份目录，MySQL 一次读全服务器）。新增纯逻辑包 `internal/meta`：不可变的 `Snapshot`（目录 + 查找索引 + 搜索条目）、只在 UI goroutine 使用的 `Cache`（按 `Key{Conn, Database}` 记录加载状态与代次）、基于 `sahilm/fuzzy` 的 `Search`。`sqlx` 新增补全上下文分析 `Complete`、关键字表和 `QuoteIfNeeded`。新增 `internal/ui/highlight`（Chroma → 颜色类别 span）与 `internal/ui/panes/complete`（候选排序 + 弹框）。控制台编辑器改为自绘视图（textarea 仍负责编辑与光标，渲染改由我们做：高亮、软换行、光标格子、光标屏幕坐标），以便叠加高亮和补全弹框。驱动把带位置的服务器错误包装成 `db.PositionError`，控制台据此移动光标。根 Model 持有 `meta.Cache`，所有加载、搜索匹配、读写 `state.db` 都在 `tea.Cmd` 中进行。

**Tech Stack:** v0.3 全部依赖，另加 github.com/alecthomas/chroma/v2 v2.27.0（语法高亮）· github.com/sahilm/fuzzy v0.1.3（模糊匹配）

**Spec:** `docs/superpowers/specs/2026-10-13-sqlvim-design.md`（§3.1 `meta` 包、§5.4 执行、§5.6 补全与高亮、§5.10 全局搜索与最近打开、§5.11 结构视图 DDL 高亮、§6.3 leader 键、§7 本地数据、§8 错误定位、§10 v0.4 行）；前三版计划 `docs/superpowers/plans/2026-10-13-sqlvim-v0.1.md`、`docs/superpowers/plans/2026-10-13-sqlvim-v0.2.md`、`docs/superpowers/plans/2026-10-13-sqlvim-v0.3.md`（其中的约定继续有效）。

## Global Constraints

- v0.1–v0.3 计划的 Global Constraints 全部继续有效（模块路径 `github.com/shepherd-yun/sqlvim`、XDG 目录、密码不落盘、日志不含密码、英文 UI 文案、UI 层不做 IO、Conventional Commits + attribution、集成测试 build tag `integration`、`Ctrl-c` 不退出、`Ctrl-c` 取消查询）。
- 新增依赖只允许：`github.com/alecthomas/chroma/v2 v2.27.0`、`github.com/sahilm/fuzzy v0.1.3`（版本固定，不升级其他依赖）。
- 元数据缓存只在内存中，不写 `state.db`。缓存键：MySQL 为 `{连接名, ""}`（一次读全服务器，排除 `information_schema`、`mysql`、`performance_schema`、`sys`）；PostgreSQL 为 `{连接名, 数据库}`（只读该数据库中名字不以 `pg_` 开头且不是 `information_schema` 的 schema；数据库为空时取配置的 `database`，仍为空取 `postgres`）。
- 加载时机：某个连接 / 数据库**第一次成功使用**时（树加载出子节点、打开数据 / 结构 / 控制台 tab、打开全局搜索）在后台加载；每个键同时最多一次加载；加载失败**不自动重试**，`<Space>r` 重新加载。加载超时 `catalogTimeout = 60 * time.Second`。
- `<Space>r`：除原有的刷新树节点 / 当前 tab 外，重新加载当前上下文连接（与数据库）的元数据；控制台执行成功的 DDL 后，若该键已有缓存（`Ready`/`Failed`/`Loading`），自动重新加载；连接被编辑或删除时丢弃它的全部缓存。重新加载期间旧快照继续可用；被新加载取代的旧加载结果一律丢弃。
- 全局搜索：`<Space><Space>` 打开；默认只搜当前上下文连接已加载的目录，查询以 `@` 开头（或没有上下文连接）时搜所有已加载的目录；匹配在 `tea.Cmd` 中进行，按代次丢弃过期结果；最多显示 `searchLimit = 200` 条；`Enter` 打开（表 / 视图 → 数据 tab；列 → 所属表的数据 tab 并把光标移到该列；函数 → 浮层显示定义；库 / schema → 在树中展开定位并聚焦树），`Ctrl-s` 打开表 / 视图 / 列所属表的结构 tab。
- 补全：控制台 INSERT 模式下，光标前的单词至少 1 个字符或刚输入 `.` 时自动弹出；最多 `maxCandidates = 50` 个候选；`Ctrl-n` / `Tab` 下一个，`Ctrl-p` / `Shift-Tab` 上一个，`Ctrl-y` 接受（未选择时接受第一个），`Esc` 关闭弹框并回到 NORMAL（与 vim 一致），`Enter` 关闭弹框并照常换行；弹框关闭时 `Ctrl-n` / `Ctrl-p` 强制弹出。在字符串、注释、带引号的标识符内部不弹出。插入的标识符按方言在需要时加引号（MySQL 反引号，PG 双引号）。关键字按输入的大小写补全（输入含小写字母则补小写）。
- 语法高亮：Chroma 词法器 `mysql` / `postgresql`，`TokeniseOptions{State: "root"}`（不改写换行），颜色只用 ANSI 16 色；Chroma 输出与原文不一致时整段按无高亮显示。
- 最近打开：`state.db` 新表 `recent`，同一对象（类型、连接、库、schema、名称）只保留一行并更新时间，最多 `maxRecent = 200` 行；`<Space>e` 列出最新的 `recentLimit = 100` 条。打开或切换到数据 / 结构 / 控制台 tab 都会记录。
- 错误定位：只有当编辑器内容自执行以来没有变化时才移动光标；状态行显示 `line L, col C: <错误>`（行列从 1 开始，列按字符计）。

### v0.4 明确不做

`<Space>o` 切换连接 / 数据库（后续版本）；元数据缓存持久化；树中显示函数；补全函数名、补全 PG `search_path` 中除控制台 schema 之外的 schema 里的表；结果表格的高亮；内置 vim 编辑器（v0.5）；数据编辑（v0.6）。

```go
// RoutineKind distinguishes stored functions from procedures.
type RoutineKind int

const (
	RoutineFunction RoutineKind = iota
	RoutineProcedure
)

// Routine is a stored function or procedure. Args is PostgreSQL's identity
// argument list (it tells overloads apart); MySQL leaves it empty.
type Routine struct {
	Namespace Namespace
	Name      string
	Kind      RoutineKind
	Args      string
}

// CatalogTable is a table or view with its namespace.
type CatalogTable struct {
	Namespace Namespace
	Name      string
	Kind      TableKind
}

// CatalogColumn is one column of a catalog table.
type CatalogColumn struct {
	Table TableRef
	Name  string
	Type  string
}

// Catalog is every user object a Conn can see, read in bulk for search and
// completion. System databases and schemas are left out of Namespaces,
// Tables, Columns and Routines.
type Catalog struct {
	Databases  []string    // every database on the server, as Databases returns them
	Namespaces []Namespace // MySQL: one per user database; PostgreSQL: one per user schema of the Conn's database
	Tables     []CatalogTable
	Columns    []CatalogColumn // grouped by table, in column order
	Routines   []Routine
}
```

`internal/db/driver.go` 的 `MetaReader` 在 `DDL` 之后加两个方法：

```go
	// Catalog reads every user namespace, table, column and routine at once:
	// PostgreSQL those of the Conn's database, MySQL those of every database.
	Catalog(ctx context.Context) (Catalog, error)
	// RoutineDDL returns the CREATE statement of r, or ErrNotFound.
	RoutineDDL(ctx context.Context, r Routine) (string, error)
```

- [ ] **Step 4: 实现 PostgreSQL**

创建 `internal/db/postgres/catalog.go`：

```go
package postgres

import (
	"context"
	"errors"
	"fmt"

	"github.com/jackc/pgx/v5"

	"github.com/shepherd-yun/sqlvim/internal/db"
)

// userSchemas filters pg_namespace n down to the schemas Schemas lists.
const userSchemas = `n.nspname !~ '^pg_' AND n.nspname <> 'information_schema'`

func (m meta) ns(schema string) db.Namespace {
	return db.Namespace{Database: m.c.database, Schema: schema}
}

func (m meta) Catalog(ctx context.Context) (db.Catalog, error) {
	var c db.Catalog
	var err error
	if c.Databases, err = m.Databases(ctx); err != nil {
		return c, err
	}
	schemas, err := m.Schemas(ctx, "")
	if err != nil {
		return c, err
	}
	for _, s := range schemas {
		c.Namespaces = append(c.Namespaces, m.ns(s))
	}

	rows, err := m.c.pool.Query(ctx, `
		SELECT n.nspname::text, c.relname::text, c.relkind::text
		FROM pg_class c JOIN pg_namespace n ON n.oid = c.relnamespace
		WHERE `+userSchemas+` AND c.relkind IN ('r','p','v','m','f') AND NOT c.relispartition
		ORDER BY 1, 2`)
	if err != nil {
		return c, err
	}
	c.Tables, err = pgx.CollectRows(rows, func(row pgx.CollectableRow) (db.CatalogTable, error) {
		var t db.CatalogTable
		var schema, kind string
		err := row.Scan(&schema, &t.Name, &kind)
		t.Namespace = m.ns(schema)
		if kind == "v" || kind == "m" {
			t.Kind = db.TableKindView
		}
		return t, err
	})
	if err != nil {
		return c, err
	}

	rows, err = m.c.pool.Query(ctx, `
		SELECT n.nspname::text, c.relname::text, a.attname::text, format_type(a.atttypid, a.atttypmod)
		FROM pg_attribute a
		JOIN pg_class c ON c.oid = a.attrelid
		JOIN pg_namespace n ON n.oid = c.relnamespace
		WHERE `+userSchemas+` AND c.relkind IN ('r','p','v','m','f') AND NOT c.relispartition
		  AND a.attnum > 0 AND NOT a.attisdropped
		ORDER BY n.nspname, c.relname, a.attnum`)
	if err != nil {
		return c, err
	}
	c.Columns, err = pgx.CollectRows(rows, func(row pgx.CollectableRow) (db.CatalogColumn, error) {
		var col db.CatalogColumn
		var schema string
		err := row.Scan(&schema, &col.Table.Name, &col.Name, &col.Type)
		col.Table.Namespace = m.ns(schema)
		return col, err
	})
	if err != nil {
		return c, err
	}

	rows, err = m.c.pool.Query(ctx, `
		SELECT n.nspname::text, p.proname::text, p.prokind::text, pg_get_function_identity_arguments(p.oid)
		FROM pg_proc p JOIN pg_namespace n ON n.oid = p.pronamespace
		WHERE `+userSchemas+` AND p.prokind IN ('f','p')
		ORDER BY 1, 2, 4`)
	if err != nil {
		return c, err
	}
	c.Routines, err = pgx.CollectRows(rows, func(row pgx.CollectableRow) (db.Routine, error) {
		var r db.Routine
		var schema, kind string
		err := row.Scan(&schema, &r.Name, &kind, &r.Args)
		r.Namespace = m.ns(schema)
		if kind == "p" {
			r.Kind = db.RoutineProcedure
		}
		return r, err
	})
	return c, err
}

func (m meta) RoutineDDL(ctx context.Context, r db.Routine) (string, error) {
	if err := m.checkDatabase(r.Namespace.Database); err != nil {
		return "", err
	}
	var def string
	err := m.c.pool.QueryRow(ctx, `
		SELECT pg_get_functiondef(p.oid)
		FROM pg_proc p JOIN pg_namespace n ON n.oid = p.pronamespace
		WHERE n.nspname = $1 AND p.proname = $2 AND pg_get_function_identity_arguments(p.oid) = $3`,
		r.Namespace.Schema, r.Name, r.Args).Scan(&def)
	if errors.Is(err, pgx.ErrNoRows) {
		return "", fmt.Errorf("%s(%s): %w", r.Name, r.Args, db.ErrNotFound)
	}
	return def, err
}
```

```go
const errNoSuchRoutine = 1305

var systemDatabases = []string{"information_schema", "mysql", "performance_schema", "sys"}

// userDatabases filters an information_schema *_SCHEMA column.
const userDatabases = " NOT IN ('information_schema', 'mysql', 'performance_schema', 'sys')"

// each runs q and calls scan for every row.
func (m meta) each(ctx context.Context, q string, scan func(*sql.Rows) error) error {
	rows, err := m.c.db.QueryContext(ctx, q)
	if err != nil {
		return err
	}
	defer func() { _ = rows.Close() }()
	for rows.Next() {
		if err := scan(rows); err != nil {
			return err
		}
	}
	return rows.Err()
}

func (m meta) Catalog(ctx context.Context) (db.Catalog, error) {
	var c db.Catalog
	var err error
	if c.Databases, err = m.Databases(ctx); err != nil {
		return c, err
	}
	for _, d := range c.Databases {
		if !slices.Contains(systemDatabases, strings.ToLower(d)) {
			c.Namespaces = append(c.Namespaces, db.Namespace{Database: d})
		}
	}
	err = m.each(ctx, `SELECT TABLE_SCHEMA, TABLE_NAME, TABLE_TYPE FROM information_schema.TABLES
		WHERE TABLE_SCHEMA`+userDatabases+` ORDER BY TABLE_SCHEMA, TABLE_NAME`, func(rows *sql.Rows) error {
		var t db.CatalogTable
		var typ string
		if err := rows.Scan(&t.Namespace.Database, &t.Name, &typ); err != nil {
			return err
		}
		if strings.Contains(typ, "VIEW") {
			t.Kind = db.TableKindView
		}
		c.Tables = append(c.Tables, t)
		return nil
	})
	if err != nil {
		return c, err
	}
	err = m.each(ctx, `SELECT TABLE_SCHEMA, TABLE_NAME, COLUMN_NAME, COLUMN_TYPE FROM information_schema.COLUMNS
		WHERE TABLE_SCHEMA`+userDatabases+` ORDER BY TABLE_SCHEMA, TABLE_NAME, ORDINAL_POSITION`, func(rows *sql.Rows) error {
		var col db.CatalogColumn
		if err := rows.Scan(&col.Table.Database, &col.Table.Name, &col.Name, &col.Type); err != nil {
			return err
		}
		c.Columns = append(c.Columns, col)
		return nil
	})
	if err != nil {
		return c, err
	}
	err = m.each(ctx, `SELECT ROUTINE_SCHEMA, ROUTINE_NAME, ROUTINE_TYPE FROM information_schema.ROUTINES
		WHERE ROUTINE_SCHEMA`+userDatabases+` ORDER BY ROUTINE_SCHEMA, ROUTINE_NAME`, func(rows *sql.Rows) error {
		var r db.Routine
		var typ string
		if err := rows.Scan(&r.Namespace.Database, &r.Name, &typ); err != nil {
			return err
		}
		if typ == "PROCEDURE" {
			r.Kind = db.RoutineProcedure
		}
		c.Routines = append(c.Routines, r)
		return nil
	})
	return c, err
}

func (m meta) RoutineDDL(ctx context.Context, r db.Routine) (string, error) {
	kind := "FUNCTION"
	if r.Kind == db.RoutineProcedure {
		kind = "PROCEDURE"
	}
	d := dialect{}
	name := d.QuoteIdent(r.Namespace.Database) + "." + d.QuoteIdent(r.Name)
	notFound := fmt.Errorf("%s: %w", name, db.ErrNotFound)
	rows, err := m.c.db.QueryContext(ctx, "SHOW CREATE "+kind+" "+name)
	if err != nil {
		var me *gomysql.MySQLError
		if errors.As(err, &me) && me.Number == errNoSuchRoutine {
			return "", notFound
		}
		return "", err
	}
	defer func() { _ = rows.Close() }()
	vals, ok, err := firstRow(rows)
	if err != nil {
		return "", err
	}
	if !ok {
		return "", notFound
	}
	// (Function, sql_mode, Create Function, ...); the definition is NULL
	// when the user may not read it.
	if len(vals) < 3 || !vals[2].Valid {
		return "", fmt.Errorf("%s: no privilege to read the definition", name)
	}
	return vals[2].String, nil
}

// firstRow scans the first row as strings; ok is false when there is none.
func firstRow(rows *sql.Rows) (vals []sql.NullString, ok bool, err error) {
	cols, err := rows.Columns()
	if err != nil {
		return nil, false, err
	}
	if !rows.Next() {
		return nil, false, rows.Err()
	}
	vals = make([]sql.NullString, len(cols))
	ptrs := make([]any, len(cols))
	for i := range vals {
		ptrs[i] = &vals[i]
	}
	return vals, true, rows.Scan(ptrs...)
}
```

```go
package db

import "errors"

// PositionError is a server error that points into the statement that
// caused it, such as a syntax error.
type PositionError struct {
	Err    error
	Offset int // byte offset into the statement text
}

func (e *PositionError) Error() string { return e.Err.Error() }
func (e *PositionError) Unwrap() error { return e.Err }

// ErrorOffset returns where in its statement err points, if it does.
func ErrorOffset(err error) (int, bool) {
	var pe *PositionError
	if errors.As(err, &pe) {
		return pe.Offset, true
	}
	return 0, false
}

// RuneOffset is the byte offset of the n-th rune (0-based) of s, clamped
// to [0, len(s)].
func RuneOffset(s string, n int) int {
	if n <= 0 {
		return 0
	}
	i := 0
	for off := range s {
		if i == n {
			return off
		}
		i++
	}
	return len(s)
}
```

```go
// locate marks server errors that carry a position (1-based, in characters).
func locate(err error, sql string) error {
	var pe *pgconn.PgError
	if errors.As(err, &pe) && pe.Position > 0 {
		return &db.PositionError{Err: err, Offset: db.RuneOffset(sql, int(pe.Position)-1)}

	return err
}
```

```go
package mysql

import (
	"errors"
	"regexp"
	"strconv"
	"strings"

	gomysql "github.com/go-sql-driver/mysql"

	"github.com/shepherd-yun/sqlvim/internal/db"
)

// nearRE matches the tail of a MySQL syntax error message. The quoted text
// is the rest of the statement from the error on (possibly cut short).
var nearRE = regexp.MustCompile(`(?s)near '(.*)' at line (\d+)$`)

// locate marks syntax errors with where they occur in query.
func locate(err error, query string) error {
	var me *gomysql.MySQLError
	if !errors.As(err, &me) {
		return err
	}
	m := nearRE.FindStringSubmatch(me.Message)
	if m == nil {
		return err
	}
	near := m[1]
	if near == "" {
		return &db.PositionError{Err: err, Offset: len(query)}
	}
	line, _ := strconv.Atoi(m[2])
	start := 0
	for i := 1; i < line; i++ {
		nl := strings.IndexByte(query[start:], '\n')
		if nl < 0 {
			return err
		}
		start += nl + 1
	}
	if k := strings.Index(query[start:], near); k >= 0 {
		return &db.PositionError{Err: err, Offset: start + k}
	}
	return &db.PositionError{Err: err, Offset: start}
}
```

```go
// Package meta caches database catalogs for search and completion.
package meta

import (
	"strings"
	"time"

	"github.com/shepherd-yun/sqlvim/internal/db"
)

// Key names one cached catalog: a connection and, for PostgreSQL, the
// database (MySQL catalogs cover the whole server and leave it empty).
type Key struct {
	Conn     string
	Database string
}

// Snapshot is a loaded catalog. It is never changed after NewSnapshot, so
// commands may read it on other goroutines.
type Snapshot struct {
	Key      Key
	Catalog  db.Catalog
	LoadedAt time.Time

	tables  map[db.Namespace][]db.CatalogTable
	columns map[db.TableRef][]db.CatalogColumn
	items   []Item
}

// NewSnapshot indexes c.
func NewSnapshot(k Key, c db.Catalog, at time.Time) *Snapshot {
	s := &Snapshot{
		Key: k, Catalog: c, LoadedAt: at,
		tables:  map[db.Namespace][]db.CatalogTable{},
		columns: map[db.TableRef][]db.CatalogColumn{},
	}
	for _, t := range c.Tables {
		s.tables[t.Namespace] = append(s.tables[t.Namespace], t)
	}
	for _, col := range c.Columns {
		s.columns[col.Table] = append(s.columns[col.Table], col)
	}
	s.items = buildItems(k, c)
	return s
}

// Tables lists the tables and views of ns. Without an exact match the
// namespace is matched ignoring case (unquoted names fold case).
func (s *Snapshot) Tables(ns db.Namespace) []db.CatalogTable {
	if t, ok := s.tables[ns]; ok {
		return t
	}
	for k, t := range s.tables {
		if strings.EqualFold(k.Database, ns.Database) && strings.EqualFold(k.Schema, ns.Schema) {
			return t
		}
	}
	return nil
}

// FindTable resolves a table name as typed: exactly, else ignoring case.
func (s *Snapshot) FindTable(ns db.Namespace, name string) (db.CatalogTable, bool) {
	tables := s.Tables(ns)
	for _, t := range tables {
		if t.Name == name {
			return t, true
		}
	}
	for _, t := range tables {
		if strings.EqualFold(t.Name, name) {
			return t, true
		}
	}
	return db.CatalogTable{}, false
}

// Columns lists the columns of t in order (t resolved as FindTable does).
func (s *Snapshot) Columns(t db.TableRef) []db.CatalogColumn {
	tb, ok := s.FindTable(t.Namespace, t.Name)
	if !ok {
		return nil
	}
	return s.columns[db.TableRef{Namespace: tb.Namespace, Name: tb.Name}]
}
```

```go
package meta

import (
	"context"
	"sort"
	"time"

	"github.com/shepherd-yun/sqlvim/internal/db"
)

// State is the load state of one catalog.
type State int

const (
	Missing State = iota // never loaded (or forgotten)
	Loading              // a load is running; an older snapshot may be shown meanwhile
	Ready
	Failed // the last load failed; an older snapshot may still be there
)

type entry struct {
	snap    *Snapshot
	loading int // generation of the running load; 0 = none
	err     error
}

// Cache holds the catalogs of the connections in use. It belongs to the UI
// goroutine and is not safe for concurrent use; loads run in commands (Load)
// and report back through Finish.
type Cache struct {
	entries map[Key]*entry
	gen     int
}

// NewCache returns an empty cache.
func NewCache() *Cache { return &Cache{entries: map[Key]*entry{}} }

func (c *Cache) entry(k Key) *entry {
	e := c.entries[k]
	if e == nil {
		e = &entry{}
		c.entries[k] = e
	}
	return e
}

// Get returns the snapshot of k (possibly stale while a reload runs) and
// its state.
func (c *Cache) Get(k Key) (*Snapshot, State) {
	e := c.entries[k]
	switch {
	case e == nil:
		return nil, Missing
	case e.loading != 0:
		return e.snap, Loading
	case e.err != nil:
		return e.snap, Failed
	case e.snap == nil:
		return nil, Missing
	}
	return e.snap, Ready
}

// Err is the error of the last failed load of k.
func (c *Cache) Err(k Key) error {
	if e := c.entries[k]; e != nil {
		return e.err
	}
	return nil
}

// Start marks k as loading and returns the generation to pass to Finish.
// ok is false when a load of k is already running.
func (c *Cache) Start(k Key) (gen int, ok bool) {
	if e := c.entries[k]; e != nil && e.loading != 0 {
		return 0, false
	}
	return c.Restart(k), true
}

// Restart starts a new load of k even if one is running; the running one's
// result will be dropped (it may predate a change).
func (c *Cache) Restart(k Key) int {
	c.gen++
	c.entry(k).loading = c.gen
	return c.gen
}

// Finish records the result of load gen of k and reports whether it was
// the current load. A failure keeps the previous snapshot.
func (c *Cache) Finish(k Key, gen int, s *Snapshot, err error) bool {
	e := c.entries[k]
	if e == nil || e.loading != gen {
		return false
	}
	e.loading = 0
	if err != nil {
		e.err = err
		return true
	}
	e.snap, e.err = s, nil
	return true
}

// Forget drops every catalog of conn; loads still running are dropped too.
func (c *Cache) Forget(conn string) {
	for k := range c.entries {
		if k.Conn == conn {
			delete(c.entries, k)
		}
	}
}

// Snapshots returns the loaded snapshots of conn ("" for every connection),
// sorted by key.
func (c *Cache) Snapshots(conn string) []*Snapshot {
	var out []*Snapshot
	for k, e := range c.entries {
		if e.snap != nil && (conn == "" || k.Conn == conn) {
			out = append(out, e.snap)
		}
	}
	sort.Slice(out, func(i, j int) bool {
		a, b := out[i].Key, out[j].Key
		if a.Conn != b.Conn {
			return a.Conn < b.Conn
		}
		return a.Database < b.Database
	})
	return out
}

// Load reads the catalog for k.
func Load(ctx context.Context, mr db.MetaReader, k Key) (*Snapshot, error) {
	c, err := mr.Catalog(ctx)
	if err != nil {
		return nil, err
	}
	return NewSnapshot(k, c, time.Now()), nil
}
```

```go
package meta

import (
	"sort"
	"strings"

	"github.com/sahilm/fuzzy"

	"github.com/shepherd-yun/sqlvim/internal/db"
)

// ItemKind is what a search item is. The order breaks ties between equally
// good matches.
type ItemKind int

const (
	ItemTable ItemKind = iota
	ItemView
	ItemRoutine
	ItemColumn
	ItemSchema
	ItemDatabase
)

func (k ItemKind) String() string {
	return [...]string{"table", "view", "routine", "column", "schema", "database"}[k]
}

// Item is one searchable object.
type Item struct {
	Kind    ItemKind
	Conn    string
	NS      db.Namespace
	Table   string // tables, views and columns: the table
	Name    string
	Detail  string     // column type; routine kind and arguments
	Routine db.Routine // ItemRoutine only
	Path    string     // what queries match: "users", "users.email", "add_one", "public", "app"
}

// Hit is an item that matches a query.
type Hit struct {
	Item
	Score int
}

func buildItems(k Key, c db.Catalog) []Item {
	out := make([]Item, 0, len(c.Databases)+len(c.Namespaces)+len(c.Tables)+len(c.Columns)+len(c.Routines))
	for _, d := range c.Databases {
		out = append(out, Item{Kind: ItemDatabase, Conn: k.Conn, NS: db.Namespace{Database: d}, Name: d, Path: d})
	}
	for _, ns := range c.Namespaces {
		if ns.Schema != "" {
			out = append(out, Item{Kind: ItemSchema, Conn: k.Conn, NS: ns, Name: ns.Schema, Path: ns.Schema})
		}
	}
	for _, t := range c.Tables {
		kind := ItemTable
		if t.Kind == db.TableKindView {
			kind = ItemView
		}
		out = append(out, Item{Kind: kind, Conn: k.Conn, NS: t.Namespace, Table: t.Name, Name: t.Name, Path: t.Name})
	}
	for _, col := range c.Columns {
		out = append(out, Item{
			Kind: ItemColumn, Conn: k.Conn, NS: col.Table.Namespace, Table: col.Table.Name,
			Name: col.Name, Detail: col.Type, Path: col.Table.Name + "." + col.Name,
		})
	}
	for _, r := range c.Routines {
		out = append(out, Item{
			Kind: ItemRoutine, Conn: k.Conn, NS: r.Namespace, Name: r.Name,
			Detail: routineDetail(r), Routine: r, Path: r.Name,
		})
	}
	return out
}

func routineDetail(r db.Routine) string {
	kind := "function"
	if r.Kind == db.RoutineProcedure {
		kind = "procedure"
	}
	if r.Args == "" {
		return kind
	}
	return kind + "(" + r.Args + ")"
}

// source presents the items of several snapshots as one fuzzy.Source
// without copying them.
type source struct {
	snaps  []*Snapshot
	starts []int
	n      int
}

func newSource(snaps []*Snapshot) source {
	s := source{snaps: snaps, starts: make([]int, len(snaps))}
	for i, sn := range snaps {
		s.starts[i] = s.n
		s.n += len(sn.items)
	}
	return s
}

func (s source) item(i int) *Item {
	k := sort.Search(len(s.starts), func(j int) bool { return s.starts[j] > i }) - 1
	return &s.snaps[k].items[i-s.starts[k]]
}

func (s source) String(i int) string { return s.item(i).Path }
func (s source) Len() int            { return s.n }

// Search matches query (fuzzy, ignoring case) against the items of snaps
// and returns at most limit hits, best first. Every PostgreSQL catalog of
// a connection lists all of its databases, so each database appears once.
func Search(snaps []*Snapshot, query string, limit int) []Hit {
	query = strings.TrimSpace(query)
	if query == "" || limit <= 0 {
		return nil
	}
	src := newSource(snaps)
	ms := fuzzy.FindFromNoSort(query, src)
	sort.SliceStable(ms, func(i, j int) bool {
		a, b := ms[i], ms[j]
		if a.Score != b.Score {
			return a.Score > b.Score
		}
		if ka, kb := src.item(a.Index).Kind, src.item(b.Index).Kind; ka != kb {
			return ka < kb
		}
		return len(a.Str) < len(b.Str)
	})
	out := []Hit{}
	seen := map[string]bool{}
	for _, m := range ms {
		it := src.item(m.Index)
		if it.Kind == ItemDatabase {
			id := it.Conn + "\x00" + it.Name
			if seen[id] {
				continue
			}
			seen[id] = true
		}
		out = append(out, Hit{Item: *it, Score: m.Score})
		if len(out) == limit {
			break
		}
	}
	return out
}
```

```go
package sqlx

import "strings"

// CompleteKind is what the word at the cursor should be completed with.
type CompleteKind int

const (
	CompleteNone CompleteKind = iota // inside a string, comment or quoted identifier
	CompleteKeyword
	CompleteTable
	CompleteColumn
)

// TableUse is a table a statement refers to.
type TableUse struct {
	Qualifier string // database (MySQL) or schema (PostgreSQL) written before the name
	Name      string
	Alias     string
}

// Completion describes the word under the cursor. Completing it replaces
// the source from Start to the cursor.
type Completion struct {
	Kind      CompleteKind
	Prefix    string // the part of the word before the cursor
	Start     int    // byte offset of the word in the source
	Qualifier string // the name before ".", if any: alias, table, schema or database
	Tables    []TableUse
}

var (
	tableClause   = wordSet("FROM", "JOIN", "UPDATE", "INTO", "TABLE")
	columnClause  = wordSet("SELECT", "WHERE", "ON", "SET", "BY", "HAVING", "AND", "OR", "NOT", "WHEN", "THEN", "ELSE", "DISTINCT", "USING")
	keywordClause = wordSet("VALUES", "LIMIT", "OFFSET")
	// aliasStop ends a table reference: these words are never aliases.
	aliasStop = wordSet("WHERE", "JOIN", "ON", "USING", "LEFT", "RIGHT", "INNER", "OUTER", "CROSS", "FULL",
		"NATURAL", "GROUP", "ORDER", "LIMIT", "HAVING", "UNION", "SET", "VALUES", "SELECT", "WINDOW", "FOR",
		"OFFSET", "FETCH", "INTERSECT", "EXCEPT", "LATERAL", "STRAIGHT_JOIN", "PARTITION", "USE", "FORCE",
		"IGNORE", "RETURNING", "DEFAULT", "AS")
)

// Complete inspects src at cursor (a byte offset).
func Complete(src string, cursor int, d Dialect) Completion {
	cursor = max(0, min(cursor, len(src)))
	start, end := statementAround(src, cursor, d)
	stmt, c := src[start:end], cursor-start
	if insideLiteral(stmt, c, d) {
		return Completion{Kind: CompleteNone, Start: cursor}
	}
	ws := c
	for ws > 0 && isWordByte(stmt[ws-1]) {
		ws--
	}
	out := Completion{Prefix: stmt[ws:c], Start: start + ws, Tables: tableUses(codeTokens(stmt, d))}
	before := codeTokens(stmt[:ws], d)
	if n := len(before); n >= 2 && isPunct(before[n-1], ".") && isName(before[n-2]) {
		out.Qualifier = before[n-2].text
		out.Kind = clauseKind(before[:n-2])
		if out.Kind == CompleteKeyword {
			out.Kind = CompleteColumn // "x." outside a known clause: x is most likely a table
		}
		return out
	}
	if n := len(before); n > 0 && endsOperand(before[n-1], d) {
		out.Kind = CompleteKeyword
		return out
	}
	out.Kind = clauseKind(before)
	return out
}

// statementAround returns the statement the cursor is in. Split trims
// trailing whitespace, so a cursor after a statement's last word (and only
// whitespace) still belongs to it; after a delimiter a new, empty
// statement starts at the cursor.
func statementAround(src string, cursor int, d Dialect) (start, end int) {
	stmts := Split(src, d)
	for i := len(stmts) - 1; i >= 0; i-- {
		s := stmts[i]
		switch {
		case s.Start > cursor:
			continue
		case cursor <= s.End:
			return s.Start, s.End
		case strings.TrimSpace(src[s.End:cursor]) == "":
			return s.Start, cursor
		}
		return cursor, cursor
	}
	return cursor, cursor
}

// insideLiteral reports whether offset c of src is inside a string, a
// quoted identifier or a comment.
func insideLiteral(src string, c int, d Dialect) bool {
	for i := 0; i < len(src) && i < c; {
		if isSpace(src[i]) {
			i++
			continue
		}
		t := lex(src, i, d)
		if t.kind == tokString || t.kind == tokIdent || t.kind == tokComment {
			if c > t.pos && c < t.end || c == t.end && !closed(src[t.pos:t.end]) {
				return true
			}
		}
		i = t.end
	}
	return false
}

// closed reports whether a string, quoted identifier or comment ends with
// its closing delimiter. A line comment runs to the end of its line, so a
// cursor at its end is still inside it.
func closed(raw string) bool {
	switch {
	case strings.HasPrefix(raw, "--"), strings.HasPrefix(raw, "#"):
		return false
	case strings.HasPrefix(raw, "/*"):
		return len(raw) >= 4 && strings.HasSuffix(raw, "*/")
	case strings.HasPrefix(raw, "$"):
		tag := raw[:strings.IndexByte(raw[1:], '$')+2]
		return len(raw) >= 2*len(tag) && strings.HasSuffix(raw, tag)
	case raw[0] == 'E' || raw[0] == 'e':
		raw = raw[1:]
	}
	return len(raw) >= 2 && raw[len(raw)-1] == raw[0]
}

// endsOperand reports whether t ends a value or name, after which the next
// word is most likely a keyword ("SELECT id |", "FROM users |").
func endsOperand(t token, d Dialect) bool {
	switch t.kind {
	case tokIdent, tokString:
		return true
	case tokPunct:
		return t.text == ")" || t.text == "*"
	case tokWord:
		return !isKeyword(t.text, d)
	}
	return false
}

// clauseKind looks back for the clause the cursor is in.
func clauseKind(toks []token) CompleteKind {
	for i := len(toks) - 1; i >= 0; i-- {
		if toks[i].kind != tokWord {
			continue
		}
		switch w := upper(toks[i]); {
		case tableClause[w]:
			if w == "INTO" && hasPunct(toks[i+1:], "(") {
				return CompleteColumn // INSERT INTO t (col, ...
			}
			return CompleteTable
		case columnClause[w]:
			return CompleteColumn
		case keywordClause[w]:
			return CompleteKeyword
		}
	}
	return CompleteKeyword
}

func hasPunct(toks []token, p string) bool {
	for _, t := range toks {
		if isPunct(t, p) {
			return true
		}
	}
	return false
}

// tableUses lists the tables after FROM (and its comma list), JOIN, UPDATE
// and INTO.
func tableUses(toks []token) []TableUse {
	var out []TableUse
	for i, t := range toks {
		if t.kind != tokWord {
			continue
		}
		w := upper(t)
		if w != "FROM" && w != "JOIN" && w != "UPDATE" && w != "INTO" {
			continue
		}
		j := i + 1
		for {
			u, next, ok := tableUse(toks, j)
			if !ok {
				break
			}
			out = append(out, u)
			if w != "FROM" || next >= len(toks) || !isPunct(toks[next], ",") {
				break
			}
			j = next + 1
		}
	}
	return out
}

func stopWord(t token) bool { return t.kind == tokWord && aliasStop[upper(t)] }

// tableUse reads "[qualifier.]name [[AS] alias]" at j.
func tableUse(toks []token, j int) (TableUse, int, bool) {
	for j < len(toks) && toks[j].kind == tokWord && modifiers[upper(toks[j])] {
		j++
	}
	if j >= len(toks) || !isName(toks[j]) || stopWord(toks[j]) {
		return TableUse{}, j, false
	}
	parts := []string{toks[j].text}
	j++
	for j+1 < len(toks) && isPunct(toks[j], ".") && isName(toks[j+1]) {
		parts = append(parts, toks[j+1].text)
		j += 2
	}
	u := TableUse{Name: parts[len(parts)-1]}
	if len(parts) > 1 {
		u.Qualifier = parts[len(parts)-2]
	}
	if j < len(toks) && isWord(toks[j], "AS") {
		j++
	}
	if j < len(toks) && isName(toks[j]) && !stopWord(toks[j]) {
		u.Alias = toks[j].text
		j++
	}
	return u, j, true
}
```

```go
// Package highlight splits SQL into colored spans using Chroma.
package highlight

import (
	"github.com/alecthomas/chroma/v2"
	"github.com/alecthomas/chroma/v2/lexers"

	"github.com/shepherd-yun/sqlvim/internal/sqlx"
)

// Class is the color class of a span.
type Class int

const (
	Plain Class = iota
	Keyword
	Builtin // types and built-in functions
	String
	Number
	Comment
	Operator
)

// Span is a run of source text with one class; offsets are bytes.
type Span struct {
	Start, End int
	Class      Class
}

// Lexers are used from the UI goroutine only.
var sqlLexers = map[sqlx.Dialect]chroma.Lexer{
	sqlx.MySQL:    lexer("mysql"),
	sqlx.Postgres: lexer("postgresql"),
}

func lexer(name string) chroma.Lexer {
	if l := lexers.Get(name); l != nil {
		return chroma.Coalesce(l)
	}
	return nil
}

// SQL classifies src. The spans cover src exactly, in order. If Chroma
// cannot reproduce the text token by token, all of it is Plain.
func SQL(src string, d sqlx.Dialect) []Span {
	if src == "" {
		return nil
	}
	plain := []Span{{Start: 0, End: len(src), Class: Plain}}
	l := sqlLexers[d]
	if l == nil {
		return plain
	}
	it, err := l.Tokenise(&chroma.TokeniseOptions{State: "root"}, src)
	if err != nil {
		return plain
	}
	var out []Span
	off := 0
	for t := it(); t != chroma.EOF; t = it() {
		end := off + len(t.Value)
		if end > len(src) || src[off:end] != t.Value {
			return plain
		}
		if end == off {
			continue
		}
		c := classOf(t.Type)
		if n := len(out); n > 0 && out[n-1].Class == c {
			out[n-1].End = end
		} else {
			out = append(out, Span{Start: off, End: end, Class: c})
		}
		off = end
	}
	if off < len(src) {
		out = append(out, Span{Start: off, End: len(src), Class: Plain})
	}
	return out
}

func classOf(t chroma.TokenType) Class {
	switch {
	case t == chroma.OperatorWord: // AND, OR, NOT
		return Keyword
	case t == chroma.KeywordType, t == chroma.NameBuiltin, t == chroma.NameFunction:
		return Builtin
	case t == chroma.LiteralStringName: // PostgreSQL "quoted identifiers"
		return Plain
	case t.InCategory(chroma.Keyword):
		return Keyword
	case t.InCategory(chroma.Comment):
		return Comment
	case t.InSubCategory(chroma.LiteralString):
		return String
	case t.InSubCategory(chroma.LiteralNumber):
		return Number
	case t.InCategory(chroma.Operator):
		return Operator
	}
	return Plain
}
```

```go
	highlight.Keyword:  lipgloss.NewStyle().Bold(true).Foreground(ColorFocus),
	highlight.Builtin:  lipgloss.NewStyle().Foreground(lipgloss.Color("6")),

	highlight.Operator: lipgloss.NewStyle().Foreground(lipgloss.Color("5")),
}

// Syntax is the style of a highlight class.
func Syntax(c highlight.Class) lipgloss.Style { return syntax[c] }

// HighlightLines colors src by spans and splits it into lines. src must be
// free of control characters other than \n (see textutil.SanitizeText).
func HighlightLines(src string, spans []highlight.Span) []string {
	var lines []string
	var b strings.Builder
	for _, s := range spans {
		for i, part := range strings.Split(src[s.Start:s.End], "\n") {
			if i > 0 {
				lines = append(lines, b.String())
				b.Reset()
			}
			switch {
			case part == "":
			case s.Class == highlight.Plain:
				b.WriteString(part)
			default:
				b.WriteString(Syntax(s.Class).Render(part))
			}
		}
	}
	return append(lines, b.String())
}
```

```go
package editor

import (
	"fmt"
	"strconv"
	"strings"
	"unicode"

	"github.com/charmbracelet/x/ansi"

	"github.com/shepherd-yun/sqlvim/internal/ui/highlight"
	"github.com/shepherd-yun/sqlvim/internal/ui/textutil"
	"github.com/shepherd-yun/sqlvim/internal/ui/theme"
)

const (
	tabWidth    = 4
	placeholder = "i to write SQL · enter runs the statement under the cursor"
)

// cell is one rune as drawn.
type cell struct {
	text  string
	width int
	class highlight.Class
}

func cellOf(r rune, class highlight.Class) cell {
	if r == '\t' {
		return cell{text: strings.Repeat(" ", tabWidth), width: tabWidth, class: class}
	}
	s := string(r)
	w := ansi.StringWidth(s)
	if unicode.IsControl(r) || w == 0 {
		return cell{text: "�", width: 1, class: class}
	}
	return cell{text: s, width: w, class: class}
}

// row is one screen row: cells[from:to] of a logical line.
type row struct {
	line     int
	first    bool // the line's first row; it shows the line number
	cells    []cell
	from, to int
	cursor   int // index into cells drawn as the cursor (to = after the text), or -1
}

// classes returns the highlight class of every byte of text, memoized.
func (m *Model) classes(text string) []highlight.Class {
	if m.hlClasses != nil && text == m.hlText {
		return m.hlClasses
	}
	cls := make([]highlight.Class, len(text))
	if m.highlight != nil {
		for _, s := range m.highlight(text) {
			for i := max(s.Start, 0); i < s.End && i < len(cls); i++ {
				cls[i] = s.Class
			}
		}
	}
	m.hlText, m.hlClasses = text, cls
	return cls
}

// wrap splits cells into runs no wider than width; a wide rune that does
// not fit starts the next run. There is always at least one run.
func wrap(cells []cell, width int) [][2]int {
	var runs [][2]int
	from, w := 0, 0
	for i, c := range cells {
		if w+c.width > width && i > from {
			runs = append(runs, [2]int{from, i})
			from, w = i, 0
		}
		w += c.width
	}
	return append(runs, [2]int{from, len(cells)})
}

func widthOf(cells []cell) int {
	w := 0
	for _, c := range cells {
		w += c.width
	}
	return w
}

// View draws the visible rows: line numbers, colored text, block cursor.
func (m *Model) View() string {
	if m.height <= 0 || m.width <= 0 {
		return ""
	}
	text := m.ta.Value()
	lines := strings.Split(text, "\n")
	digits := max(len(strconv.Itoa(len(lines))), 2)
	gutter := digits + 1
	textW := max(m.width-gutter, 1)
	cls := m.classes(text)
	curLine, curCol := m.ta.Line(), m.ta.Column()

	var rows []row
	curRow, curX := 0, 0
	off := 0
	for i, l := range lines {
		cells := make([]cell, 0, len(l))
		for j, r := range l {
			cells = append(cells, cellOf(r, cls[off+j]))
		}
		off += len(l) + 1
		runs := wrap(cells, textW)
		for k, run := range runs {
			rw := row{line: i, first: k == 0, cells: cells, from: run[0], to: run[1], cursor: -1}
			last := k == len(runs)-1
			if c := min(curCol, len(cells)); i == curLine && c >= run[0] && (c < run[1] || last && c == run[1]) {
				x := widthOf(cells[run[0]:c])
				if x >= textW { // after a full last row: the cursor gets a row of its own
					rows = append(rows, rw)
					rw = row{line: i, cells: cells, from: c, to: c}
					x = 0
				}
				rw.cursor, curRow, curX = c, len(rows), x
			}
			rows = append(rows, rw)
		}
	}

	if curRow < m.top {
		m.top = curRow
	}
	if curRow >= m.top+m.height {
		m.top = curRow - m.height + 1
	}
	m.top = textutil.Clamp(m.top, 0, max(len(rows)-1, 0))
	m.curX, m.curY = gutter+curX, curRow-m.top

	out := make([]string, 0, m.height)
	for r := m.top; r < len(rows) && len(out) < m.height; r++ {
		out = append(out, drawRow(rows[r], digits, textW, curLine, text == ""))
	}
	for len(out) < m.height {
		out = append(out, strings.Repeat(" ", m.width))
	}
	return strings.Join(out, "\n")
}

func drawRow(r row, digits, textW, curLine int, empty bool) string {
	gutter := strings.Repeat(" ", digits+1)
	if r.first {
		num := fmt.Sprintf("%*d ", digits, r.line+1)
		if r.line == curLine {
			gutter = num
		} else {
			gutter = theme.Muted.Render(num)
		}
	}
	var b, run strings.Builder
	class := highlight.Plain
	flush := func() {
		if run.Len() == 0 {
			return
		}
		if class == highlight.Plain {
			b.WriteString(run.String())
		} else {
			b.WriteString(theme.Syntax(class).Render(run.String()))
		}
		run.Reset()
	}
	for i := r.from; i < r.to; i++ {
		c := r.cells[i]
		if i == r.cursor {
			flush()
			b.WriteString(theme.Selected.Render(c.text))
			continue
		}
		if c.class != class {
			flush()
			class = c.class
		}
		run.WriteString(c.text)
	}
	flush()
	if r.cursor == r.to {
		b.WriteString(theme.Selected.Render(" "))
		if empty {
			b.WriteString(theme.Muted.Render(placeholder))
		}
	}
	return gutter + textutil.Fit(b.String(), textW)
}
```

```go
// Package complete is the console's completion popup.
package complete

import (
	"fmt"
	"strings"

	"github.com/charmbracelet/x/ansi"
	"github.com/sahilm/fuzzy"

	"github.com/shepherd-yun/sqlvim/internal/ui/textutil"
	"github.com/shepherd-yun/sqlvim/internal/ui/theme"
)

// Kind tags a candidate.
type Kind int

const (
	Keyword Kind = iota
	Table
	View
	Column
	Namespace // a database (MySQL) or schema (PostgreSQL)
)

var tags = [...]string{"kw", "table", "view", "col", "ns"}

// Candidate is one completion.
type Candidate struct {
	Text   string // inserted text, quoted if needed
	Label  string // the name as shown and matched
	Kind   Kind
	Detail string // e.g. a column type
}

// Rank keeps the candidates whose label starts with prefix (ignoring case)
// in their given order, then the others that match it fuzzily, best first;
// at most limit. An empty prefix keeps every candidate.
func Rank(prefix string, cands []Candidate, limit int) []Candidate {
	var out []Candidate
	if prefix == "" {
		out = append(out, cands...)
	} else {
		p := strings.ToLower(prefix)
		var rest []int
		for i, c := range cands {
			if strings.HasPrefix(strings.ToLower(c.Label), p) {
				out = append(out, c)
			} else {
				rest = append(rest, i)
			}
		}
		labels := make([]string, len(rest))
		for i, k := range rest {
			labels[i] = cands[k].Label
		}
		for _, m := range fuzzy.Find(prefix, labels) {
			out = append(out, cands[rest[m.Index]])
		}
	}
	if len(out) > limit {
		out = out[:limit]
	}
	return out
}

const maxRows = 10

// Model is the popup: candidates and the selected one (-1 before the user
// picks one).
type Model struct {
	items  []Candidate
	sel    int
	offset int
}

// New opens a popup on items with nothing selected.
func New(items []Candidate) *Model { return &Model{items: items, sel: -1} }

func (m *Model) Len() int { return len(m.items) }

// Next selects the next candidate, wrapping around.
func (m *Model) Next() {
	if n := len(m.items); n > 0 {
		m.sel = (m.sel + 1) % n
	}
}

// Prev selects the previous candidate, wrapping around.
func (m *Model) Prev() {
	if n := len(m.items); n > 0 {
		if m.sel <= 0 {
			m.sel = n - 1
		} else {
			m.sel--
		}
	}
}

// Selected returns the selected candidate, if any.
func (m *Model) Selected() (Candidate, bool) {
	if m.sel < 0 || m.sel >= len(m.items) {
		return Candidate{}, false
	}
	return m.items[m.sel], true
}

// Chosen is the candidate to insert: the selected one, else the first.
func (m *Model) Chosen() Candidate {
	if c, ok := m.Selected(); ok {
		return c
	}
	if len(m.items) == 0 {
		return Candidate{}
	}
	return m.items[0]
}

func pad(s string, w int) string { return s + strings.Repeat(" ", max(w-ansi.StringWidth(s), 0)) }

// View draws the popup with a border, at most maxW wide and maxH tall.
func (m *Model) View(maxW, maxH int) string {
	h := min(len(m.items), maxRows, max(maxH-2, 1))
	if m.sel >= 0 {
		if m.sel < m.offset {
			m.offset = m.sel
		}
		if m.sel >= m.offset+h {
			m.offset = m.sel - h + 1
		}
	}
	labelW, detailW := 0, 0
	for _, c := range m.items {
		labelW = max(labelW, ansi.StringWidth(textutil.Sanitize(c.Label)))
		detailW = max(detailW, ansi.StringWidth(textutil.Sanitize(c.Detail)))
	}
	inner := 6 + labelW
	if detailW > 0 {
		inner += 2 + detailW
	}
	w := max(min(inner+2, maxW), 2)
	lines := make([]string, 0, h)
	for i := m.offset; i < len(m.items) && i < m.offset+h; i++ {
		c := m.items[i]
		tag := fmt.Sprintf("%-5s ", tags[c.Kind])
		label := pad(textutil.Sanitize(c.Label), labelW)
		detail := ""
		if c.Detail != "" {
			detail = "  " + textutil.Sanitize(c.Detail)
		}
		if i == m.sel {
			lines = append(lines, theme.Selected.Render(textutil.Fit(tag+label+detail, w-2)))
			continue
		}
		lines = append(lines, textutil.Fit(theme.Muted.Render(tag)+label+theme.Muted.Render(detail), w-2))
	}
	return theme.Box("", strings.Join(lines, "\n"), w, h+2, true)
}
```

```go
package ui

import (
	"context"
	"log/slog"
	"time"

	tea "charm.land/bubbletea/v2"

	"github.com/shepherd-yun/sqlvim/internal/db"

)

// catalogTimeout bounds one catalog load.
const catalogTimeout = 60 * time.Second

type metaLoadedMsg struct {
	key  meta.Key
	gen  int
	snap *meta.Snapshot
	err  error
}

// metaStaleMsg says a console ran DDL, so the catalog of its database changed.
type metaStaleMsg struct{ conn, database string }

// metaKeyFor is the key of the catalog that covers database on conn: a
// MySQL catalog covers the server, a PostgreSQL one a single database.
func metaKeyFor(b Backend, conn, database string) (meta.Key, bool) {
	cfg, ok := b.Connection(conn)
	if !ok {
		return meta.Key{}, false
	}
	if cfg.Driver != "postgres" {
		return meta.Key{Conn: conn}, true
	}
	if database == "" {
		database = cfg.Database
	}
	if database == "" {
		database = "postgres"
	}
	return meta.Key{Conn: conn, Database: database}, true
}

func loadMeta(b Backend, k meta.Key, gen int) tea.Cmd {
	return func() tea.Msg {
		ctx, cancel := context.WithTimeout(context.Background(), catalogTimeout)
		defer cancel()
		var snap *meta.Snapshot
		err := withConn(ctx, b, k.Conn, k.Database, func(c db.Conn) error {
			var err error
			snap, err = meta.Load(ctx, c.Meta(), k)
			return err
		})
		if err != nil {
			slog.Warn("load catalog", "conn", k.Conn, "database", k.Database, "err", err)
		}
		return metaLoadedMsg{key: k, gen: gen, snap: snap, err: err}
	}
}

// ensureMeta loads the catalog of database on conn in the background unless
// it was loaded (or tried) before. Failed loads wait for <space>r.
func (m *Model) ensureMeta(conn, database string) tea.Cmd {
	k, ok := metaKeyFor(m.backend, conn, database)
	if !ok {
		return nil
	}
	if _, st := m.catalogs.Get(k); st != meta.Missing {
		return nil
	}
	gen, ok := m.catalogs.Start(k)
	if !ok {
		return nil
	}
	return loadMeta(m.backend, k, gen)
}

// reloadMeta loads the catalog again; a load already running is superseded.
func (m *Model) reloadMeta(conn, database string) tea.Cmd {
	k, ok := metaKeyFor(m.backend, conn, database)
	if !ok {
		return nil
	}
	return loadMeta(m.backend, k, m.catalogs.Restart(k))
}

func (m *Model) metaLoaded(msg metaLoadedMsg) tea.Cmd {
	m.catalogs.Finish(msg.key, msg.gen, msg.snap, msg.err)
	return nil
}

// metaStale reloads a catalog that DDL changed, if it was ever loaded.
func (m *Model) metaStale(msg metaStaleMsg) tea.Cmd {
	k, ok := metaKeyFor(m.backend, msg.conn, msg.database)
	if !ok {
		return nil
	}
	if _, st := m.catalogs.Get(k); st == meta.Missing {
		return nil
	}
	return m.reloadMeta(msg.conn, msg.database)
}
```

（`metaLoadedMsg` 故意不实现 `connFailure`：后台加载失败不应把连接标成断开，也不弹密码框。）

```go
)

// maxCandidates bounds the completion popup.
const maxCandidates = 50

// defaultNamespace is where a console resolves unqualified table names:
// its database (MySQL; the configured one when the console has none), or
// its schema, else public (PostgreSQL).
func defaultNamespace(cfg config.Connection, key meta.Key, ns db.Namespace) db.Namespace {
	if cfg.Driver == "postgres" {
		schema := ns.Schema
		if schema == "" {
			schema = "public"
		}
		return db.Namespace{Database: key.Database, Schema: schema}
	}
	database := ns.Database
	if database == "" {
		database = cfg.Database
	}
	return db.Namespace{Database: database}
}

// popupKey handles the completion keys in INSERT mode; used reports that
// the key was consumed.
func (t *consoleTab) popupKey(key string) (cmd tea.Cmd, used bool) {
	if t.popup == nil {
		if key == "ctrl+n" || key == "ctrl+p" {
			t.suggest(true)
			return nil, true
		}
		return nil, false
	}
	switch key {
	case "ctrl+n", "tab":
		t.popup.Next()
	case "ctrl+p", "shift+tab":
		t.popup.Prev()
	case "ctrl+y":
		return t.acceptCompletion(), true
	case "esc":
		t.popup = nil
		t.editor.ExitInsert()
	case "enter":
		t.popup = nil
		return nil, false // the editor still gets the newline
	default:
		return nil, false
	}
	return nil, true
}

// suggest opens (or refreshes, or closes) the popup for the word at the
// cursor. Without force it opens only once a word is started or right
// after "qualifier.".
func (t *consoleTab) suggest(force bool) {
	t.popup = nil
	c := sqlx.Complete(t.editor.Value(), t.editor.Offset(), t.dialect)
	if c.Kind == sqlx.CompleteNone {
		return
	}
	if !force && c.Prefix == "" && c.Qualifier == "" {
		return
	}
	ranked := complete.Rank(c.Prefix, t.candidates(c), maxCandidates)
	if len(ranked) == 0 || !force && len(ranked) == 1 && strings.EqualFold(ranked[0].Label, c.Prefix) {
		return // nothing to offer, or the word is already complete
	}
	t.popup, t.popStart = complete.New(ranked), c.Start
}

func (t *consoleTab) candidates(c sqlx.Completion) []complete.Candidate {
	snap, _ := t.catalogs.Get(t.metaKey)
	var out []complete.Candidate
	switch c.Kind {
	case sqlx.CompleteTable:
		out = t.tableCandidates(snap, c.Qualifier)
	case sqlx.CompleteColumn:
		out = t.columnCandidates(snap, c)
	}
	if c.Qualifier == "" && c.Kind != sqlx.CompleteTable {
		out = append(out, keywordCandidates(c.Prefix, t.dialect)...)
	}
	return out
}

// qualified resolves the qualifier written before a table name.
func (t *consoleTab) qualified(q string) db.Namespace {
	switch {
	case q == "":
		return t.defNS
	case t.dialect == sqlx.Postgres:
		return db.Namespace{Database: t.defNS.Database, Schema: q}
	}
	return db.Namespace{Database: q}
}

func (t *consoleTab) tableCandidates(snap *meta.Snapshot, qualifier string) []complete.Candidate {
	if snap == nil {
		return nil
	}
	var out []complete.Candidate
	for _, tb := range snap.Tables(t.qualified(qualifier)) {
		kind := complete.Table
		if tb.Kind == db.TableKindView {
			kind = complete.View
		}
		out = append(out, complete.Candidate{Text: sqlx.QuoteIfNeeded(tb.Name, t.dialect), Label: tb.Name, Kind: kind})
	}
	if qualifier != "" {
		return out
	}
	for _, ns := range snap.Catalog.Namespaces {
		name := ns.Database
		if t.dialect == sqlx.Postgres {
			name = ns.Schema
		}
		out = append(out, complete.Candidate{Text: sqlx.QuoteIfNeeded(name, t.dialect), Label: name, Kind: complete.Namespace})
	}
	return out
}

func (t *consoleTab) columnCandidates(snap *meta.Snapshot, c sqlx.Completion) []complete.Candidate {
	if snap == nil {
		return nil
	}
	uses := c.Tables
	if c.Qualifier != "" {
		uses = nil
		for _, u := range c.Tables {
			if strings.EqualFold(u.Alias, c.Qualifier) || u.Alias == "" && strings.EqualFold(u.Name, c.Qualifier) {
				uses = append(uses, u)
			}
		}
		if len(uses) == 0 {
			uses = []sqlx.TableUse{{Name: c.Qualifier}}
		}
	}
	var out []complete.Candidate
	for _, u := range uses {
		tb, ok := snap.FindTable(t.qualified(u.Qualifier), u.Name)
		if !ok {
			continue
		}
		for _, col := range snap.Columns(db.TableRef{Namespace: tb.Namespace, Name: tb.Name}) {
			detail := col.Type
			if len(uses) > 1 {
				detail = tb.Name + " · " + col.Type
			}
			out = append(out, complete.Candidate{
				Text: sqlx.QuoteIfNeeded(col.Name, t.dialect), Label: col.Name, Kind: complete.Column, Detail: detail,
			})
		}
	}
	return out
}

// keywordCandidates offers keywords in the case the user is typing.
func keywordCandidates(prefix string, d sqlx.Dialect) []complete.Candidate {
	lower := strings.ToUpper(prefix) != prefix
	kws := sqlx.Keywords(d)
	out := make([]complete.Candidate, len(kws))
	for i, kw := range kws {
		if lower {
			kw = strings.ToLower(kw)
		}
		out[i] = complete.Candidate{Text: kw, Label: kw, Kind: complete.Keyword}
	}
	return out
}

func (t *consoleTab) acceptCompletion() tea.Cmd {
	c := t.popup.Chosen()
	t.popup = nil
	t.editor.ReplaceBeforeCursor(t.popStart, c.Text)
	return t.scheduleDraft()
}

// drawPopup draws the completion popup at the cursor: below it when it
// fits, otherwise above.
func (t *consoleTab) drawPopup(view string) string {
	if t.popup == nil || !t.CapturesInput() {
		return view
	}
	x, y := t.editor.CursorPos()
	box := t.popup.View(min(t.width, 60), min(t.height, 12))
	w, h := lipgloss.Width(box), lipgloss.Height(box)
	top := y + 1
	if top+h > t.height {
		top = max(y-h, 0)
	}
	return overlay.PlaceAt(view, box, min(x, max(t.width-w, 0)), top)
}
```

```go
// locateError moves the editor cursor to where the server says r failed,
// when the editor still holds the text that ran, and returns the status
// line for the error.
func (t *consoleTab) locateError(text string, r runner.Result) string {
	msg := errorText(r.Err)
	off, ok := db.ErrorOffset(r.Err)
	if !ok || r.Start < 0 || text == "" || text != t.editor.Value() {
		return msg
	}
	pos := min(r.Start+off, len(text))
	t.editor.SetCursorOffset(pos)
	t.onResults = false
	before := text[:pos]
	line := strings.Count(before, "\n") + 1
	col := utf8.RuneCountInString(before[strings.LastIndexByte(before, '\n')+1:]) + 1
	return fmt.Sprintf("line %d, col %d: %s", line, col, msg)
}
```

```go
package overlay

import (
	"fmt"
	"strings"

	tea "charm.land/bubbletea/v2"

	"github.com/shepherd-yun/sqlvim/internal/ui/textutil"
	"github.com/shepherd-yun/sqlvim/internal/ui/theme"
)

// SearchItem is one row of the global search.
type SearchItem struct {
	Kind  string // table, view, column, routine, schema, database
	Label string
	Where string
}

// SearchQueryMsg asks for the results of Text; the reply carries Gen.
type SearchQueryMsg struct {
	Text string
	Gen  int
}

// SearchPickMsg reports the chosen row; Structure is set for ctrl+s.
type SearchPickMsg struct {
	Index     int
	Structure bool
}

// Search is the <space><space> popup. The root model computes the results
// (asynchronously) and hands them back with SetResults.
type Search struct {
	query    field
	gen      int // generation of the current query
	answered int // generation of the results shown
	items    []SearchItem
	cur      int
	offset   int
	note     string
}

// NewSearch opens an empty search; note explains missing results.
func NewSearch(note string) *Search { return &Search{note: note} }

func (s *Search) HandleKey(msg tea.KeyPressMsg) (Overlay, tea.Cmd) {
	switch msg.String() {
	case "esc":
		return nil, nil
	case "enter", "ctrl+s":
		if len(s.items) == 0 {
			return s, nil
		}
		return nil, emit(SearchPickMsg{Index: s.cur, Structure: msg.String() == "ctrl+s"})
	case "down", "ctrl+n":
		s.cur = textutil.Clamp(s.cur+1, 0, len(s.items)-1)
	case "up", "ctrl+p":
		s.cur = textutil.Clamp(s.cur-1, 0, len(s.items)-1)
	default:
		before := s.query.String()
		s.query.handle(msg)
		if s.query.String() != before {
			text, gen := s.Requery()
			return s, emit(SearchQueryMsg{Text: text, Gen: gen})
		}
	}
	return s, nil
}

// Requery starts a new generation for the current text and returns both.
func (s *Search) Requery() (string, int) {
	s.gen++
	return s.query.String(), s.gen
}

// SetResults shows the results of generation gen; it reports false (and
// changes nothing) for results of an older query.
func (s *Search) SetResults(gen int, items []SearchItem) bool {
	if gen != s.gen {
		return false
	}
	s.items, s.answered, s.cur, s.offset = items, gen, 0, 0
	return true
}

		s.offset = s.cur

		s.offset = s.cur - listH + 1

	case s.query.Len() == 0:
		status = "tables, views, columns, routines, schemas, databases · start with @ to search every connection"
	case s.answered != s.gen:
		status = "searching…"
	case len(s.items) == 0:
		status = "(no matches)"
	default:
		status = fmt.Sprintf("%d matches", len(s.items))
	}

		"> " + textutil.Sanitize(s.query.String()) + "█",
		theme.Muted.Render(textutil.Fit(status, w-2)),
	}
	for i := s.offset; i < len(s.items) && i < s.offset+listH; i++ {
		it := s.items[i]
		tag := fmt.Sprintf("%-9s", it.Kind)
		label, where := textutil.Sanitize(it.Label), textutil.Sanitize(it.Where)
		if i == s.cur {
			lines = append(lines, theme.Selected.Render(textutil.Fit(tag+label+"  "+where, w-2)))

		footer = s.note + " · " + footer

		theme.Muted.Render(textutil.Fit(textutil.Sanitize(footer), w-2))
```

```go
// RevealResult says how far Reveal got.
type RevealResult int

const (
	Revealed  RevealResult = iota // the whole path is expanded and its end selected
	NeedsLoad                     // the returned node was marked loading: load its children, then call Reveal again
	Waiting                       // a node on the path is loading already: call Reveal again when it is done
	NotFound                      // the connection or a name on the path does not exist
)

// Reveal expands the tree of conn along path (database, then schema) and
// selects the deepest node it reaches.
func (m *Model) Reveal(conn string, path []string) (*Node, RevealResult) {
	var n *Node
	for _, r := range m.roots {
		if r.Conn == conn {
			n = r
		}
	}
	if n == nil {
		return nil, NotFound
	}
	for _, name := range path {
		m.selected = n
		switch {
		case n.Loading:
			return nil, Waiting
		case !n.Loaded:
			m.StartLoad(n)
			return n, NeedsLoad
		}
		n.Expanded = true
		var next *Node
		for _, c := range n.Children {
			if c.Name == name {
				next = c
				break
			}
		}
		if next == nil {
			return nil, NotFound
		}
		n = next
	}
	m.selected = n
	return nil, Revealed
}
```

```go
import (
	"context"
	"strings"

	tea "charm.land/bubbletea/v2"

	"github.com/shepherd-yun/sqlvim/internal/db"
	"github.com/shepherd-yun/sqlvim/internal/meta"
	"github.com/shepherd-yun/sqlvim/internal/ui/overlay"
	"github.com/shepherd-yun/sqlvim/internal/ui/panes/tree"

// searchLimit bounds the global search results.
const searchLimit = 200

type searchResultsMsg struct {
	gen  int
	hits []meta.Hit
	all  bool // the results span every connection
}

type routineLoadedMsg struct {
	conn    string
	routine db.Routine
	ddl     string
	err     error
}

func (m routineLoadedMsg) failure() (string, error) { return m.conn, m.err }

// revealTarget is a tree path being opened for a search result.
type revealTarget struct {
	conn string
	path []string
}

// openSearch shows the <space><space> popup for the connection in context.
func (m *Model) openSearch() tea.Cmd {
	conn, ns := m.contextNamespace()
	m.searchConn, m.searchHits = conn, nil
	m.searchKey, _ = metaKeyFor(m.backend, conn, ns.Database)
	var cmd tea.Cmd
	if conn != "" {
		cmd = m.ensureMeta(conn, ns.Database)
	}
	m.overlay = overlay.NewSearch(m.searchNote())
	return cmd
}

// searchNote explains missing results: metadata loading or failed.
func (m *Model) searchNote() string {
	if m.searchConn == "" {
		return ""
	}
	switch _, st := m.catalogs.Get(m.searchKey); st {
	case meta.Loading:
		return "loading metadata of " + m.searchConn + "…"
	case meta.Failed:
		return "metadata of " + m.searchConn + " failed: " + m.catalogs.Err(m.searchKey).Error() + " · <space>r retries"
	}
	return ""
}

// runSearch matches text in a command. A leading @, or no connection in
// context, searches the catalogs of every connection.
func (m *Model) runSearch(text string, gen int) tea.Cmd {
	all := m.searchConn == "" || strings.HasPrefix(text, "@")
	conn := m.searchConn
	if all {
		conn = ""
	}
	snaps := m.catalogs.Snapshots(conn)
	q := strings.TrimPrefix(text, "@")
	return func() tea.Msg {
		return searchResultsMsg{gen: gen, hits: meta.Search(snaps, q, searchLimit), all: all}
	}
}

func (m *Model) searchResults(msg searchResultsMsg) {
	s, ok := m.overlay.(*overlay.Search)
	if !ok {
		return
	}
	items := make([]overlay.SearchItem, len(msg.hits))
	for i, h := range msg.hits {
		items[i] = searchItem(h, msg.all)
	}
	if s.SetResults(msg.gen, items) {
		m.searchHits = msg.hits
	}
}

func searchItem(h meta.Hit, all bool) overlay.SearchItem {
	var where []string
	if all {
		where = append(where, h.Conn)
	}
	switch h.Kind {
	case meta.ItemDatabase:
	case meta.ItemSchema:
		where = append(where, h.NS.Database)
	default:
		for _, p := range []string{h.NS.Database, h.NS.Schema} {
			if p != "" {
				where = append(where, p)
			}
		}
	}
	w := strings.Join(where, "/")
	if h.Detail != "" {
		if w != "" {
			w += " · "
		}
		w += h.Detail
	}
	return overlay.SearchItem{Kind: h.Kind.String(), Label: h.Path, Where: w}
}

// searchPicked opens a result: a table's data (or structure with ctrl+s),
// a column's table with the cursor on the column, a routine's definition,
// or a database or schema in the tree.
func (m *Model) searchPicked(msg overlay.SearchPickMsg) tea.Cmd {
	if msg.Index < 0 || msg.Index >= len(m.searchHits) {
		return nil
	}
	h := m.searchHits[msg.Index]
	switch h.Kind {
	case meta.ItemTable, meta.ItemView, meta.ItemColumn:
		ref := db.TableRef{Namespace: h.NS, Name: h.Table}
		if msg.Structure {
			return m.openStructure(h.Conn, ref)
		}
		cmd := m.openData(h.Conn, ref)
		if t, ok := m.activeTab().(*dataTab); ok && h.Kind == meta.ItemColumn {
			t.focusColumn(h.Name)
		}
		return cmd
	case meta.ItemRoutine:
		return loadRoutine(m.backend, h.Conn, h.Routine)
	case meta.ItemDatabase:
		return m.reveal(h.Conn, []string{h.NS.Database})
	case meta.ItemSchema:
		return m.reveal(h.Conn, []string{h.NS.Database, h.NS.Schema})
	}
	return nil
}

func loadRoutine(b Backend, conn string, r db.Routine) tea.Cmd {
	return func() tea.Msg {
		ctx, cancel := context.WithTimeout(context.Background(), loadTimeout)
		defer cancel()
		var ddl string
		err := withConn(ctx, b, conn, r.Namespace.Database, func(c db.Conn) error {
			var err error
			ddl, err = c.Meta().RoutineDDL(ctx, r)
			return err
		})
		return routineLoadedMsg{conn: conn, routine: r, ddl: ddl, err: err}
	}
}

func (m *Model) routineLoaded(msg routineLoadedMsg) {
	if msg.err != nil {
		m.setStatus(msg.routine.Name+": "+msg.err.Error(), true)
		return
	}
	m.overlay = overlay.NewDetail(msg.routine.Name, msg.ddl)
}

// reveal expands the tree along path and selects its end; children that
// are not loaded yet are loaded on the way (continueReveal resumes).
func (m *Model) reveal(conn string, path []string) tea.Cmd {
	m.setFocus(focusTree)
	m.revealing = nil
	n, res := m.tree.Reveal(conn, path)
	switch res {
	case tree.NeedsLoad:
		m.revealing = &revealTarget{conn: conn, path: path}
		return loadChildren(m.backend, n)
	case tree.Waiting:
		m.revealing = &revealTarget{conn: conn, path: path}
	case tree.NotFound:
		m.setStatus(strings.Join(path, "/")+" is not in the tree of "+conn, true)
	}
	return nil
}

// continueReveal resumes a reveal once children of its connection loaded.
func (m *Model) continueReveal(msg childrenLoadedMsg) tea.Cmd {
	r := m.revealing
	if r == nil || r.conn != msg.node.Conn {
		return nil
	}
	if msg.err != nil {
		m.revealing = nil
		return nil
	}
	return m.reveal(r.conn, r.path)
}
```

```go
package ui

import (
	"fmt"
	"log/slog"
	"time"

	tea "charm.land/bubbletea/v2"

	"github.com/shepherd-yun/sqlvim/internal/db"
	"github.com/shepherd-yun/sqlvim/internal/history"
	"github.com/shepherd-yun/sqlvim/internal/ui/overlay"
)

// recentLimit bounds the <space>e list.
const recentLimit = 100

type (
	recentLoadedMsg struct {
		items []history.Recent
		err   error
	}
	recentPickedMsg struct{ r history.Recent }
)

// recordRecent saves that r was opened now.
func recordRecent(st Store, r history.Recent) tea.Cmd {
	r.Time = time.Now()
	return func() tea.Msg {
		if err := st.AddRecent(r); err != nil {
			slog.Warn("save recent", "err", err)
		}
		return nil
	}
}

func loadRecent(st Store) tea.Cmd {
	return func() tea.Msg {
		items, err := st.Recent(recentLimit)
		return recentLoadedMsg{items: items, err: err}
	}
}

var recentKinds = map[string]string{
	history.RecentData:      "data",
	history.RecentStructure: "struct",
	history.RecentConsole:   "console",
}

func recentLabel(r history.Recent) string {
	path := r.Conn
	for _, p := range []string{r.Database, r.Schema, r.Name} {
		if p != "" {
			path += "/" + p
		}
	}
	return fmt.Sprintf("%-8s %s  %s", recentKinds[r.Kind], path, r.Time.Local().Format("01-02 15:04"))
}

func (m *Model) recentLoaded(msg recentLoadedMsg) {
	switch {
	case msg.err != nil:
		m.setStatus("recent: "+msg.err.Error(), true)
	case len(msg.items) == 0:
		m.setStatus("nothing opened yet", false)
	default:
		labels := make([]string, len(msg.items))
		for i, r := range msg.items {
			labels[i] = recentLabel(r)
		}
		items := msg.items
		m.overlay = overlay.NewPicker("Recent", labels, func(i int) tea.Msg { return recentPickedMsg{r: items[i]} })
	}
}

// openRecent reopens (or switches to) a recent tab.
func (m *Model) openRecent(r history.Recent) tea.Cmd {
	if _, ok := m.backend.Connection(r.Conn); !ok {
		m.setStatus("connection "+r.Conn+" no longer exists", true)
		return nil
	}
	ns := db.Namespace{Database: r.Database, Schema: r.Schema}
	switch r.Kind {
	case history.RecentData:
		return m.openData(r.Conn, db.TableRef{Namespace: ns, Name: r.Name})
	case history.RecentStructure:
		return m.openStructure(r.Conn, db.TableRef{Namespace: ns, Name: r.Name})
	case history.RecentConsole:
		return m.openConsole(r.Conn, ns)
	}
	return nil
}
```

```go
	touch := recordRecent(m.store, rec)
	for i, t := range m.tabs {
		if t.Key() == key {
			m.gotoTab(i)
			return touch
		}
	}

	m.tabs = append(m.tabs, t)

	m.layout()

}
```

```markdown
## Search and completion

sqlvim reads each connection's catalog (tables, views, columns, routines) in the
background the first time you use it — the whole server for MySQL, one database at a time
for PostgreSQL — and keeps it in memory. `<Space>r` reloads it; running DDL in a console
reloads it automatically.

In the console, completion pops up as you type: tables after `FROM`/`JOIN`/`UPDATE`/`INTO`,
columns of the statement's tables (and of `alias.`), keywords elsewhere. Names that need
quoting (`order`, `MixedCase` on PostgreSQL) are inserted quoted. When a statement fails
with a syntax error, the cursor jumps to where the server says the error is.
```
