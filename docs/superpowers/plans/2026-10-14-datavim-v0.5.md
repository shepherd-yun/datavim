# datavim v0.5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 datavim v0.5「内置 vim 编辑器」：用纯逻辑包 `internal/ui/vimedit` 取代控制台里的 Bubbles textarea，支持 NORMAL / INSERT / VISUAL / V-LINE 四种模式、spec §5.5 列出的全部 motion（`h j k l w b e W B E 0 ^ $ gg G f F t T % { }`）、operator（`d c y > <`）与 text object（`iw aw i" a" i( a(` 等）的组合、`x p P o O u Ctrl-r . dd yy cc`、计数前缀、寄存器 `"a`–`"z` 与映射系统剪贴板的 `"+`；VISUAL 模式下 `Enter` 执行选中内容（spec §5.4）；`<Space>v` 照旧交给 `$EDITOR`。

**Architecture:** `vimedit` 不依赖终端：`buffer`（`[][]rune` 行 + 字节偏移换算）、`history`（按步撤销 / 重做）、纯函数式的 motion 与 text object、`Editor` 状态机（按键解析 → `cmd` → 执行），按键以 `vimedit.Key{Name, Text}` 进入，`Feed` 返回 `Result` 告诉宿主：键是否被用掉、要不要写 / 读系统剪贴板、要不要切 tab。`panes/editor` 改为包一层 `vimedit.Editor`，自绘视图照旧并加上 VISUAL 选区。控制台把 NORMAL / VISUAL 模式下的按键**先**交给编辑器（根 Model 新增 `keyTaker` 接口，只在没有挂起的 leader 序列时生效），编辑器不认识的键（`<Space>`、`:`、`Enter`、`R`、`Ctrl-j`…）再走 keymap；INSERT 模式沿用 `inputCapturer`。剪贴板读写、`gt`/`gT` 等副作用都在 `tea.Cmd` 里完成。

**Tech Stack:** v0.4 全部依赖；不新增依赖。`charm.land/bubbles/v2`（只有旧编辑器在用）在 `go mod tidy` 后从 `go.mod` 中移除。

**Spec:** `docs/superpowers/specs/2026-10-13-datavim-design.md`（§3.1 `vimedit`、§3.2 纯逻辑包可独立测试、§5.4 VISUAL 执行选中内容、§5.5 编辑器、§6.1 模式、§6.2 `1`–`9`、§9 vimedit 表格驱动测试、§10 v0.5 行）；前四版计划 `docs/superpowers/plans/2026-10-13-datavim-v0.1.md`、`…-v0.2.md`、`…-v0.3.md`、`docs/superpowers/plans/2026-10-14-datavim-v0.4.md`（其中的约定继续有效）。

## Global Constraints

- v0.1–v0.4 计划的 Global Constraints 全部继续有效（模块路径 `github.com/shepherd-yun/datavim`、XDG 目录、密码不落盘、日志不含密码、英文 UI 文案、UI 层不做 IO、Conventional Commits + attribution、集成测试 build tag `integration`、`Ctrl-c` 不退出、`Ctrl-c` 取消查询）。
- 不新增依赖；`go mod tidy` 移除 `charm.land/bubbles/v2` 与间接依赖 `github.com/atotto/clipboard`，其余依赖版本不变。
- `internal/ui/vimedit` 只依赖标准库（不 import Bubble Tea、不做 IO），按 spec §9 用表格驱动测试：初始文本与光标（测试里用 `|` 标出）+ 按键序列 → 期望文本、光标、模式。
- 按键名与 Bubble Tea `KeyPressMsg.String()` 一致（`"j"`、`"G"`、`"ctrl+r"`、`"esc"`、`"enter"`、`"space"`）；会输入文字的键另带 `Text`。
- **数字键（作者已决定）**：控制台编辑器在 NORMAL / VISUAL 模式下 `1`–`9` 是计数前缀（`0` 在已有计数后也是）；`gt` 下一个 tab、`gT` 上一个（可带计数）、`{n}gt` 跳到第 n 个 tab，都循环、并像 `1`–`9` 一样记入最近打开。树、表格、结构、控制台结果区里 `1`–`9` 照旧跳 tab。
- 控制台编辑器的按键归属：根 Model 没有挂起的按键序列时，NORMAL / VISUAL 模式的键先给 `vimedit`；它不用的键（空闲状态下的 `space`、`:`、`?`、`enter`、`R`、`M`、`ctrl+j`、`ctrl+h`、`ctrl+l`、`tab`、`shift+tab`、`ctrl+c`…）交给 keymap。编辑器正在等后续键时（如按了 `d`），任何键都由编辑器处理（不认识的键取消该命令）。INSERT 模式：补全弹框的键优先，然后 `ctrl+enter` / `ctrl+j` 执行、`ctrl+c` 取消，其余交给 `vimedit`（`esc` 回 NORMAL，弹框开着时第一个 `esc` 只关弹框，与 v0.4 一致）。
- 计数上限 `maxCount = 9999`；带计数的 `p` 最多插入 `maxPut = 16 << 20` 字节。
- 缩进：`>` / `<` 每次 4 个空格（`<` 也会去掉一个行首 tab，空行不缩进）；INSERT 模式 `tab` 插入 4 个空格；`o` / `O` / INSERT 模式 `enter` 沿用当前行的缩进（`enter` 只取光标前的那部分）。
- 撤销：一个 NORMAL 命令或一次 INSERT 会话（从进入到 `esc`）是一步；INSERT 模式里移动光标（方向键、`home`、`end`）开始新的一步；最多 `maxUndo = 1000` 步；`u` 后光标回到这一步之前的位置。加载草稿（`SetValue`）清空撤销历史；`$EDITOR` 改回的内容和从 SQL 历史插入的语句是可撤销的一步（`ReplaceAll`）。
- 寄存器：无名寄存器 `"`、`"a`–`"z`、`"+`（系统剪贴板）。`"+y…` / `"+d…` 用现有 `clipboard.Copy` 写入；`"+p` / `"+P` 本地 macOS 用 `pbpaste` 读取，否则发 OSC 52 读请求，终端的回答（`tea.ClipboardMsg`）交给当前控制台；回答到达前文本被改过就丢弃并在状态行提示。剪贴板内容以换行结尾时按行粘贴。
- `.` 重复上一个修改文本的 NORMAL 命令（包括它的 INSERT 会话里输入的内容、粘贴和补全）；`.` 前的计数替换原计数。
- VISUAL 模式 `Enter` 执行选中文本里的全部语句（`sqlx.Split` 后把偏移平移回整段文本，出错定位照常），并回到 NORMAL。
- 状态栏模式名：`NORMAL` / `INSERT` / `VISUAL` / `V-LINE`；控制台状态行显示正在输入的命令（如 `"a2d`）。
- 测试**绝不**碰真实系统剪贴板：`internal/ui` 测试替身在 `init` 里把读写剪贴板换成空操作。

`internal/ui/vimedit/buffer.go`：

```go
// Package vimedit is the console's vim editing engine: a text buffer with
// a cursor, modes, motions, operators, text objects, registers, undo and
// dot-repeat. It knows nothing about terminals: keys come in as Key values
// and the host (internal/ui/panes/editor) draws the text.
package vimedit

import (
	"slices"
	"strings"
	"unicode/utf8"
)

// Pos is a place in the text: a line and a rune column, both 0-based.
// Col may equal the line's length: the position of its line break.
type Pos struct{ Line, Col int }

func (p Pos) less(q Pos) bool { return p.Line < q.Line || p.Line == q.Line && p.Col < q.Col }

func order(a, b Pos) (Pos, Pos) {
	if b.less(a) {
		return b, a
	}
	return a, b
}

// buffer is the text as lines of runes; there is always at least one line.
type buffer struct {
	lines   [][]rune
	text    string // Text() cache, valid while !dirty
	dirty   bool
	version int // bumped by every change
}

func newBuffer(s string) buffer { return buffer{lines: splitLines(s), text: s} }

func splitLines(s string) [][]rune {
	parts := strings.Split(s, "\n")
	out := make([][]rune, len(parts))
	for i, p := range parts {
		out[i] = []rune(p)
	}
	return out
}

func (b *buffer) Text() string {
	if b.dirty {
		parts := make([]string, len(b.lines))
		for i, l := range b.lines {
			parts[i] = string(l)
		}
		b.text, b.dirty = strings.Join(parts, "\n"), false
	}
	return b.text
}

func (b *buffer) last() int           { return len(b.lines) - 1 }
func (b *buffer) lineLen(l int) int   { return len(b.lines[l]) }
func (b *buffer) empty(l int) bool    { return len(b.lines[l]) == 0 }
func (b *buffer) end() Pos            { return Pos{b.last(), b.lineLen(b.last())} }
func (b *buffer) lineEnd(l int) Pos   { return Pos{l, b.lineLen(l)} }
func (b *buffer) clampLine(l int) int { return min(max(l, 0), b.last()) }

// clamp keeps p inside the text; Col may reach the line's length.
func (b *buffer) clamp(p Pos) Pos {
	p.Line = b.clampLine(p.Line)
	p.Col = min(max(p.Col, 0), b.lineLen(p.Line))
	return p
}

func runeBytes(rs []rune) int {
	n := 0
	for _, r := range rs {
		n += utf8.RuneLen(r)
	}
	return n
}

// offset is p as a byte offset into Text().
func (b *buffer) offset(p Pos) int {
	p = b.clamp(p)
	off := 0
	for _, l := range b.lines[:p.Line] {
		off += runeBytes(l) + 1
	}
	return off + runeBytes(b.lines[p.Line][:p.Col])
}

// pos is the position of byte offset off (clamped; a byte inside a rune
// counts as that rune).
func (b *buffer) pos(off int) Pos {
	off = max(off, 0)
	for i, l := range b.lines {
		n := runeBytes(l)
		if off <= n || i == b.last() {
			col := 0
			for _, r := range l {
				if off <= 0 {
					break
				}
				off -= utf8.RuneLen(r)
				if off >= 0 {
					col++
				}
			}
			return Pos{i, col}
		}
		off -= n + 1
	}
	return b.end()
}

// slice is the text from from to to (exclusive).
func (b *buffer) slice(from, to Pos) string {
	from, to = order(b.clamp(from), b.clamp(to))
	if from.Line == to.Line {
		return string(b.lines[from.Line][from.Col:to.Col])
	}
	var s strings.Builder
	s.WriteString(string(b.lines[from.Line][from.Col:]))
	for l := from.Line + 1; l < to.Line; l++ {
		s.WriteByte('\n')
		s.WriteString(string(b.lines[l]))
	}
	s.WriteByte('\n')
	s.WriteString(string(b.lines[to.Line][:to.Col]))
	return s.String()
}

// replace puts s in place of the text from from to to and returns the
// position right after s.
func (b *buffer) replace(from, to Pos, s string) Pos {
	from, to = order(b.clamp(from), b.clamp(to))
	head := b.lines[from.Line][:from.Col]
	tail := b.lines[to.Line][to.Col:]
	ins := splitLines(s)
	ins[0] = append(slices.Clone(head), ins[0]...)
	last := len(ins) - 1
	end := Pos{from.Line + last, len(ins[last])}
	ins[last] = append(ins[last], tail...)
	b.lines = slices.Replace(b.lines, from.Line, to.Line+1, ins...)
	b.dirty = true
	b.version++
	return end
}

// after is where s ends when it is inserted at p.
func after(p Pos, s string) Pos {
	n := strings.Count(s, "\n")
	if n == 0 {
		return Pos{p.Line, p.Col + utf8.RuneCountInString(s)}
	}
	return Pos{p.Line + n, utf8.RuneCountInString(s[strings.LastIndexByte(s, '\n')+1:])}
}
```

```go
package vimedit

// maxUndo bounds the undo history.
const maxUndo = 1000

// edit is one replacement: at at, old was replaced by new.
type edit struct {
	at       Pos
	old, new string
}

// step is what one u undoes: the edits of one command or INSERT session.
type step struct {
	edits  []edit
	cursor Pos // the cursor before the step
}

// history records edits in steps for undo and redo.
type history struct {
	undo, redo []step
	open       *step
}

// record adds e to the open step, opening one (with the cursor before it)
// if needed. A new edit drops what could be redone.
func (h *history) record(e edit, cursor Pos) {
	h.redo = nil
	if h.open == nil {
		h.open = &step{cursor: cursor}
	}
	if n := len(h.open.edits); n > 0 {
		// typing: grow the previous insertion instead of adding an edit per key
		if last := &h.open.edits[n-1]; last.old == "" && e.old == "" && after(last.at, last.new) == e.at {
			last.new += e.new
			return
		}
	}
	h.open.edits = append(h.open.edits, e)
}

// commit closes the open step.
func (h *history) commit() {
	if h.open == nil {
		return
	}
	if len(h.open.edits) > 0 {
		h.undo = append(h.undo, *h.open)
		if over := len(h.undo) - maxUndo; over > 0 {
			h.undo = h.undo[over:]
		}
	}
	h.open = nil
}

func (h *history) reset() { *h = history{} }

// undoStep reverts the last step on b and returns where the cursor goes.
func (h *history) undoStep(b *buffer) (Pos, bool) {
	h.commit()
	if len(h.undo) == 0 {
		return Pos{}, false
	}
	s := h.undo[len(h.undo)-1]
	h.undo = h.undo[:len(h.undo)-1]
	for i := len(s.edits) - 1; i >= 0; i-- {
		e := s.edits[i]
		b.replace(e.at, after(e.at, e.new), e.old)
	}
	h.redo = append(h.redo, s)
	return s.cursor, true
}

// redoStep applies the last undone step again and returns where the
// cursor goes: where its first edit starts.
func (h *history) redoStep(b *buffer) (Pos, bool) {
	if len(h.redo) == 0 {
		return Pos{}, false
	}
	s := h.redo[len(h.redo)-1]
	h.redo = h.redo[:len(h.redo)-1]
	for _, e := range s.edits {
		b.replace(e.at, after(e.at, e.old), e.new)
	}
	h.undo = append(h.undo, s)
	return s.edits[0].at, true
}
```

```go
package vimedit

import (
	"strings"
	"unicode"
)

// Character classes for word motions. A line break is its own class.
const (
	clsBreak = -1
	clsBlank = 0
	clsWord  = 1
	clsPunct = 2
)

// at is the rune at p, '\n' at a line's end.
func (b *buffer) at(p Pos) rune {
	if p.Col >= b.lineLen(p.Line) {
		return '\n'
	}
	return b.lines[p.Line][p.Col]
}

// cls is the class of the rune at p; big (W, B, E) makes every
// non-blank rune part of a word.
func (b *buffer) cls(p Pos, big bool) int {
	r := b.at(p)
	switch {
	case r == '\n':
		return clsBreak
	case r == ' ' || r == '\t':
		return clsBlank
	case big || r == '_' || unicode.IsLetter(r) || unicode.IsDigit(r):
		return clsWord
	}
	return clsPunct
}

// next is the position after p, walking line breaks; false at the end.
func (b *buffer) next(p Pos) (Pos, bool) {
	if p.Col < b.lineLen(p.Line) {
		return Pos{p.Line, p.Col + 1}, true
	}
	if p.Line < b.last() {
		return Pos{p.Line + 1, 0}, true
	}
	return p, false
}

// prev is the position before p; false at the start.
func (b *buffer) prev(p Pos) (Pos, bool) {
	if p.Col > 0 {
		return Pos{p.Line, min(p.Col, b.lineLen(p.Line)) - 1}, true
	}
	if p.Line > 0 {
		return b.lineEnd(p.Line - 1), true
	}
	return p, false
}

// wordForward is w / W: the start of the next word. An empty line counts
// as a word. At the last word it stops at the end of the text.
func (b *buffer) wordForward(p Pos, big bool) Pos {
	ok := true
	if c := b.cls(p, big); c > clsBlank {
		for ok && b.cls(p, big) == c {
			p, ok = b.next(p)
		}
	}
	for ok {
		switch b.cls(p, big) {
		case clsBreak:
			if p, ok = b.next(p); ok && b.empty(p.Line) {
				return p
			}
		case clsBlank:
			p, ok = b.next(p)
		default:
			return p
		}
	}
	return p
}

// wordEnd is e / E: the last rune of this or the next word.
func (b *buffer) wordEnd(p Pos, big bool) Pos {
	start := p
	p, ok := b.next(p)
	for ok && b.cls(p, big) <= clsBlank {
		p, ok = b.next(p)
	}
	if !ok {
		if b.cls(p, big) <= clsBlank {
			return start
		}
		return p
	}
	c := b.cls(p, big)
	for {
		n, ok := b.next(p)
		if !ok || b.cls(n, big) != c {
			return p
		}
		p = n
	}
}

// wordBack is b / B: the start of this or the previous word. An empty
// line counts as a word.
func (b *buffer) wordBack(p Pos, big bool) Pos {
	p, ok := b.prev(p)
	for ok && b.cls(p, big) <= clsBlank {
		if b.empty(p.Line) {
			return p
		}
		p, ok = b.prev(p)
	}
	c := b.cls(p, big)
	for {
		q, ok := b.prev(p)
		if !ok || b.cls(q, big) != c {
			return p
		}
		p = q
	}
}

// firstNonBlank is ^: the first rune of line l that is not a blank.
func (b *buffer) firstNonBlank(l int) Pos {
	for i, r := range b.lines[l] {
		if r != ' ' && r != '\t' {
			return Pos{l, i}
		}
	}
	return Pos{l, max(b.lineLen(l)-1, 0)}
}

// findChar is f / F / t / T within the line: the count-th r after
// (forward) or before p; till stops one rune short.
func (b *buffer) findChar(p Pos, r rune, forward, till bool, count int) (Pos, bool) {
	line := b.lines[p.Line]
	col := p.Col
	for n := 0; n < count; {
		if forward {
			col++
		} else {
			col--
		}
		if col < 0 || col >= len(line) {
			return p, false
		}
		if line[col] == r {
			n++
		}
	}
	if till {
		if forward {
			col--
		} else {
			col++
		}
	}
	return Pos{p.Line, col}, true
}

const brackets = "()[]{}"

// matchBracket is %: from the first bracket at or after p on its line to
// the bracket that pairs with it.
func (b *buffer) matchBracket(p Pos) (Pos, bool) {
	line := b.lines[p.Line]
	col := p.Col
	for col < len(line) && !strings.ContainsRune(brackets, line[col]) {
		col++
	}
	if col >= len(line) {
		return p, false
	}
	open := line[col]
	i := strings.IndexRune(brackets, open)
	pair := rune(brackets[i^1])
	forward := i%2 == 0
	depth := 0
	q, ok := Pos{p.Line, col}, true
	for ok {
		switch b.at(q) {
		case open:
			depth++
		case pair:
			depth--
			if depth == 0 {
				return q, true
			}
		}
		if forward {
			q, ok = b.next(q)
		} else {
			q, ok = b.prev(q)
		}
	}
	return p, false
}

// paragraph is } (dir 1) and { (dir -1): the next empty line after the
// current paragraph, or the start / end of the text.
func (b *buffer) paragraph(p Pos, dir int) Pos {
	l := p.Line
	for l >= 0 && l <= b.last() && b.empty(l) { // leave the empty lines the cursor is on
		l += dir
	}
	for l >= 0 && l <= b.last() && !b.empty(l) { // cross the paragraph
		l += dir
	}
	switch {
	case l < 0:
		return Pos{}
	case l > b.last():
		return b.end()
	}
	return Pos{l, 0}
}
```

```go
package vimedit

import "strings"

// textObject is the range [from, to) of i<obj> (inner) or a<obj> at p.
// obj is the key after i / a: w W " ' ` ( ) b [ ] { }.
func (b *buffer) textObject(p Pos, obj rune, inner bool) (from, to Pos, ok bool) {
	switch obj {
	case 'w', 'W':
		from, to = b.wordObject(p, obj == 'W', inner)
		return from, to, true
	case '"', '\'', '`':
		return b.quoteObject(p, obj, inner)
	case 'b':
		obj = '('
	}
	if i := strings.IndexRune(brackets, obj); i >= 0 {
		return b.bracketObject(p, rune(brackets[i&^1]), rune(brackets[i|1]), inner)
	}
	return p, p, false
}

// wordObject is iw / aw: the run of same-class runes at p; aw adds the
// blanks after it (or, if there are none, the blanks before it), and on
// blanks takes the word after them.
func (b *buffer) wordObject(p Pos, big, inner bool) (Pos, Pos) {
	line := b.lines[p.Line]
	if len(line) == 0 {
		return p, p
	}
	p.Col = min(p.Col, len(line)-1)
	run := func(col int) (int, int) {
		c := b.cls(Pos{p.Line, col}, big)
		s, e := col, col+1
		for s > 0 && b.cls(Pos{p.Line, s - 1}, big) == c {
			s--
		}
		for e < len(line) && b.cls(Pos{p.Line, e}, big) == c {
			e++
		}
		return s, e
	}
	s, e := run(p.Col)
	if inner {
		return Pos{p.Line, s}, Pos{p.Line, e}
	}
	if b.cls(p, big) == clsBlank {
		if e < len(line) {
			_, e = run(e)
		}
		return Pos{p.Line, s}, Pos{p.Line, e}
	}
	if e < len(line) && b.cls(Pos{p.Line, e}, big) == clsBlank {
		_, e = run(e)
	} else if s > 0 && b.cls(Pos{p.Line, s - 1}, big) == clsBlank {
		s, _ = run(s - 1)
	}
	return Pos{p.Line, s}, Pos{p.Line, e}
}

// quoteObject is i" / a" (and ' `) on p's line: the quoted string around
// the cursor, or else the first one after it. a" adds the quotes and the
// blanks after the closing one.
func (b *buffer) quoteObject(p Pos, q rune, inner bool) (Pos, Pos, bool) {
	line := b.lines[p.Line]
	var quotes []int
	for i, r := range line {
		if r == q {
			quotes = append(quotes, i)
		}
	}
	for i := 0; i+1 < len(quotes); i += 2 {
		first, second := quotes[i], quotes[i+1]
		if second < p.Col {
			continue
		}
		if inner {
			return Pos{p.Line, first + 1}, Pos{p.Line, second}, true
		}
		end := second + 1
		for end < len(line) && (line[end] == ' ' || line[end] == '\t') {
			end++
		}
		return Pos{p.Line, first}, Pos{p.Line, end}, true
	}
	return p, p, false
}

// bracketObject is i( / a( (and [ {): the innermost pair around p. i(
// leaves out the brackets.
func (b *buffer) bracketObject(p Pos, open, shut rune, inner bool) (Pos, Pos, bool) {
	p = b.clamp(p)
	start, ok := b.openBefore(p, open, shut)
	if !ok {
		return p, p, false
	}
	depth := 0
	for end := start; ok; end, ok = b.next(end) {
		switch b.at(end) {
		case open:
			depth++
		case shut:
			if depth--; depth > 0 {
				continue
			}
			if inner {
				return Pos{start.Line, start.Col + 1}, end, true
			}
			return start, Pos{end.Line, end.Col + 1}, true
		}
	}
	return p, p, false
}

// openBefore finds the open bracket of the innermost pair around p: p
// itself on an open bracket, the partner of a close bracket.
func (b *buffer) openBefore(p Pos, open, shut rune) (Pos, bool) {
	if b.at(p) == open {
		return p, true
	}
	q, ok := p, true
	if b.at(p) == shut {
		q, ok = b.prev(p)
	}
	depth := 0
	for ; ok; q, ok = b.prev(q) {
		switch b.at(q) {
		case shut:
			depth++
		case open:
			if depth == 0 {
				return q, true
			}
			depth--
		}
	}
	return p, false
}
```

```go
// show is the editor's text with "|" before the cursor.
func show(e *Editor) string {
	off := e.Offset()
	text := e.Text()
	return text[:off] + "|" + text[off:]
}

// keys turns "d2w<esc>" into key presses: <esc> <cr> <bs> <del> <tab>
// <space> <left> <c-r> name special keys, every other rune types itself.
func keys(s string) []Key {
	var out []Key
	for s != "" {
		if s[0] == '<' {
			if end := strings.IndexByte(s, '>'); end > 1 {
				name := s[1:end]
				s = s[end+1:]
				switch {
				case name == "cr":
					name = "enter"
				case name == "bs":
					name = "backspace"
				case name == "del":
					name = "delete"
				case strings.HasPrefix(name, "c-"):
					name = "ctrl+" + name[2:]
				}
				k := Key{Name: name}
				if name == "space" {
					k.Text = " "
				}
				out = append(out, k)
				continue
			}
		}
		r := []rune(s)[0]
		s = s[len(string(r)):]
		if r == ' ' {
			out = append(out, Key{Name: "space", Text: " "})
			continue
		}
		out = append(out, Key{Name: string(r), Text: string(r)})
	}
	return out
}

// feed sends keys to e and returns the last result.
func feed(e *Editor, s string) Result {
	var r Result
	for _, k := range keys(s) {
		r = e.Feed(k)
	}
	return r
}

// newAt is an editor holding s ("|" marks the cursor) in NORMAL mode.
func newAt(t *testing.T, s string) *Editor {
	t.Helper()
	text, p := parse(t, s)
	e := New()
	e.SetText(text)
	e.SetCursor(p)
	return e
}

// editCase is one table row: start text, keys, expected text and mode.
type editCase struct {
	start, keys, want string
	mode              Mode
}

func runCases(t *testing.T, cases []editCase) {
	t.Helper()
	for _, c := range cases {
		e := newAt(t, c.start)
		feed(e, c.keys)
		if got := show(e); got != c.want || e.Mode() != c.mode {
			t.Errorf("%q + %q = %q (%s), want %q (%s)", c.start, c.keys, got, e.Mode(), c.want, c.mode)
		}
	}
}
```

```go
package vimedit

import (
	"strings"
)

// Mode is the editor's vim mode.
type Mode int

const (
	Normal Mode = iota
	Insert
	Visual
	VisualLine
)

func (m Mode) String() string {
	switch m {
	case Insert:
		return "INSERT"
	case Visual:
		return "VISUAL"
	case VisualLine:
		return "V-LINE"
	}
	return "NORMAL"
}

// Key is one key press: Name as Bubble Tea prints it ("j", "G", "ctrl+r",
// "esc", "enter", "space") and Text for keys that type text.
type Key struct{ Name, Text string }

// TabJump is gt / gT for the host: To is a 1-based tab number ({n}gt),
// otherwise By is a relative move (gt +1, {n}gT -n).
type TabJump struct{ To, By int }

// ClipboardPaste asks the host for the system clipboard ("+p, "+P). The
// host reads it and calls Editor.PasteClipboard.
type ClipboardPaste struct {
	Before  bool
	Count   int
	version int // the text the request was made on
}

// Result tells the host what a key did.
type Result struct {
	Handled   bool            // false: the key means nothing to the editor here
	Clipboard *string         // text yanked or deleted into "+: copy it to the system clipboard
	Paste     *ClipboardPaste // "+p / "+P: read the system clipboard
	Tab       *TabJump        // gt / gT
}

const (
	maxCount   = 9999     // bounds count prefixes
	maxPut     = 16 << 20 // bytes a counted p may insert
	shiftWidth = 4        // > < indent and INSERT-mode tab insert four spaces
	wantEnd    = -1       // after $: j and k stay at line ends
)

type register struct {
	text     string
	linewise bool
}

// cmd is one parsed NORMAL / VISUAL command: ["x][count]op(motion).
type cmd struct {
	reg    rune   // register; 0 is the unnamed one
	count  int    // 0: no count typed
	op     string // d c y > <, a command key (x p o …), or "" for a motion
	motion string // motion or text object: w, gg, $, iw, a(; the operator again for dd
	char   rune   // the argument of f t F T
}

func (c cmd) n() int { return max(c.count, 1) }

// pending is the command being typed.
type pending struct {
	keys   []string // as typed, for Pending
	reg    rune
	count  int    // before the operator
	op     string // operator typed so far
	count2 int    // after the operator
	await  string // the next key completes: `"` a register, g, f t F T a rune, i a an object
}

// Editor is the vim state machine over a text.
type Editor struct {
	buf    buffer
	cur    Pos
	want   int // the column j and k aim for, or wantEnd
	mode   Mode
	height int // lines on screen; ctrl+d and ctrl+u move half of it

	regs map[rune]register
	hist history
	pend pending
	res  Result
}

// New returns an empty editor in NORMAL mode.
func New() *Editor {
	return &Editor{buf: newBuffer(""), regs: map[rune]register{}, height: 20}
}

func (e *Editor) Text() string { return e.buf.Text() }

// Version changes whenever the text does.
func (e *Editor) Version() int { return e.buf.version }

func (e *Editor) Mode() Mode { return e.mode }

func (e *Editor) Cursor() Pos { return e.cur }

// SetHeight tells the editor how many lines are on screen.
func (e *Editor) SetHeight(h int) { e.height = max(h, 1) }

// SetCursor moves the cursor, clamped to the text and the mode.
func (e *Editor) SetCursor(p Pos) {
	e.cur = e.buf.clamp(p)
	e.fit()
	e.want = e.cur.Col
}

// Offset is the cursor as a byte offset into Text().
func (e *Editor) Offset() int { return e.buf.offset(e.cur) }

// SetOffset moves the cursor to a byte offset into Text().
func (e *Editor) SetOffset(off int) { e.SetCursor(e.buf.pos(off)) }

// SetText replaces the text as a newly loaded one: the undo history is
// cleared and the cursor goes to the end.
func (e *Editor) SetText(s string) {
	v := e.buf.version
	e.buf = newBuffer(s)
	e.buf.version = v + 1
	e.hist.reset()
	e.pend = pending{}
	e.SetCursor(e.buf.end())
}

// ReplaceAll replaces the text as one change that u undoes; the cursor
// goes to the end.
func (e *Editor) ReplaceAll(s string) {
	e.hist.commit()
	e.change(Pos{}, e.buf.end(), s)
	e.hist.commit()
	e.SetCursor(e.buf.end())
}

// InsertText inserts s at the cursor: typed text in INSERT mode, a change
// of its own otherwise.
func (e *Editor) InsertText(s string) {
	if e.mode == Insert {
		e.typeText(s)
		return
	}
	end := e.change(e.cur, e.cur, s)
	e.hist.commit()
	e.SetCursor(Pos{end.Line, end.Col - 1})
}

// ReplaceBeforeCursor replaces the text from byte offset start to the
// cursor with s, leaving the cursor after s (completion).
func (e *Editor) ReplaceBeforeCursor(start int, s string) {
	off := e.Offset()
	start = min(max(start, 0), off)
	e.replaceBefore(off-start, s)
	if e.mode != Insert {
		e.hist.commit()
		e.fit()
	}
}

func (e *Editor) replaceBefore(back int, s string) {
	from := e.buf.pos(e.Offset() - back)
	e.cur = e.change(from, e.cur, s)
}

// Pending is the command typed so far, like vim's showcmd.
func (e *Editor) Pending() string { return strings.Join(e.pend.keys, "") }

// PasteClipboard finishes a "+p / "+P with the clipboard's text. It does
// nothing (false) if the text or the mode changed since the request.
func (e *Editor) PasteClipboard(p ClipboardPaste, text string) bool {
	if p.version != e.buf.version || e.mode != Normal || text == "" {
		return false
	}
	text = strings.ReplaceAll(text, "\r\n", "\n")
	e.putText(register{text: text, linewise: strings.HasSuffix(text, "\n")}, p.Before, p.Count)
	e.hist.commit()
	e.fit()
	return true
}

// Feed handles one key.
func (e *Editor) Feed(k Key) Result {
	e.res = Result{Handled: true}
	if e.mode == Insert {
		e.insertKey(k)
	} else {
		e.normalKey(k)
	}
	return e.res
}
```

```go
package vimedit

import "unicode/utf8"

func keyRune(k Key) (rune, bool) {
	s := k.Text
	if s == "" {
		s = k.Name
	}
	r, size := utf8.DecodeRuneInString(s)
	return r, size > 0 && size == len(s)
}

func isMotion(name string) bool {
	switch name {
	case "h", "j", "k", "l", "left", "right", "up", "down", "w", "b", "e", "W", "B", "E",
		"0", "^", "$", "G", "%", "{", "}":
		return true
	}
	return false
}

// isFind reports f t F T, which take a rune.
func isFind(name string) bool {
	return name == "f" || name == "t" || name == "F" || name == "T"
}

func isOperator(name string) bool {
	switch name {
	case "d", "c", "y", ">", "<":
		return true
	}
	return false
}

func (e *Editor) normalKey(k Key) {
	p := &e.pend
	name := k.Name
	idle := len(p.keys) == 0
	if name == "esc" {
		e.pend = pending{}
		return
	}
	if p.await != "" {
		e.complete(k)
		return
	}
	count := &p.count
	if p.op != "" {
		count = &p.count2
	}
	if len(name) == 1 && (name >= "1" && name <= "9" || name == "0" && *count > 0) {
		*count = min(*count*10+int(name[0]-'0'), maxCount)
		p.keys = append(p.keys, name)
		return
	}
	c := cmd{reg: p.reg, count: p.total()}
	switch {
	case name == `"` && p.op == "":
		p.await = `"`
	case name == "g" || isFind(name):
		p.await = name
	case (name == "i" || name == "a") && p.op != "":
		p.await = name
	case isMotion(name):
		c.op, c.motion = p.op, name
		e.pend = pending{}
		e.exec(c)
		return
	case isOperator(name) && p.op == "":
		p.op = name
	case isOperator(name) && p.op == name:
		c.op, c.motion = name, name
		e.pend = pending{}
		e.exec(c)
		return
	case p.op == "" && isCommand(name):
		c.op = name
		e.pend = pending{}
		e.exec(c)
		return
	default:
		e.res.Handled = !idle
		e.pend = pending{}
		return
	}
	p.keys = append(p.keys, name)
}

// isCommand reports a NORMAL-mode command that is not a motion or an
// operator.
func isCommand(name string) bool {
	switch name {
	case "x", "p", "P", "D", "C", "o", "O", "i", "a", "I", "A", "u", "ctrl+r",
		"ctrl+d", "ctrl+u":
		return true
	}
	return false
}

func (p *pending) total() int {
	switch {
	case p.count == 0:
		return p.count2
	case p.count2 == 0:
		return p.count
	}
	return min(p.count*p.count2, maxCount)
}

// complete finishes a command waiting for one more key.
func (e *Editor) complete(k Key) {
	p := &e.pend
	r, ok := keyRune(k)
	if k.Name == "space" {
		r, ok = ' ', true
	}
	c := cmd{reg: p.reg, count: p.total(), op: p.op}
	await := p.await
	p.await = ""
	switch {
	case !ok:
		e.pend = pending{}
	case await == `"`:
		if r == '"' || r == '+' || r >= 'a' && r <= 'z' {
			p.reg = r
			p.keys = append(p.keys, string(r))
			return
		}
		e.pend = pending{}
	case await == "g" && r == 'g':
		c.motion = "gg"
		e.pend = pending{}
		e.exec(c)
	case await == "g" && (r == 't' || r == 'T') && p.op == "":
		e.pend = pending{}
		switch {
		case r == 't' && c.count > 0:
			e.res.Tab = &TabJump{To: c.count}
		case r == 't':
			e.res.Tab = &TabJump{By: 1}
		default:
			e.res.Tab = &TabJump{By: -c.n()}
		}
	case isFind(await):
		c.motion, c.char = await, r
		e.pend = pending{}
		e.exec(c)
	case await == "i" || await == "a":
		c.motion = await + string(r)
		e.pend = pending{}
		e.exec(c)
	default:
		e.pend = pending{}
	}
}
```

```go
package vimedit

import (
	"strings"
	"unicode/utf8"
)

// exec runs a NORMAL-mode command.
func (e *Editor) exec(c cmd) {
	switch {
	case c.op == "" && c.motion != "":
		e.move(c)
	case isOperator(c.op):
		e.operate(c)
	default:
		e.run(c)
	}
	if e.mode != Insert {
		e.hist.commit()
		e.fit()
	}
}

// fit keeps the cursor on a rune in NORMAL and VISUAL mode (INSERT mode
// may also be at the line's end).
func (e *Editor) fit() {
	e.cur = e.buf.clamp(e.cur)
	if e.mode != Insert {
		e.cur.Col = min(e.cur.Col, max(e.buf.lineLen(e.cur.Line)-1, 0))
	}
}

// move runs a motion without an operator.
func (e *Editor) move(c cmd) {
	to, _, ok := e.motion(e.cur, c)
	if !ok {
		return
	}
	e.cur = to
	switch c.motion {
	case "j", "k", "up", "down":
	case "$":
		e.want = wantEnd
	default:
		e.want = to.Col
	}
}

// motionKind is how an operator treats a motion's range.
type motionKind int

const (
	exclusive motionKind = iota
	inclusive
	linewise
)

// motion is where c.motion goes from p.
func (e *Editor) motion(p Pos, c cmd) (Pos, motionKind, bool) {
	b := &e.buf
	n := c.n()
	switch c.motion {
	case "h", "left":
		return Pos{p.Line, max(p.Col-n, 0)}, exclusive, p.Col > 0
	case "l", "right":
		limit := b.lineLen(p.Line) - 1
		if c.op != "" {
			limit++
		}
		return Pos{p.Line, min(p.Col+n, limit)}, exclusive, p.Col < limit
	case "j", "down", "k", "up":
		l := p.Line + n
		if c.motion == "k" || c.motion == "up" {
			l = p.Line - n
		}
		l = b.clampLine(l)
		col := e.want
		if col == wantEnd || col > b.lineLen(l) {
			col = b.lineLen(l)
		}
		return Pos{l, col}, linewise, l != p.Line
	case "w", "W":
		for range n {
			p = b.wordForward(p, c.motion == "W")
		}
		return p, exclusive, true
	case "b", "B":
		for range n {
			p = b.wordBack(p, c.motion == "B")
		}
		return p, exclusive, true
	case "e", "E":
		for range n {
			p = b.wordEnd(p, c.motion == "E")
		}
		return p, inclusive, true
	case "0":
		return Pos{p.Line, 0}, exclusive, true
	case "^":
		return b.firstNonBlank(p.Line), exclusive, true
	case "$":
		l := b.clampLine(p.Line + n - 1)
		return Pos{l, max(b.lineLen(l)-1, 0)}, inclusive, true
	case "gg", "G":
		l := 0
		if c.motion == "G" {
			l = b.last()
		}
		if c.count > 0 {
			l = b.clampLine(c.count - 1)
		}
		return b.firstNonBlank(l), linewise, true
	case "%":
		to, ok := b.matchBracket(p)
		return to, inclusive, ok
	case "{", "}":
		dir := 1
		if c.motion == "{" {
			dir = -1
		}
		for range n {
			p = b.paragraph(p, dir)
		}
		return p, exclusive, true
	case "f", "t", "F", "T":
		to, ok := b.findChar(p, c.char, c.motion == "f" || c.motion == "t", c.motion == "t" || c.motion == "T", n)
		kind := inclusive
		if c.motion == "F" || c.motion == "T" {
			kind = exclusive
		}
		return to, kind, ok
	}
	return p, exclusive, false
}

// operate runs an operator over a motion, a text object or (doubled) lines.
func (e *Editor) operate(c cmd) {
	b := &e.buf
	var from, to Pos
	kind := exclusive
	switch m := c.motion; {
	case m == c.op:
		from, to, kind = e.cur, Pos{b.clampLine(e.cur.Line + c.n() - 1), 0}, linewise
	case len(m) == 2 && (m[0] == 'i' || m[0] == 'a'):
		r, _ := utf8.DecodeRuneInString(m[1:])
		var ok bool
		if from, to, ok = b.textObject(e.cur, r, m[0] == 'i'); !ok {
			return
		}
	case c.op == "c" && (m == "w" || m == "W") && b.cls(e.cur, m == "W") > clsBlank:
		// cw changes to the end of the word, like ce
		to = e.cur
		for nx, ok := b.next(to); ok && b.cls(nx, m == "W") == b.cls(e.cur, m == "W"); nx, ok = b.next(to) {
			to = nx
		}
		for range c.n() - 1 {
			to = b.wordEnd(to, m == "W")
		}
		from, kind = e.cur, inclusive
	case m == "w" || m == "W":
		// when the last word moved over ends a line, the range ends there
		from, to = e.cur, e.cur
		for i := range c.n() {
			start := to
			to = b.wordForward(to, m == "W")
			if i == c.n()-1 && to.Line > start.Line {
				to = b.lineEnd(start.Line)
			}
		}
	default:
		var ok bool
		if to, kind, ok = e.motion(e.cur, c); !ok {
			return
		}
		from = e.cur
	}
	from, to = order(from, to)
	if kind == inclusive {
		to = Pos{to.Line, min(to.Col+1, b.lineLen(to.Line))}
	}
	if kind == exclusive && to.Line > from.Line && to.Col == 0 {
		// an exclusive range ending at a line start stops at the previous line's end
		to = b.lineEnd(to.Line - 1)
		if from.Col <= b.firstNonBlank(from.Line).Col {
			kind = linewise
		}
	}
	e.apply(c, from, to, kind == linewise)
}

// apply runs operator c.op on [from, to), or on lines from.Line..to.Line.
func (e *Editor) apply(c cmd, from, to Pos, lines bool) {
	b := &e.buf
	if lines {
		a, z := from.Line, to.Line
		text := b.slice(Pos{a, 0}, b.lineEnd(z)) + "\n"
		switch c.op {
		case "d":
			e.store(c.reg, text, true)
			e.deleteLines(a, z)
		case "y":
			e.store(c.reg, text, true)
			if a < e.cur.Line {
				e.cur.Line = a
			}
		case "c":
			e.store(c.reg, text, true)
			indent := leadingBlanks(b.lines[a])
			e.cur = e.change(Pos{a, 0}, b.lineEnd(z), indent)
			e.mode = Insert
		case ">", "<":
			e.shift(a, z, c.op == ">")
		}
		return
	}
	text := b.slice(from, to)
	switch c.op {
	case "d", "c":
		e.store(c.reg, text, false)
		e.change(from, to, "")
		e.cur = from
		if c.op == "c" {
			e.mode = Insert
		}
	case "y":
		e.store(c.reg, text, false)
		e.cur = from
	case ">", "<":
		e.shift(from.Line, to.Line, c.op == ">")
	}
}

func leadingBlanks(line []rune) string {
	n := 0
	for n < len(line) && (line[n] == ' ' || line[n] == '\t') {
		n++
	}
	return string(line[:n])
}

// deleteLines deletes lines a..z and puts the cursor on the line after them.
func (e *Editor) deleteLines(a, z int) {
	b := &e.buf
	switch {
	case z < b.last():
		e.change(Pos{a, 0}, Pos{z + 1, 0}, "")
	case a > 0:
		e.change(b.lineEnd(a-1), b.lineEnd(z), "")
	default:
		e.change(Pos{}, b.end(), "")
	}
	e.cur = b.firstNonBlank(b.clampLine(a))
}

// shift indents (right) or unindents lines a..z by shiftWidth spaces; a
// leading tab counts as one level. Empty lines stay empty.
func (e *Editor) shift(a, z int, right bool) {
	for l := a; l <= z; l++ {
		line := e.buf.lines[l]
		switch {
		case len(line) == 0:
		case right:
			e.change(Pos{l, 0}, Pos{l, 0}, strings.Repeat(" ", shiftWidth))
		case line[0] == '\t':
			e.change(Pos{l, 0}, Pos{l, 1}, "")
		default:
			n := 0
			for n < shiftWidth && n < len(line) && line[n] == ' ' {
				n++
			}
			e.change(Pos{l, 0}, Pos{l, n}, "")
		}
	}
	e.cur = e.buf.firstNonBlank(a)
}

// store keeps deleted or yanked text in the unnamed register and in reg;
// "+ hands it to the host for the system clipboard.
func (e *Editor) store(reg rune, text string, linewise bool) {
	r := register{text: text, linewise: linewise}
	e.regs['"'] = r
	switch {
	case reg >= 'a' && reg <= 'z':
		e.regs[reg] = r
	case reg == '+':
		e.res.Clipboard = &text
	}
}

// change replaces from..to with s, records it for undo and returns
// where s ends.
func (e *Editor) change(from, to Pos, s string) Pos {
	from, to = order(e.buf.clamp(from), e.buf.clamp(to))
	old := e.buf.slice(from, to)
	if old == s {
		return after(from, s)
	}
	e.hist.record(edit{at: from, old: old, new: s}, e.cur)
	return e.buf.replace(from, to, s)
}

// run runs a command that is not a motion or an operator.
func (e *Editor) run(c cmd) {
	b := &e.buf
	l := e.cur.Line
	switch c.op {
	case "x":
		if b.lineLen(l) > 0 {
			end := Pos{l, min(e.cur.Col+c.n(), b.lineLen(l))}
			e.store(c.reg, b.slice(e.cur, end), false)
			e.change(e.cur, end, "")
		}
	case "D", "C":
		end := b.lineEnd(b.clampLine(l + c.n() - 1))
		e.store(c.reg, b.slice(e.cur, end), false)
		e.change(e.cur, end, "")
		if c.op == "C" {
			e.mode = Insert
		}
	case "p", "P":
		e.put(c, c.op == "P")
	case "i":
		e.mode = Insert
	case "a":
		e.mode = Insert
		e.cur.Col = min(e.cur.Col+1, b.lineLen(l))
	case "I":
		e.mode = Insert
		e.cur = b.firstNonBlank(l)
		if strings.TrimSpace(string(b.lines[l])) == "" {
			e.cur.Col = b.lineLen(l)
		}
	case "A":
		e.mode = Insert
		e.cur = b.lineEnd(l)
	case "o", "O":
		indent := leadingBlanks(b.lines[l])
		if c.op == "o" {
			e.cur = e.change(b.lineEnd(l), b.lineEnd(l), "\n"+indent)
		} else {
			e.change(Pos{l, 0}, Pos{l, 0}, indent+"\n")
			e.cur = Pos{l, utf8.RuneCountInString(indent)}
		}
		e.mode = Insert
	case "u", "ctrl+r":
		for range c.n() {
			undo := e.hist.undoStep
			if c.op == "ctrl+r" {
				undo = e.hist.redoStep
			}
			p, ok := undo(b)
			if !ok {
				break
			}
			e.cur = p
		}
	case "ctrl+d", "ctrl+u":
		dir := "j"
		if c.op == "ctrl+u" {
			dir = "k"
		}
		e.move(cmd{motion: dir, count: max(e.height/2, 1)})
	}
}

// put is p / P from c's register.
func (e *Editor) put(c cmd, before bool) {
	if c.reg == '+' {
		e.res.Paste = &ClipboardPaste{Before: before, Count: c.n(), version: e.buf.version}
		return
	}
	reg := c.reg
	if reg == 0 {
		reg = '"'
	}
	if r, ok := e.regs[reg]; ok && r.text != "" {
		e.putText(r, before, c.n())
	}
}

// putText pastes r count times: lines below (above) the cursor's line, or
// text after (before) the cursor.
func (e *Editor) putText(r register, before bool, count int) {
	b := &e.buf
	count = min(count, max(maxPut/len(r.text), 1))
	if r.linewise {
		block := strings.TrimSuffix(strings.Repeat(r.text, count), "\n")
		l := e.cur.Line
		if before {
			e.change(Pos{l, 0}, Pos{l, 0}, block+"\n")
		} else {
			e.change(b.lineEnd(l), b.lineEnd(l), "\n"+block)
			l++
		}
		e.cur = b.firstNonBlank(l)
		return
	}
	s := strings.Repeat(r.text, count)
	at := e.cur
	if !before && b.lineLen(at.Line) > 0 {
		at.Col++
	}
	end := e.change(at, at, s)
	if strings.Contains(s, "\n") {
		e.cur = at
	} else {
		e.cur = Pos{end.Line, end.Col - 1}
	}
}
```

```go
package vimedit

import "strings"

func (e *Editor) insertKey(k Key) {
	b := &e.buf
	l, col := e.cur.Line, e.cur.Col
	switch k.Name {
	case "esc":
		e.stopInsert()
		return
	case "enter":
		indent := []rune(leadingBlanks(b.lines[l]))
		e.typeText("\n" + string(indent[:min(len(indent), col)]))
	case "backspace", "ctrl+h":
		e.backspace()
	case "delete":
		if col < b.lineLen(l) || l < b.last() {
			nx, _ := b.next(e.cur)
			e.change(e.cur, nx, "")
		}
	case "ctrl+w":
		start := col
		for start > 0 && b.cls(Pos{l, start - 1}, false) == clsBlank {
			start--
		}
		if start > 0 {
			c := b.cls(Pos{l, start - 1}, false)
			for start > 0 && b.cls(Pos{l, start - 1}, false) == c {
				start--
			}
		}
		if col == 0 {
			e.backspace()
		} else {
			e.cur = e.change(Pos{l, start}, e.cur, "")
		}
	case "ctrl+u":
		if col == 0 {
			e.backspace()
		} else {
			e.cur = e.change(Pos{l, 0}, e.cur, "")
		}
	case "tab":
		e.typeText(strings.Repeat(" ", shiftWidth))
	case "left", "right", "up", "down", "home", "end":
		switch k.Name {
		case "left":
			e.cur.Col = max(col-1, 0)
		case "right":
			e.cur.Col = min(col+1, b.lineLen(l))
		case "up", "down":
			nl := l - 1
			if k.Name == "down" {
				nl = l + 1
			}
			e.cur = b.clamp(Pos{nl, col})
		case "home":
			e.cur.Col = 0
		case "end":
			e.cur.Col = b.lineLen(l)
		}
		e.hist.commit() // moving starts a new undo step
		return
	default:
		if k.Text == "" {
			e.res.Handled = false
			return
		}
		e.typeText(k.Text)
	}
}

func (e *Editor) typeText(s string) { e.cur = e.change(e.cur, e.cur, s) }

func (e *Editor) backspace() {
	b := &e.buf
	if p, ok := b.prev(e.cur); ok {
		e.change(p, e.cur, "")
		e.cur = p
	}
}

func (e *Editor) stopInsert() {
	e.mode = Normal
	e.hist.commit()
	if e.cur.Col > 0 {
		e.cur.Col--
	}
	e.fit()
	e.want = e.cur.Col
}
```

```go
package vimedit

// typed is one edit of an INSERT session, kept so . can repeat it: a key,
// text (typed or pasted), or a completion that replaced back bytes before
// the cursor with text.
type typed struct {
	key  string
	text string
	back int
}

// change is a repeatable command and what its INSERT session typed.
type change struct {
	cmd
	typed []typed
}

// isChange reports whether . repeats commands like op.
func isChange(op string) bool {
	switch op {
	case "d", "c", ">", "<", "x", "p", "P", "D", "C", "o", "O", "i", "a", "I", "A":
		return true
	}
	return false
}

// record adds an INSERT-mode edit to the change . will repeat.
func (e *Editor) record(t typed) {
	if e.rec != nil && !e.replay {
		e.rec.typed = append(e.rec.typed, t)
	}
}

// repeat is .: the last change again, with c's count if one was typed.
func (e *Editor) repeat(c cmd) {
	if e.dot == nil {
		return
	}
	d := *e.dot
	if c.count > 0 {
		d.count = c.count
		e.dot.count = c.count
	}
	e.replay = true
	defer func() { e.replay = false }()
	e.exec(d.cmd)
	if e.mode != Insert {
		return
	}
	for _, t := range d.typed {
		switch {
		case t.key != "":
			e.insertKey(Key{Name: t.key})
		case t.back > 0:
			e.replaceBefore(t.back, t.text)
		default:
			e.typeText(t.text)
		}
	}
	e.stopInsert()
}
```

```go
// Editor is the vim state machine over a text.
type Editor struct {
	buf    buffer
	cur    Pos
	want   int // the column j and k aim for, or wantEnd
	mode   Mode
	height int // lines on screen; ctrl+d and ctrl+u move half of it

	regs map[rune]register
	hist history
	pend pending
	res  Result

	dot    *change // the last change, for .
	rec    *change // the change in progress until its INSERT session ends
	replay bool    // . is running: do not record
}

// SetText replaces the text as a newly loaded one: the undo history is
// cleared and the cursor goes to the end.
func (e *Editor) SetText(s string) {
	v := e.buf.version
	e.buf = newBuffer(s)
	e.buf.version = v + 1
	e.hist.reset()
	e.pend, e.rec = pending{}, nil
	e.SetCursor(e.buf.end())
}

// InsertText inserts s at the cursor: typed text in INSERT mode, a change
// of its own otherwise.
func (e *Editor) InsertText(s string) {
	if e.mode == Insert {
		e.typeText(s)
		e.record(typed{text: s})
		return
	}
	end := e.change(e.cur, e.cur, s)
	e.hist.commit()
	e.SetCursor(Pos{end.Line, end.Col - 1})
}

// ReplaceBeforeCursor replaces the text from byte offset start to the
// cursor with s, leaving the cursor after s (completion).
func (e *Editor) ReplaceBeforeCursor(start int, s string) {
	off := e.Offset()
	start = min(max(start, 0), off)
	e.replaceBefore(off-start, s)
	if e.mode == Insert {
		e.record(typed{text: s, back: off - start})
	} else {
		e.hist.commit()
		e.fit()
	}
}
```

```go
// exec runs a NORMAL-mode command.
func (e *Editor) exec(c cmd) {
	changed := e.buf.version
	switch {
	case c.op == "" && c.motion != "":
		e.move(c)
	case isOperator(c.op):
		e.operate(c)
	default:
		e.run(c)
	}
	if !e.replay && isChange(c.op) {
		ch := &change{cmd: c}
		switch {
		case e.mode == Insert:
			e.rec = ch
		case e.buf.version != changed || c.reg == '+':
			e.dot = ch
		}
	}
	if e.mode != Insert {
		e.hist.commit()
		e.fit()
	}
}

// run runs a command that is not a motion or an operator.
func (e *Editor) run(c cmd) {
	b := &e.buf
	l := e.cur.Line
	switch c.op {
	case "x":

			e.mode = Insert
		}
```

```go
package vimedit

import "unicode/utf8"

// Selection is the visual selection as byte offsets [from, to). A
// linewise selection covers its lines without the last line break.
func (e *Editor) Selection() (from, to int, ok bool) {
	a, z, ok := e.selection()
	if !ok {
		return 0, 0, false
	}
	return e.buf.offset(a), e.buf.offset(z), true
}

func (e *Editor) selection() (Pos, Pos, bool) {
	a, z := order(e.anchor, e.cur)
	switch e.mode {
	case Visual:
		return a, Pos{z.Line, min(z.Col+1, e.buf.lineLen(z.Line))}, true
	case VisualLine:
		return Pos{a.Line, 0}, e.buf.lineEnd(z.Line), true
	}
	return Pos{}, Pos{}, false
}

func (e *Editor) leaveVisual() {
	e.mode = Normal
	e.fit()
}

// selectObject is v_iw, v_a( …: the selection becomes the text object.
func (e *Editor) selectObject(c cmd) {
	r, _ := utf8.DecodeRuneInString(c.motion[1:])
	from, to, ok := e.buf.textObject(e.cur, r, c.motion[0] == 'i')
	if !ok || !from.less(to) {
		return
	}
	e.mode, e.anchor = Visual, from
	e.cur, _ = e.buf.prev(to)
	e.want = e.cur.Col
}

// visualOp runs an operator or command on the visual selection.
func (e *Editor) visualOp(c cmd) {
	switch c.op {
	case "v", "V":
		m := Visual
		if c.op == "V" {
			m = VisualLine
		}
		if e.mode == m {
			e.leaveVisual()
		} else {
			e.mode = m
		}
		return
	case "o":
		e.anchor, e.cur = e.cur, e.anchor
		e.want = e.cur.Col
		return
	case "ctrl+d", "ctrl+u":
		e.run(c)
		e.fit()
		return
	case "x":
		c.op = "d"
	}
	from, to, _ := e.selection()
	lines := e.mode == VisualLine
	e.mode = Normal
	switch c.op {
	case "p", "P":
		reg := c.reg
		if reg == 0 {
			reg = '"'
		}
		r, ok := e.regs[reg]
		e.apply(cmd{op: "d"}, from, to, lines)
		if ok && r.text != "" {
			if !lines {
				e.cur = from
			}
			// lines deleted at the end of the text: paste below the new last line
			e.putText(r, !lines || from.Line <= e.buf.last(), 1)
		}
	default:
		e.apply(c, from, to, lines)
	}
	if e.mode != Insert {
		e.hist.commit()
		e.fit()
	}
}
```

```go
func (e *Editor) normalKey(k Key) {
	p := &e.pend
	name := k.Name
	idle := len(p.keys) == 0
	visual := e.mode == Visual || e.mode == VisualLine
	if name == "esc" {
		if idle && visual {
			e.leaveVisual()
		}
		e.pend = pending{}
		return
	}
	if p.await != "" {
		e.complete(k)
		return
	}
	count := &p.count
	if p.op != "" {
		count = &p.count2
	}
	if len(name) == 1 && (name >= "1" && name <= "9" || name == "0" && *count > 0) {
		*count = min(*count*10+int(name[0]-'0'), maxCount)
		p.keys = append(p.keys, name)
		return
	}
	c := cmd{reg: p.reg, count: p.total()}
	switch {
	case name == `"` && p.op == "":
		p.await = `"`
	case name == "g" || isFind(name):
		p.await = name
	case (name == "i" || name == "a") && (p.op != "" || visual):
		p.await = name
	case isMotion(name):
		c.op, c.motion = p.op, name
		e.pend = pending{}
		e.exec(c)
		return
	case isOperator(name) && visual:
		c.op = name
		e.pend = pending{}
		e.visualOp(c)
		return
	case isOperator(name) && p.op == "":
		p.op = name
	case isOperator(name) && p.op == name:
		c.op, c.motion = name, name
		e.pend = pending{}
		e.exec(c)
		return
	case p.op == "" && e.command(name, visual):
		c.op = name
		e.pend = pending{}
		if visual {
			e.visualOp(c)
		} else {
			e.exec(c)
		}
		return
	default:
		e.res.Handled = !idle
		e.pend = pending{}
		return
	}
	p.keys = append(p.keys, name)
}

// command reports whether name is a command (not a motion or operator)
// in the current mode.
func (e *Editor) command(name string, visual bool) bool {
	if visual {
		switch name {
		case "v", "V", "o", "x", "p", "P", "ctrl+d", "ctrl+u":
			return true
		}
		return false
	}
	switch name {
	case "x", "p", "P", "D", "C", "o", "O", "i", "a", "I", "A", "u", "ctrl+r", ".",
		"v", "V", "ctrl+d", "ctrl+u":
		return true
	}
	return false
}

// complete finishes a command waiting for one more key.
func (e *Editor) complete(k Key) {
	p := &e.pend
	r, ok := keyRune(k)
	if k.Name == "space" {
		r, ok = ' ', true
	}
	c := cmd{reg: p.reg, count: p.total(), op: p.op}
	await := p.await
	p.await = ""
	visual := e.mode == Visual || e.mode == VisualLine
	switch {
	case !ok:
		e.pend = pending{}
	case await == `"`:
		if r == '"' || r == '+' || r >= 'a' && r <= 'z' {
			p.reg = r
			p.keys = append(p.keys, string(r))
			return
		}
		e.pend = pending{}
	case await == "g" && r == 'g':
		c.motion = "gg"
		e.pend = pending{}
		e.exec(c)
	case await == "g" && (r == 't' || r == 'T') && p.op == "" && !visual:
		e.pend = pending{}
		switch {
		case r == 't' && c.count > 0:
			e.res.Tab = &TabJump{To: c.count}
		case r == 't':
			e.res.Tab = &TabJump{By: 1}
		default:
			e.res.Tab = &TabJump{By: -c.n()}
		}
	case isFind(await):
		c.motion, c.char = await, r
		e.pend = pending{}
		e.exec(c)
	case await == "i" || await == "a":
		c.motion = await + string(r)
		e.pend = pending{}
		if visual {
			e.selectObject(c)
		} else {
			e.exec(c)
		}
	default:
		e.pend = pending{}
	}
}
```

```go
// run runs a command that is not a motion or an operator.
func (e *Editor) run(c cmd) {
	b := &e.buf
	l := e.cur.Line
	switch c.op {
	case "x":
		if b.lineLen(l) > 0 {
			end := Pos{l, min(e.cur.Col+c.n(), b.lineLen(l))}
			e.store(c.reg, b.slice(e.cur, end), false)
			e.change(e.cur, end, "")
		}
	case "D", "C":
		end := b.lineEnd(b.clampLine(l + c.n() - 1))
		e.store(c.reg, b.slice(e.cur, end), false)
		e.change(e.cur, end, "")
		if c.op == "C" {
			e.mode = Insert
		}
	case "p", "P":
		e.put(c, c.op == "P")
	case "i":
		e.mode = Insert
	case "a":
		e.mode = Insert
		e.cur.Col = min(e.cur.Col+1, b.lineLen(l))
	case "I":
		e.mode = Insert
		e.cur = b.firstNonBlank(l)
		if strings.TrimSpace(string(b.lines[l])) == "" {
			e.cur.Col = b.lineLen(l)
		}
	case "A":
		e.mode = Insert
		e.cur = b.lineEnd(l)
	case "o", "O":
		indent := leadingBlanks(b.lines[l])
		if c.op == "o" {
			e.cur = e.change(b.lineEnd(l), b.lineEnd(l), "\n"+indent)
		} else {
			e.change(Pos{l, 0}, Pos{l, 0}, indent+"\n")
			e.cur = Pos{l, utf8.RuneCountInString(indent)}
		}
		e.mode = Insert
	case "u", "ctrl+r":
		for range c.n() {
			undo := e.hist.undoStep
			if c.op == "ctrl+r" {
				undo = e.hist.redoStep
			}
			p, ok := undo(b)
			if !ok {
				break
			}
			e.cur = p
		}
	case ".":
		e.repeat(c)
	case "v":
		e.mode, e.anchor = Visual, e.cur
	case "V":
		e.mode, e.anchor = VisualLine, e.cur
	case "ctrl+d", "ctrl+u":
		dir := "j"
		if c.op == "ctrl+u" {
			dir = "k"
		}
		e.move(cmd{motion: dir, count: max(e.height/2, 1)})
	}
}
```

```go
// Model is the editor pane.
type Model struct {
	vim           *vimedit.Editor
	width, height int
	top           int // first visible screen row

	highlight func(string) []highlight.Span
	hlText    string
	hlClasses []highlight.Class
	curX      int // where View drew the cursor
	curY      int
}

// New returns an empty editor in NORMAL mode.
func New() *Model { return &Model{vim: vimedit.New()} }

// SetSize sets the drawing area.
func (m *Model) SetSize(w, h int) {
	m.width, m.height = max(w, 0), max(h, 0)
	m.vim.SetHeight(h)
}

// SetHighlighter sets how View colors the text (nil: no colors).
func (m *Model) SetHighlighter(f func(string) []highlight.Span) {
	m.highlight, m.hlClasses = f, nil
}

// KeyOf turns a Bubble Tea key press into a vimedit key.
func KeyOf(msg tea.KeyPressMsg) vimedit.Key {
	k := vimedit.Key{Name: msg.String()}
	if key := msg.Key(); key.Text != "" && key.Mod&^tea.ModShift == 0 {
		k.Text = key.Text
	}
	return k
}

// Update feeds a key press to the editor, or types a paste in INSERT
// mode. Handled is false for keys the editor leaves to the console.
func (m *Model) Update(msg tea.Msg) vimedit.Result {
	switch msg := msg.(type) {
	case tea.KeyPressMsg:
		return m.vim.Feed(KeyOf(msg))
	case tea.PasteMsg:
		if m.Insert() {
			m.vim.InsertText(msg.Content)
			return vimedit.Result{Handled: true}
		}
	}
	return vimedit.Result{}
}

func (m *Model) Value() string { return m.vim.Text() }

// SetValue replaces the text as newly loaded (u does not undo it); the
// cursor goes to the end.
func (m *Model) SetValue(s string) { m.vim.SetText(s) }

// ReplaceAll replaces the text as one change that u undoes.
func (m *Model) ReplaceAll(s string) { m.vim.ReplaceAll(s) }

// Version changes whenever the text does.
func (m *Model) Version() int { return m.vim.Version() }

func (m *Model) Mode() vimedit.Mode { return m.vim.Mode() }
func (m *Model) Insert() bool       { return m.vim.Mode() == vimedit.Insert }

// Visual reports VISUAL and V-LINE mode.
func (m *Model) Visual() bool {
	md := m.vim.Mode()
	return md == vimedit.Visual || md == vimedit.VisualLine
}

// EnterInsert is i; Escape is esc (it leaves INSERT or VISUAL mode).
func (m *Model) EnterInsert() { m.vim.Feed(vimedit.Key{Name: "i", Text: "i"}) }
func (m *Model) Escape()      { m.vim.Feed(vimedit.Key{Name: "esc"}) }

// Pending is the command typed so far (vim's showcmd).
func (m *Model) Pending() string { return m.vim.Pending() }

// Selection is the visual selection as byte offsets into Value().
func (m *Model) Selection() (from, to int, ok bool) { return m.vim.Selection() }

// PasteClipboard finishes a "+p with the clipboard's text.
func (m *Model) PasteClipboard(p vimedit.ClipboardPaste, text string) bool {
	return m.vim.PasteClipboard(p, text)
}

// Offset is the cursor position as a byte offset into Value().
func (m *Model) Offset() int { return m.vim.Offset() }

// Cursor returns the cursor line and column (in runes), both 0-based.
func (m *Model) Cursor() (line, col int) {
	p := m.vim.Cursor()
	return p.Line, p.Col
}

// SetCursor moves the cursor to line and column (in runes), clamped.
func (m *Model) SetCursor(line, col int) { m.vim.SetCursor(vimedit.Pos{Line: line, Col: col}) }

// SetCursorOffset moves the cursor to a byte offset into Value().
func (m *Model) SetCursorOffset(off int) { m.vim.SetOffset(off) }

// ReplaceBeforeCursor replaces the text from byte offset start to the
// cursor with s and leaves the cursor after s.
func (m *Model) ReplaceBeforeCursor(start int, s string) { m.vim.ReplaceBeforeCursor(start, s) }

func (m *Model) Top()    { m.SetCursor(0, 0) }
func (m *Model) Bottom() { m.SetCursor(1<<30, 1<<30) }

// CursorPos is where the last View drew the cursor, relative to the
// editor's top-left corner (line numbers included).
func (m *Model) CursorPos() (x, y int) { return m.curX, m.curY }
```

```go
// before the keymap sees it; used is false when the editor leaves the key
// to the keymap (space, :, enter, ctrl+j …).
func (t *consoleTab) TakeKey(msg tea.KeyPressMsg) (tea.Cmd, bool) {
	if t.onResults {

	before := t.editor.Version()
	res := t.editor.Update(msg)
	if !res.Handled {
		return nil, false
	}
	t.popup = nil
	if t.editor.Version() != before {
		return t.scheduleDraft(), true
	}
	return nil, true
}
```

```go
// Package clipboard copies text to and reads text from the system clipboard.
package clipboard

import (
	"os"
	"os/exec"
	"runtime"
	"strings"

	tea "charm.land/bubbletea/v2"
)

// Copy puts text on the clipboard: pbcopy in a local macOS session,
// otherwise the terminal's OSC 52 sequence (which also works over SSH).
func Copy(text string) tea.Cmd {
	return func() tea.Msg {
		if useMacTool("pbcopy", runtime.GOOS, os.Getenv, exec.LookPath) {
			cmd := exec.Command("pbcopy")
			cmd.Stdin = strings.NewReader(text)
			if err := cmd.Run(); err == nil {
				return nil
			}
		}
		return tea.SetClipboard(text)()
	}
}

// Read reads the clipboard: pbpaste in a local macOS session, whose text
// done turns into a message; otherwise it asks the terminal over OSC 52,
// and the terminal's answer (if it allows reading) arrives as a
// tea.ClipboardMsg.
func Read(done func(text string) tea.Msg) tea.Cmd {
	return func() tea.Msg {
		if useMacTool("pbpaste", runtime.GOOS, os.Getenv, exec.LookPath) {
			if out, err := exec.Command("pbpaste").Output(); err == nil {
				return done(string(out))
			}
		}
		return tea.ReadClipboard()
	}
}

// useMacTool reports whether the macOS clipboard tool works here: a local
// (not SSH) macOS session that has it.
func useMacTool(tool, goos string, getenv func(string) string, lookPath func(string) (string, error)) bool {
	if goos != "darwin" || getenv("SSH_TTY") != "" {
		return false
	}
	_, err := lookPath(tool)
	return err == nil
}
```

```go
func (t *consoleTab) Input(msg tea.Msg) tea.Cmd {
	if k, ok := msg.(tea.KeyPressMsg); ok {
		if cmd, used := t.popupKey(k.String()); used {
			return cmd
		}
		switch k.String() {
		case "ctrl+enter", "ctrl+j":
			t.popup = nil
			return t.runAtCursor()
		case "ctrl+c":
			return t.cancelRun()
		}
	}
	before := t.editor.Version()
	cmd := t.effects(t.editor.Update(msg))
	if t.editor.Version() == before || !t.editor.Insert() {
		t.popup = nil // the cursor moved, or esc left INSERT mode
		return cmd
	}
	t.suggest(false)
	return tea.Batch(cmd, t.scheduleDraft())
}

// TakeKey gives a key pressed in NORMAL or VISUAL mode to the editor
// before the keymap sees it; used is false when the editor leaves the key
// to the keymap (space, :, enter, ctrl+j …).
func (t *consoleTab) TakeKey(msg tea.KeyPressMsg) (tea.Cmd, bool) {
	if t.onResults {
		return nil, false
	}
	before := t.editor.Version()
	res := t.editor.Update(msg)
	if !res.Handled {
		return nil, false
	}
	t.popup = nil
	cmd := t.effects(res)
	if t.editor.Version() != before {
		cmd = tea.Batch(cmd, t.scheduleDraft())
	}
	return cmd, true
}

// effects carries out what the editor asked of the console: the system
// clipboard for "+ and tab jumps for gt / gT.
func (t *consoleTab) effects(res vimedit.Result) tea.Cmd {
	var cmds []tea.Cmd
	if res.Clipboard != nil {
		cmds = append(cmds, copyToClipboard(*res.Clipboard))
	}
	if res.Paste != nil {
		req, id := *res.Paste, t.id
		t.clipPaste = &req
		cmds = append(cmds, readClipboard(func(text string) tea.Msg {
			return clipboardTextMsg{tabID: id, text: text}
		}))
	}
	if res.Tab != nil {
		j := *res.Tab
		cmds = append(cmds, func() tea.Msg { return tabJumpMsg(j) })
	}
	return tea.Batch(cmds...)
}
```

```markdown
## Console editor

The console is a vim editor: NORMAL, INSERT, VISUAL (`v`) and V-LINE (`V`) modes;
motions `h j k l w b e W B E 0 ^ $ gg G f F t T % { }` and `Ctrl-d` `Ctrl-u`; operators
`d c y > <` with a motion, a text object (`iw aw i" a" i' a' i( a( i[ a[ i{ a{`) or doubled
(`dd` `cc` `yy` `>>` `<<`); `x D C p P o O i a I A`; `u` / `Ctrl-r` undo and redo; `.`
repeats the last change; counts (`3dd`, `2dw`); registers `"a`–`"z`, and `"+` for the
system clipboard. In the editor the digits are counts, so `gt` / `gT` / `{n}gt` switch
tabs. `Enter` in VISUAL mode runs the selected statements. `>` and `<` indent by four
spaces; `Tab` in INSERT mode types four spaces.

Not built in: macros, ex ranges, windows, `/` search — `<Space>v` opens the console in
`$EDITOR` for those.
```

```markdown
## [0.5.0] - 2026-10-14

### Added
- A built-in vim editor in the console: NORMAL, INSERT, VISUAL and V-LINE modes, motions
  (`w b e W B E 0 ^ $ gg G f F t T % { }`), operators `d c y > <` with motions, text
  objects and counts, `x p P o O D C I A`, undo / redo, `.` repeat and registers
  `"a`–`"z`; `"+` reads and writes the system clipboard (pbcopy / pbpaste locally,
  OSC 52 over SSH).
- `Enter` in VISUAL mode runs the selected statements.
- `gt` / `gT` / `{n}gt` switch tabs from the console editor.
- The console status line shows the command being typed (`"a2d`), and `?` lists the
  editor's keys.

### Changed
- In the console editor the digits `1`–`9` are counts; they still go to a tab everywhere else.
- Text from `<Space>v` and from SQL history can be undone with `u`.
- The Bubbles dependency is gone.
```
