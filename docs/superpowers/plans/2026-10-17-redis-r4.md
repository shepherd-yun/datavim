# Redis R4（运维与增强）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给 Redis 连接加上一个"服务器"标签页（状态指标 + 每 2 秒采样的 sparkline、慢查询、客户端列表），收藏和最近打开的 key，把 key 的值导出成文件，以及按 db 限速扫描的大 key 分析。

**Architecture:** `rdb.Client` 增加 `Info`、`SlowLog`、`Clients`、`KillClient`、`KeySizes` 和 `IsNoPerm`。UI 新增两种标签页：`serverTab`（三个分区，`[` / `]` 切换；状态分区只在标签页可见时采样，由 `Model` 在当前标签页变化时调用 `Shown()` / `Hidden()` 通知）和 `bigKeysTab`（分批 `SCAN` + `KeySizes` pipeline，每批之间停顿，可取消）。sparkline 是新的纯 widget `ui/panes/sparkline`。收藏是 `internal/history` 的新表 `favorites`，最近打开复用 `recent` 表加一个 kind；两者都用 `rcmd.Quote` 后的 key 名存储。`keyTab` 实现 `exporter`，大 key 可以选择"整个 key"分页流式写出。

**Tech Stack:** Go 1.26、`github.com/redis/go-redis/v9` v9.23.0（`SlowLogGet`、`ClientList`、`ClientKillByFilter` / `Do`、`Pipeline`，实现前用 Context7 查当前用法）、testcontainers `modules/redis` v0.44.0（沿用 `internal/rdb/integration_test.go` 的 `images` / `eachImage`，`redis:7` 和 `redis:5` 都跑）、`modernc.org/sqlite`（现有）。

**Spec:** `docs/superpowers/specs/2026-10-16-redis-design.md`（本计划覆盖 §8 全部；§8 的六项互不依赖，Task 2~3、4、5、6 可以按任意顺序做，都只依赖 Task 1）

## Global Constraints

- key 名一律用原始字节在 `rdb` 和标签页之间传递；显示用 `rcmd.Escape`。写进 SQLite（收藏、最近打开）时存 `rcmd.Quote(key)`，读回用 `parseKeyName`（R3 `keyops.go`）解析，不直接把可能不是 UTF-8 的字节写进 TEXT 列。
- 状态分区：采样间隔 `statusInterval = 2 * time.Second`，保留最近 `statusSamples = 150` 个样本（5 分钟）。标签页不是当前标签页、或者当前分区不是状态分区时**不发 INFO**。用 `INFO`（不带 section 参数，取默认的几节）——Redis 5 和 6 的 `INFO` 只接受一个 section。
- 慢查询读 `SLOWLOG GET 128`（`slowLogCount = 128`）。显示的命令一律过 `rcmd.Redact`（Redis 5 的 slowlog 里可能有 `AUTH <密码>`、`CONFIG SET requirepass …`，不能显示密码）。
- `CLIENT KILL ID <id>` 走 `rcmd.GuardArgs`：只读连接拒绝；它是危险命令，任何连接都要确认，prod 上要输入连接名。
- 任何一项因为 ACL 被拒绝（服务器回 `NOPERM …`）时，那一项显示 `permission denied`，其他项照常；不重试、不弹框。其他服务器错误（比如命令被 `rename-command` 改名后的 `ERR unknown command`）显示服务器的原文。
- 大 key 分析：每批 `SCAN … COUNT 1000`（`bigKeysBatch = 1000`），每批之后对这批 key 发一个 pipeline 取长度（可选 `MEMORY USAGE key SAMPLES 0`）；**所有连接**每批之间停 `prodScanPause`（10 ms），prod 上开始前按 `y` 确认；每种类型保留最大的 `bigKeysTop = 20` 个；可以用 `Cancel`（`ctrl+c`）停止，停止后保留已有结果。
- 导出：不是合法 UTF-8 或含控制字符（`hasControl`）的单元格写成 `rcmd.Escape` 的形式，状态里注明 ` · N binary values written escaped (\xNN)`；其余原样写出。
- 这些常量都不进 `config.toml`。
- 新按键放进 `keymap/defaults.go` 并带描述；UI 文字里的按键一律用 `keyHint`。UI 文字用英文。不记录、不显示密码。
- 提交信息用 Conventional Commits 并带 scope，**不加 Co-Authored-By**。CHANGELOG 和 README 在 Task 7 统一写。

## Review Focus

1. **标签页不可见时仍在采样**：打开服务器标签页后切到另一个标签页、关掉它、或者切到慢查询分区，之后不能再发 `INFO`；切回来立刻采样一次并恢复 2 秒节奏，而且不能因为旧的 tick 和新的 tick 叠在一起变成每秒两次。测试在 Task 2（`TestServerSamplingStopsWhenHidden`、`TestServerSamplingNoDoubleTick`）。
2. **慢查询里的密码**：Redis 5 的 slowlog 条目 `AUTH s3cret`、`CONFIG SET requirepass s3cret` 显示出来不能含 `s3cret`，复制和导出也不能。测试在 Task 3（`TestSlowLogRedacts`）。
3. **二进制 key 进 SQLite**：收藏或打开 key `"a\xffb\x00"` 后，从最近打开 / 收藏列表里打开，必须打开原始字节的同一个 key，而不是 `\xFF` 字面文字或 U+FFFD 替换后的 key。测试在 Task 4（`TestFavoriteBinaryKey`、`TestRecentKeyBinary`）。
4. **大 key 分析里 SCAN 返回重复的 key**：同一个大 key 在两批里都出现时，排行里只出现一次。另外扫描中途 key 被删掉（`KeySizes` 里拿到 `TYPE none` / 长度错误）不能让整次分析失败。测试在 Task 1（`TestKeySizesSkipsGone`，集成）和 Task 6（`TestBigKeyStatsDedup`）。
5. **INFO 在 Redis 5 上**：`INFO` 字段缺失（Redis 5 没有 `instantaneous_input_repl_kbps` 之类，或者某个托管实例去掉了 `maxmemory_human`）时显示 `—`，不崩溃、sparkline 不报错。测试在 Task 1（`TestInfo` 在 `redis:5` 上跑）和 Task 2（`TestStatusFactsMissing`）。

  ```go
  // Info is the fields of an INFO reply ("# Section" and blank lines dropped).
  // Keyspace lines keep their raw value: Info["db0"] == "keys=3,expires=0,avg_ttl=0".
  type Info map[string]string
  func ParseInfo(s string) Info
  func (i Info) Int(field string) (int64, bool)     // false when missing or not an integer
  func (i Info) Float(field string) (float64, bool)
  func (i Info) Keys() int64                        // the keys= of every dbN line, summed

  type SlowEntry struct {
      ID       int64
      Time     time.Time
      Duration time.Duration
      Args     []string // as the server truncated them
      Addr     string   // "" before Redis 4
      Name     string
  }
  // ClientInfo is one CLIENT LIST line: "id=7 addr=… name= age=3 …" as a map.
  type ClientInfo map[string]string
  func parseClientList(s string) []ClientInfo

  // KeySize is one key's length (STRLEN / HLEN / …; -1 for module types)
  // and MEMORY USAGE (-1 when not asked for or not allowed).
  type KeySize struct {
      Key, Type string
      Len, Mem  int64
  }
  // IsNoPerm reports whether err is the server's NOPERM (an ACL refusal).
  func IsNoPerm(err error) bool
  ```
  加进 `Client`：
  ```go
  // Info sends INFO with no section: the default sections (Redis 5 takes one section at most).
  Info(ctx context.Context) (Info, error)
  // SlowLog is SLOWLOG GET n, newest first.
  SlowLog(ctx context.Context, n int64) ([]SlowEntry, error)
  Clients(ctx context.Context) ([]ClientInfo, error)
  // KillClient is CLIENT KILL ID id; false when no such client.
  KillClient(ctx context.Context, id int64) (bool, error)
  // KeySizes reads every key's length in one pipeline, plus MEMORY USAGE
  // key SAMPLES 0 when memory. Keys gone meanwhile (or whose type changed)
  // are left out; a MEMORY error leaves Mem at -1 and is not an error.
  KeySizes(ctx context.Context, keys []KeyEntry, memory bool) ([]KeySize, error)
  ```

  7. `enter`：用 `rows()` 里对应行的原始 key `openKey`。
  8. `Refresh`：在跑时先停；然后用同样的模式和选项重新开始（prod 再确认一次）。`bigKeysTab` 实现现有的 `shutdowner`（`shutdown()` 调 `cancel` 并 `gen++`），关闭标签页或退出时停止扫描；它**不**实现 `shower`，切到别的标签页时继续跑。
