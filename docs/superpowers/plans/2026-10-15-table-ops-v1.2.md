# 表操作第 1 阶段（v1.2）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在树上删除（`dd`）、重命名（`r`）、清空（动作菜单里的 Truncate）表和视图，并用 `a` 打开当前节点的动作菜单，作为终端里的"右键菜单"。

**Architecture:** `db.Dialect` 新增 `DDL() DDLWriter`，由 MySQL / PG 驱动各自写出 `DROP` / `RENAME` / `TRUNCATE` 语句，行为由 `dbtest` contract 在两个引擎上验证。UI 新增 `internal/ui/tableops.go`：按键 → 检查（只读、事务、未提交修改）→ 在 `tea.Cmd` 里取连接并让方言写出 SQL → 确认框 → 通过连接池的 `Conn` 执行（不重试）→ 刷新元数据和树、关闭或改指向相关标签页。动作菜单复用 `overlay.Choice`，选中后走现有的 `dispatch`。

**Tech Stack:** Go、Bubble Tea v2（`charm.land/bubbletea/v2`）、Lip Gloss v2、testcontainers（集成测试）；不新增依赖。

**Spec:** `docs/superpowers/specs/2026-10-15-table-ops-compare-design.md`（本 plan 实现 §3.3 的前半、§5.1 中 `a` / `dd` / `r` 三行、§8 第 1 阶段）

## Global Constraints

- **UI 文案用英文。** 提示里的按键一律用 `keyHint` 或 `Keymap.KeysFor` 生成，不写死键名。
- UI 层不做 IO：所有数据库访问都在 `tea.Cmd` 里，带 `context.WithTimeout`。
- DDL 执行**不重试**：连接断开时调用 `Backend.Reset`，并告诉用户语句可能执行了也可能没执行。
- 安全规则不能少：只读连接拒绝执行；同连接上有 console 开着事务时拒绝；这张表的数据页有未提交的修改时拒绝。
- prod 连接默认只读（`config.Connection.IsReadOnly`），要先 `:set noreadonly` 才能做这些操作；测试里用 `b.SetReadOnly("prod", false)`。
- Drop 和 Truncate 在任何连接上都要输入表名确认；Rename 在 prod 连接上要输入表名确认，其它连接按 `y`。
- 不新增依赖；`go.mod` 不变。
- 每个任务结束时：`gofumpt -l .` 无输出、`go vet ./...` 通过、`go test -race ./...` 全绿；改到 `internal/db` 的任务还要跑 `make test-integration`。
- Conventional Commits，带 scope，描述用中文（与仓库历史一致）。**commit message 不加 `Co-Authored-By` 行。**
- 每个用户可见的改动在 `CHANGELOG.md` 的 `[Unreleased]` 下记一行；README 的改动同时改 `README.zh-CN.md`。

## Review Focus

1. **需要加引号的名字**（空格、大小写混写、名字里有 `` ` `` 或 `"`）：两种方言写出的语句都正确加引号，并且在真实数据库上能执行。→ Task 1 `TestDDLWriter`（两个驱动）和 contract 子测试 `DDLWriter renames, truncates and drops tables and views`（表名 `Ops Tmp`）。
2. **执行 DDL 时连接断开**：不重试，状态栏说明语句可能执行了也可能没执行，标签页保持不变。→ Task 3 `TestDropConnLostIsNotRetried`。
3. **数据库拒绝了操作**（被外键引用的表不能 drop、重命名后的名字已存在）：显示数据库的错误，树和标签页都不变。→ Task 3 `TestDropFailureKeepsTabs`、Task 4 `TestRenameFailureKeepsTabs`。
4. **确认框还没出来，用户已经打开了别的弹窗**（准备 SQL 是异步的）：不覆盖用户正在用的弹窗。→ Task 3 `TestPreparedOpKeepsAnOpenPopup`。
5. **老的 `keymap.toml` 用了 `conn.delete`**：仍然能加载，并且绑定到新的 `node.delete`。→ Task 2 `TestCustomAcceptsRenamedAction`。

```go
// Dialect hides SQL syntax differences between engines.
type Dialect interface {
	QuoteIdent(s string) string
	QualifiedName(t TableRef) string
	Paginate(sql string, limit, offset int) string
	DDL() DDLWriter
}

// DDLWriter writes the engine's statements for changing tables. The
// statements have no trailing semicolon.
type DDLWriter interface {
	// DropTable drops t; view selects DROP VIEW.
	DropTable(t TableRef, view bool) string
	// RenameTable renames t within its namespace.
	RenameTable(t TableRef, newName string, view bool) string
	TruncateTable(t TableRef) string
}
```

- [ ] **Step 5: MySQL 实现**

新建 `internal/db/mysql/ddlwriter.go`：

```go
package mysql

import "github.com/shepherd-yun/datavim/internal/db"

func (dialect) DDL() db.DDLWriter { return ddlWriter{} }

// ddlWriter writes MySQL DDL.
type ddlWriter struct{ d dialect }

func (w ddlWriter) DropTable(t db.TableRef, view bool) string {
	if view {
		return "DROP VIEW " + w.d.QualifiedName(t)
	}
	return "DROP TABLE " + w.d.QualifiedName(t)
}

// RenameTable uses RENAME TABLE, which MySQL accepts for views too.
func (w ddlWriter) RenameTable(t db.TableRef, newName string, _ bool) string {
	to := t
	to.Name = newName
	return "RENAME TABLE " + w.d.QualifiedName(t) + " TO " + w.d.QualifiedName(to)
}

func (w ddlWriter) TruncateTable(t db.TableRef) string {
	return "TRUNCATE TABLE " + w.d.QualifiedName(t)
}
```

```go
package postgres

import "github.com/shepherd-yun/datavim/internal/db"

func (dialect) DDL() db.DDLWriter { return ddlWriter{} }

// ddlWriter writes PostgreSQL DDL.
type ddlWriter struct{ d dialect }

func (w ddlWriter) DropTable(t db.TableRef, view bool) string {
	if view {
		return "DROP VIEW " + w.d.QualifiedName(t)
	}
	return "DROP TABLE " + w.d.QualifiedName(t)
}

// RenameTable keeps the schema: RENAME TO takes a bare name.
func (w ddlWriter) RenameTable(t db.TableRef, newName string, view bool) string {
	kw := "ALTER TABLE "
	if view {
		kw = "ALTER VIEW "
	}
	return kw + w.d.QualifiedName(t) + " RENAME TO " + w.d.QuoteIdent(newName)
}

func (w ddlWriter) TruncateTable(t db.TableRef) string {
	return "TRUNCATE TABLE " + w.d.QualifiedName(t)
}
```

```go
		w := d.DDL()
		exec := func(q string) {
			t.Helper()
			if _, err := conn.Exec(ctx, q); err != nil {
				t.Fatalf("%s: %v", q, err)
			}
		}
		kinds := func() map[string]db.TableKind {
			t.Helper()
			tables, err := conn.Meta().Tables(ctx, ns)
			if err != nil {
				t.Fatal(err)
			}
			out := map[string]db.TableKind{}
			for _, tb := range tables {
				out[tb.Name] = tb.Kind
			}
			return out
		}
		table, view := ref("Ops Tmp"), ref("ops_view")
		exec("CREATE TABLE " + d.QualifiedName(table) + " (id int)")
		exec("INSERT INTO " + d.QualifiedName(table) + " VALUES (1), (2)")
		exec("CREATE VIEW " + d.QualifiedName(view) + " AS SELECT 1 AS one")

		exec(w.RenameTable(table, "Ops Tmp2", false))
		exec(w.RenameTable(view, "ops_view2", true))
		table, view = ref("Ops Tmp2"), ref("ops_view2")
		got := kinds()
		if _, old := got["Ops Tmp"]; old || got["Ops Tmp2"] != db.TableKindTable || got["ops_view2"] != db.TableKindView {
			t.Fatalf("after rename: %v", got)
		}

		exec(w.TruncateTable(table))
		rs, err := conn.Query(ctx, "SELECT COUNT(*) FROM "+d.QualifiedName(table))
		if err != nil {
			t.Fatal(err)
		}
		if n := rs.Rows[0][0].Text; n != "0" {
			t.Fatalf("rows after truncate = %s", n)
		}

		exec(w.DropTable(view, true))
		exec(w.DropTable(table, false))
		got = kinds()
		if _, ok := got["Ops Tmp2"]; ok {
			t.Fatalf("table still there: %v", got)
		}
		if _, ok := got["ops_view2"]; ok {
			t.Fatalf("view still there: %v", got)
		}
	})
```

```go
// Namespace returns the loaded node whose children are the tables of ns on
// conn: a database node for MySQL, a schema node for PostgreSQL. It
// returns nil when no such node is loaded.
func (m *Model) Namespace(conn string, ns db.Namespace) *Node {
	var walk func(nodes []*Node) *Node
	walk = func(nodes []*Node) *Node {
		for _, n := range nodes {
			if n.Conn != conn {
				continue
			}
			if (n.Kind == KindDatabase || n.Kind == KindSchema) && n.NS == ns && n.Loaded {
				return n
			}
			if found := walk(n.Children); found != nil {
				return found
			}
		}
		return nil
	}
	return walk(m.roots)
}
```

```go
package ui

import (
	"context"
	"log/slog"
	"time"

	tea "charm.land/bubbletea/v2"

	"github.com/shepherd-yun/datavim/internal/config"
	"github.com/shepherd-yun/datavim/internal/db"
	"github.com/shepherd-yun/datavim/internal/history"

	"github.com/shepherd-yun/datavim/internal/sqlx"
	"github.com/shepherd-yun/datavim/internal/ui/overlay"
)

// tableOpKind is a change made to a table from the tree.
type tableOpKind int

const (
	opDrop tableOpKind = iota
	opRename
	opTruncate
)

// tableOp is one drop, rename or truncate of a table or view.
type tableOp struct {
	kind    tableOpKind
	conn    string
	ref     db.TableRef
	view    bool
	newName string // opRename only
}

func (o tableOp) object() string {
	if o.view {
		return "view"
	}
	return "table"
}

func (o tableOp) title() string {
	verb := [...]string{opDrop: "Drop", opRename: "Rename", opTruncate: "Truncate"}[o.kind]
	return verb + " " + o.object() + " " + o.ref.Name
}

func (o tableOp) done() string {
	switch o.kind {
	case opRename:
		return "renamed " + o.object() + " " + o.ref.Name + " to " + o.newName
	case opTruncate:
		return "truncated table " + o.ref.Name
	}
	return "dropped " + o.object() + " " + o.ref.Name
}

func (o tableOp) warning() string {
	switch {
	case o.kind == opRename:
		return "SQL and code that use the old name stop working."
	case o.kind == opTruncate:
		return "Every row of the table is deleted. This cannot be undone."
	case o.view:
		return "The view is deleted."
	}
	return "The table and all its rows are deleted. This cannot be undone."
}

// renamed is the table after a rename.
func (o tableOp) renamed() db.TableRef {
	to := o.ref
	to.Name = o.newName
	return to
}

func (o tableOp) statement(w db.DDLWriter) string {
	switch o.kind {
	case opRename:
		return w.RenameTable(o.ref, o.newName, o.view)
	case opTruncate:
		return w.TruncateTable(o.ref)
	}
	return w.DropTable(o.ref, o.view)
}

type (
	// tableOpPreparedMsg carries op's statement, written by the
	// connection's dialect.
	tableOpPreparedMsg struct {
		op  tableOp
		sql string
		err error
	}
	// tableOpConfirmedMsg is the user's go-ahead for sql.
	tableOpConfirmedMsg struct {
		op  tableOp
		sql string
	}
	tableOpDoneMsg struct {
		op  tableOp
		err error
	}
)

func (m tableOpPreparedMsg) failure() (string, error) { return m.op.conn, m.err }
func (m tableOpDoneMsg) failure() (string, error)     { return m.op.conn, m.err }

// tableOpBlocked says why op cannot run now ("" when it can).
func (m *Model) tableOpBlocked(op tableOp) string {
	if cfg, _ := m.backend.Connection(op.conn); cfg.IsReadOnly() {
		return "read-only connection · :set noreadonly allows changes for this session"
	}
	for _, t := range m.tabs {
		switch t := t.(type) {
		case *consoleTab:
			if t.conn == op.conn && t.openTx() {
				return "a console on " + op.conn + " has an open transaction · :commit or :rollback first"
			}
		case *dataTab:
			if t.conn == op.conn && t.ref == op.ref && t.changes() > 0 {
				return joinHints(t.Title()+" has "+plural(t.changes(), "unsaved change"), t.unsavedHint("submits", "discards"))
			}
		}
	}
	return ""
}

// startTableOp checks op, then has the connection's dialect write its SQL.
func (m *Model) startTableOp(op tableOp) tea.Cmd {
	if msg := m.tableOpBlocked(op); msg != "" {
		m.setStatus(msg, true)
		return nil
	}
	b := m.backend
	return func() tea.Msg {
		ctx, cancel := context.WithTimeout(context.Background(), loadTimeout)
		defer cancel()
		msg := tableOpPreparedMsg{op: op}
		msg.err = withConn(ctx, b, op.conn, op.ref.Database, func(c db.Conn) error {
			msg.sql = op.statement(c.Dialect().DDL())
			return nil
		})
		return msg
	}
}

// tableOpPrepared asks before running: drop and truncate always want the
// table's name typed, a rename only on prod.
func (m *Model) tableOpPrepared(msg tableOpPreparedMsg) {
	op := msg.op
	if msg.err != nil {
		m.setStatus(op.object()+" "+op.ref.Name+": "+errorText(msg.err), true)
		return
	}
	if m.overlay != nil {
		return // the user opened something else meanwhile
	}
	cfg, _ := m.backend.Connection(op.conn)
	policy := runner.Policy{ReadOnly: cfg.IsReadOnly(), Prod: cfg.Env == config.EnvProd}
	stmts := []sqlx.Statement{{Text: msg.sql}}
	if chk := runner.Guard(stmts, sqlx.DialectOf(cfg.Driver), policy); chk.Verdict == runner.Reject {
		m.setStatus(chk.Reason, true)
		return
	}
	title := op.title()
	if policy.Prod {
		title = "PROD · " + title
	}
	ok := tableOpConfirmedMsg{op: op, sql: msg.sql}
	if op.kind == opRename && !policy.Prod {
		m.overlay = overlay.NewPreview(title, []string{msg.sql + ";"}, ok)
		return
	}
	lines := []string{msg.sql + ";", "", op.warning(), "Type " + op.ref.Name + " to confirm."}
	m.overlay = overlay.NewConfirm(title, lines, op.ref.Name, ok)
}

// runTableOp runs the confirmed statement on a pooled connection. It never
// retries: a dropped connection may or may not have run it.
func runTableOp(b Backend, st Store, op tableOp, sql string) tea.Cmd {
	return func() tea.Msg {
		ctx, cancel := context.WithTimeout(context.Background(), queryTimeout)
		defer cancel()
		c, err := b.Conn(ctx, op.conn, op.ref.Database)
		if err == nil {
			start := time.Now()
			_, err = c.Exec(ctx, sql)
			entry := history.Entry{Time: start, Conn: op.conn, Database: op.ref.Database, SQL: sql + ";", Duration: time.Since(start)}
			if err != nil {
				entry.Err = errorText(err)
			}
			if herr := st.AddHistory(entry); herr != nil {
				slog.Warn("save history", "err", herr)
			}
		}
		if db.IsConnLost(err) {
			b.Reset(op.conn)
		}
		return tableOpDoneMsg{op: op, err: err}
	}
}

// tableOpDone brings the tree, the catalog and the open tabs up to date.
func (m *Model) tableOpDone(msg tableOpDoneMsg) tea.Cmd {
	op := msg.op
	if msg.err != nil {
		text := op.title() + ": " + errorText(msg.err)
		if db.IsConnLost(msg.err) {
			text += " · it may or may not have run"
		}
		m.setStatus(text, true)
		return nil
	}
	m.setStatus(op.done(), false)
	cmds := []tea.Cmd{m.metaStale(metaStaleMsg{conn: op.conn, database: op.ref.Database})}
	switch op.kind {
	case opDrop:
		cmds = append(cmds, m.closeTabsOfTable(op.conn, op.ref), m.reloadTables(op.conn, op.ref.Namespace, ""))
	}
	return tea.Batch(cmds...)
}

// closeTabsOfTable closes the data and structure tabs of ref.
func (m *Model) closeTabsOfTable(conn string, ref db.TableRef) tea.Cmd {
	var cmds []tea.Cmd
	for i := len(m.tabs) - 1; i >= 0; i-- {
		if c, r := m.tabs[i].Target(); c == conn && r == ref {
			cmds = append(cmds, m.closeTab(i))
		}
	}
	return tea.Batch(cmds...)
}

// reloadTables reloads the tree node listing the tables of ns and, when
// selectName is set, selects that table once it is loaded.
func (m *Model) reloadTables(conn string, ns db.Namespace, selectName string) tea.Cmd {
	n := m.tree.Namespace(conn, ns)
	if n == nil {
		return nil
	}
	m.tree.StartLoad(n)
	if selectName != "" {
		m.revealing = &revealTarget{conn: conn, path: tablePath(ns, selectName)}
	}
	return loadChildren(m.backend, n)
}

// tablePath is the tree path of a table below its connection.
func tablePath(ns db.Namespace, name string) []string {
	path := []string{ns.Database}
	if ns.Schema != "" {
		path = append(path, ns.Schema)
	}
	return append(path, name)
}
```

```go
package ui

import (
	"fmt"

	tea "charm.land/bubbletea/v2"

	"github.com/shepherd-yun/datavim/internal/ui/keymap"
	"github.com/shepherd-yun/datavim/internal/ui/overlay"
	"github.com/shepherd-yun/datavim/internal/ui/panes/tree"
)

// menuItem is one entry of the tree's actions menu.
type menuItem struct {
	action keymap.Action
	desc   string
	keys   string // as bound in the keymap; empty when unbound
}

// menuPickedMsg runs the action picked in the actions menu.
type menuPickedMsg struct{ action keymap.Action }

// nodeMenu lists what can be done with n, the tree's right-click menu.
func (m *Model) nodeMenu(n *tree.Node) []menuItem {
	type entry struct {
		a    keymap.Action
		desc string
	}
	var entries []entry
	switch n.Kind {
	case tree.KindConn:
		entries = []entry{
			{keymap.OpenConsole, "Open console"},
			{keymap.EditConnection, "Edit connection"},
			{keymap.Password, "Enter password"},
			{keymap.Refresh, "Refresh"},
			{keymap.DeleteNode, "Delete connection"},
		}
	case tree.KindDatabase, tree.KindSchema:
		entries = []entry{
			{keymap.OpenConsole, "Open console"},
			{keymap.Refresh, "Refresh"},
		}
	case tree.KindTable, tree.KindView:
		obj := "table"
		if n.Kind == tree.KindView {
			obj = "view"
		}
		entries = []entry{
			{keymap.Expand, "Open data"},
			{keymap.OpenStructure, "Columns"},
			{keymap.OpenFullStructure, "Open structure"},
			{keymap.CopyDDL, "Copy DDL"},
			{keymap.OpenConsole, "Open console"},
			{keymap.RenameTable, "Rename " + obj},
		}
		if n.Kind == tree.KindTable {
			entries = append(entries, entry{keymap.TruncateTable, "Truncate table"})
		}
		entries = append(entries, entry{keymap.DeleteNode, "Drop " + obj})
	}
	items := make([]menuItem, len(entries))
	for i, e := range entries {
		items[i] = menuItem{action: e.a, desc: e.desc, keys: m.keys.KeysFor(keymap.Tree, e.a)}
	}
	return items
}

// openNodeMenu shows the actions menu of the selected node.
func (m *Model) openNodeMenu() {
	n := m.tree.Selected()
	if n == nil {
		return
	}
	items := m.nodeMenu(n)
	labels := make([]string, len(items))
	for i, it := range items {
		labels[i] = fmt.Sprintf("%-10s %s", it.keys, it.desc)
	}
	m.overlay = overlay.NewChoice(n.Name, labels, func(i int) tea.Msg {
		return menuPickedMsg{action: items[i].action}
	})
}
```
