# sqlvim v0.6 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 sqlvim v0.6「数据编辑」：表数据 tab 里 `i` / `Enter` 用内置 vim 编辑器改单元格（`Ctrl-n` 设为 NULL）、`o` 新增行、`dd` 标记删除、`u` 撤销上一项、`U` 撤销全部；修改先暂存并着色（改过的单元格黄、新增行绿、待删除行红色删除线）；`:w` / `<Space>w` 预览生成的 SQL，确认后在一个事务里执行，任一语句影响行数不为 1 就整体回滚；行定位按主键 → 唯一非空索引 → MySQL 全列匹配加 `LIMIT 1` / PostgreSQL `ctid`；提交前过 spec §5.3 的保护检查。另加过滤与排序：`f` 按当前单元格的值过滤、`F` 输入 WHERE 条件、`s` 按当前列切换升序 → 降序 → 无。

**Architecture:** 新的纯逻辑包 `internal/edit`（spec §3.1）：`Table` 保存一页数据的暂存修改与撤销栈，`ChooseKey` 决定怎样定位行，`Plan` 把暂存修改变成 DELETE / UPDATE / INSERT 文本（字面量内联，预览即所执行），`Apply` 在一个 `db.Session` 上 BEGIN → 逐条执行并检查影响行数 → COMMIT / ROLLBACK。SQL 字面量、标识符引号、表名限定、BEGIN 语句集中到 `sqlx`（`export` 与控制台改用它们）。`grid` 增加单元格标记（暂存状态）、排序箭头和光标读写；`overlay` 增加 `CellEditor`（包一层 `panes/editor`，即 vimedit）与可滚动的 `Preview`。表数据 tab 用 `tableQuery`（过滤、排序、键列、`ctid`）拼查询；暂存修改存在时，翻页 / 刷新 / 过滤 / 排序被拒绝，关闭 tab、退出、编辑或删除连接会先询问或拦截。UI 层仍不做 IO：提交在 `tea.Cmd` 里执行。

**Tech Stack:** v0.5 全部依赖；不新增依赖。go-sql-driver/mysql 的 `Config.ClientFoundRows`（已用 `go doc` 核对：`Return number of matching rows instead of rows changed`）。

**Spec:** `docs/superpowers/specs/2026-10-13-sqlvim-design.md`（§3.1 `edit/`、§3.2 分层与纯逻辑包、§5.3 生产库保护、§5.7 结果表格的 `f` `F` `s`、§5.8 数据编辑、§6.1 单元格编辑的 INSERT 模式、§6.2 `:qa` 有未提交修改时询问、§6.3 `<Space>w`、§9 测试策略、§10 v0.6 行）；前五版计划 `docs/superpowers/plans/2026-10-13-sqlvim-v0.1.md`、`…-v0.2.md`、`…-v0.3.md`、`docs/superpowers/plans/2026-10-14-sqlvim-v0.4.md`、`…-v0.5.md`（其中的约定继续有效）。

## Global Constraints

- v0.1–v0.5 计划的 Global Constraints 全部继续有效（模块路径 `github.com/shepherd-yun/sqlvim`、XDG 目录、密码不落盘、日志不含密码、英文 UI 文案、UI 层不做 IO、Conventional Commits + attribution、集成测试 build tag `integration`、`Ctrl-c` 不退出、测试绝不碰真实系统剪贴板）。
- 不新增依赖；`go.mod` 不变。
- `internal/edit` 只依赖标准库、`internal/db`、`internal/sqlx`；不 import Bubble Tea，自己不做 IO（`Apply` 只调用传入的 `db.Querier`）。
- **只有表数据 tab 可编辑**；控制台结果只读（spec §5.8）。编辑键只绑定在 `keymap.Grid` 上下文，`keymap.Results` 不绑定。
- 生成的 SQL 把值内联为字面量（`sqlx.Literal`）：NULL → `NULL`；数值类型且文本是数字 → 原样；MySQL 二进制类型且以 `0x` 开头 → 原样；其余 → 单引号字符串，`'` 双写，MySQL 下 `\` 也双写。预览里显示的就是要执行的文本。
- 行定位（`edit.ChooseKey`）：主键（优先用 Primary 索引的列顺序）→ 第一个所有列都 NOT NULL 的唯一索引 → PostgreSQL 普通表用 `ctid`（数据查询为 `SELECT ctid::text, * FROM …`，第一列剥离后存为行 ID）→ MySQL 用全部可比较列（排除 `FLOAT` `DOUBLE` `REAL` `JSON` `GEOMETRY`），NULL 用 `IS NULL`，语句尾加 ` LIMIT 1` → 都不行（PostgreSQL 无键视图）则只能新增行。定位永远用**从服务器读到的原值**（改主键本身也能定位）。后两种方式在预览里给出一条警告。
- 语句顺序：先全部 DELETE，再 UPDATE，再 INSERT，各自按行顺序。INSERT 只写用户给过值的列；一列都没给时 MySQL 写 `INSERT INTO t () VALUES ()`，PostgreSQL 写 `INSERT INTO t DEFAULT VALUES`。
- 提交：`edit.Apply` 在一个新开的 `db.Session` 上执行 `sqlx.BeginSQL`（MySQL `START TRANSACTION`、PostgreSQL `BEGIN`）→ 每条语句 → `COMMIT`；任一语句出错或 `RowsAffected != 1` → `ROLLBACK`（用独立的 5 秒超时 context）并返回 `*edit.StatementError`（`Index`、`SQL`、`Err`；影响行数不对时 `Err` 是 `*edit.CountError`）。失败时暂存修改保留；成功后清空暂存并重新加载当前页。连接断开时不自动重试提交（`withConn` 的重试不用于提交）。
- MySQL 连接一律设 `ClientFoundRows = true`（UPDATE 报告匹配行数而不是实际改变的行数，与 PostgreSQL 一致；否则把值改成原值会被当成「0 行」而回滚）。这会覆盖 `params` 里显式写的 `clientFoundRows=false`。
- 保护检查（spec §5.3）：只读连接在暂存时就拒绝（`read-only connection · :set noreadonly allows changes for this session`），提交时再用 `runner.Guard` 检查一次（拒绝时不打开预览）；预览总要按 `y` 确认，prod 连接标题前加 `PROD · `。
- 暂存修改存在时：`[` `]` 翻页、`<Space>r` 刷新、`f` `F` `s` 都被拒绝并提示 `N unsaved change(s) · <space>w submits, U discards`；`:q` 询问（`:q!` 不问）；`:qa` 与未结束的事务一起询问（`:qa!` 不问）；树上 `e` / `dd` 编辑或删除该连接被拦截。
- 单元格编辑器（`overlay.CellEditor`）：以 INSERT 模式打开、光标在值的末尾；`Enter` 保存（没有任何编辑时只关闭，不暂存，NULL 仍是 NULL）；`Ctrl-n` 保存 NULL；`Esc` 在 INSERT / VISUAL 下回 NORMAL，在 NORMAL 下（没有挂起的命令时）取消；换行用 NORMAL 模式的 `o` / `O` 或粘贴；`"+` 寄存器与 `gt` / `gT` 在这里不起作用。状态栏模式显示编辑器的模式。
- 新增行的单元格未给值时显示灰色 `DEFAULT`，写入时省略该列；`Ctrl-n` 给出的显式 NULL 不是默认值。
- 过滤：`f` 把 `col = 字面量`（NULL 为 `col IS NULL`）用 `AND` 追加到现有条件（`(旧条件) AND 新条件`）；`F` 打开预填当前条件的输入框，空串清除，结尾的 `;` 去掉。查询拼成 `… WHERE (` + 条件 + `\n) ORDER BY …`（换行让行注释无法吞掉后面的 ORDER BY / LIMIT），并要求 `sqlx.Split` 后恰好一条语句且 `sqlx.Analyze` 为 `Read`，否则拒绝：`the filter must be a condition, like: name = 'x' AND id > 10`。
- 排序：`s` 对当前列循环 升序 → 降序 → 无；单列排序，键列追加在后面保证分页稳定；表头显示 ` ▲` / ` ▼`。过滤或排序后回到第 1 页，光标留在原来的列。
- 过滤与排序之后，「导出整表」也按同样的条件和顺序导出（选项文字变为 `Every row matching the filter`）；复制与导出当前页用屏幕上的值（含暂存修改）。
- 提交成功或失败都写一条 SQL 历史（全部语句用 `;\n` 连接、末尾 `;`），失败时带错误文本；没能打开会话（没连上）时不写。
- 撤销栈上限 `maxUndo = 1000` 步；`U` 不可撤销。

### v0.6 明确不做

控制台结果的编辑（spec §5.8）；表格内 VISUAL 框选、多单元格批量编辑、粘贴 TSV 块到多个单元格；按列类型在客户端校验输入（交给服务器报错，失败整体回滚）；二进制列的专门编辑（按文本显示与写入）；外键跳转 / 值选择；MySQL `NO_BACKSLASH_ESCAPES` 模式；多列排序、保存过滤条件、过滤输入的补全；浮点列按值过滤可能匹配不到（与服务器的文本表示有关）；`U` 的撤销；自定义按键（v1.0）。

```go
package sqlx

import (
	"regexp"
	"strings"

	"github.com/shepherd-yun/sqlvim/internal/db"
)

var (
	numericTypes = wordSet("INT", "INTEGER", "TINYINT", "SMALLINT", "MEDIUMINT", "BIGINT", "DECIMAL", "NUMERIC",
		"FLOAT", "DOUBLE", "REAL", "YEAR", "INT2", "INT4", "INT8", "FLOAT4", "FLOAT8", "OID")
	binaryTypes = wordSet("BINARY", "VARBINARY", "BLOB", "TINYBLOB", "MEDIUMBLOB", "LONGBLOB", "BIT", "GEOMETRY")
	numberRe    = regexp.MustCompile(`^-?\d+(\.\d+)?([eE][-+]?\d+)?$`)
)

// NormType upper-cases a driver type name and drops MySQL's UNSIGNED prefix.
func NormType(t string) string { return strings.TrimPrefix(strings.ToUpper(t), "UNSIGNED ") }

// IsNumericType reports a numeric column type, as drivers name them.
func IsNumericType(t string) bool { return numericTypes[NormType(t)] }

// IsBinaryType reports a MySQL binary column type.
func IsBinaryType(t string) bool { return binaryTypes[NormType(t)] }

// IsNumber reports text that is a plain decimal number.
func IsNumber(s string) bool { return numberRe.MatchString(s) }

// QuoteIdent quotes an identifier: `name` (MySQL) or "name" (PostgreSQL).
func QuoteIdent(d Dialect, s string) string {
	if d == Postgres {
		return db.Quote(s, '"')
	}
	return db.Quote(s, '`')
}

// QualifiedName names a table in SQL text: database.table (MySQL) or
// schema.table (PostgreSQL), just the table without a namespace.
func QualifiedName(d Dialect, ref db.TableRef) string {
	ns := ref.Database
	if d == Postgres {
		ns = ref.Schema
	}
	if ns == "" {
		return QuoteIdent(d, ref.Name)
	}
	return QuoteIdent(d, ns) + "." + QuoteIdent(d, ref.Name)
}

// Literal writes v as a SQL literal for a column of type dbType: NULL, a
// bare number for numeric columns, MySQL 0x… hex for binary columns, and
// otherwise a quoted string ('' for ', and on MySQL \\ for \).
func Literal(d Dialect, dbType string, v db.Value) string {
	switch {
	case v.Null:
		return "NULL"
	case IsNumericType(dbType) && IsNumber(v.Text):
		return v.Text
	case d == MySQL && IsBinaryType(dbType) && strings.HasPrefix(v.Text, "0x"):
		return v.Text
	}
	s := v.Text
	if d == MySQL {
		s = strings.ReplaceAll(s, `\`, `\\`)
	}
	return "'" + strings.ReplaceAll(s, "'", "''") + "'"
}

// BeginSQL starts a transaction.
func BeginSQL(d Dialect) string {
	if d == Postgres {
		return "BEGIN"
	}
	return "START TRANSACTION"
}
```

```go
// Package edit stages changes to a page of table data and turns them into
// the statements that apply them (spec §5.8).
package edit

import (
	"errors"
	"slices"

	"github.com/shepherd-yun/sqlvim/internal/db"
)

// State is how a row differs from the server.
type State int

const (
	Unchanged State = iota
	Modified
	Inserted
	Deleted
)

// Row is one row of the page being edited. Callers read it; only Table
// changes it.
type Row struct {
	ID     string     // PostgreSQL ctid when rows are located by it
	Orig   []db.Value // as read from the server; nil for a new row
	Values []db.Value // as shown and written
	Set    []bool     // cells given a value (new rows: cells not left to their default)
	State  State
}

func (r *Row) clone() *Row {
	c := *r
	c.Values = slices.Clone(r.Values)
	c.Set = slices.Clone(r.Set)
	return &c
}

func (r *Row) equal(o *Row) bool {
	return r.State == o.State && slices.Equal(r.Values, o.Values) && slices.Equal(r.Set, o.Set)
}

// ErrDeleted is returned when a row marked for deletion is edited.
var ErrDeleted = errors.New("the row is marked for deletion · u undoes that")

const maxUndo = 1000

// step undoes one change: it puts before back at index at, or removes the
// row at at when before is nil (the change added it). removed means the
// change took the row out, so undoing puts it back in.
type step struct {
	at      int
	before  *Row
	removed bool
}

// Table is a page of rows with staged changes and their undo history.
type Table struct {
	cols []db.ColumnInfo
	orig [][]db.Value
	ids  []string
	rows []*Row
	undo []step
}

// New stages changes over rows; ids, when not nil, holds each row's ctid.
func New(cols []db.ColumnInfo, rows [][]db.Value, ids []string) *Table {
	t := &Table{cols: cols, orig: rows, ids: ids}
	t.Reset()
	return t
}

// Reset drops every staged change and the undo history.
func (t *Table) Reset() {
	t.rows = make([]*Row, len(t.orig))
	for i, vals := range t.orig {
		r := &Row{Orig: vals, Values: slices.Clone(vals), Set: make([]bool, len(t.cols))}
		if i < len(t.ids) {
			r.ID = t.ids[i]
		}
		t.rows[i] = r
	}
	t.undo = nil
}

func (t *Table) Columns() []db.ColumnInfo { return t.cols }
func (t *Table) Len() int                 { return len(t.rows) }
func (t *Table) Row(i int) *Row           { return t.rows[i] }

// Result is the rows as shown: staged values, new rows included. Cells
// left to their default read as NULL.
func (t *Table) Result() *db.ResultSet {
	rs := &db.ResultSet{Columns: t.cols, Rows: make([][]db.Value, len(t.rows))}
	for i, r := range t.rows {
		rs.Rows[i] = r.Values
	}
	return rs
}

// Changes counts the rows with a staged change.
func (t *Table) Changes() int {
	n := 0
	for _, r := range t.rows {
		if r.State != Unchanged {
			n++
		}
	}
	return n
}

func (t *Table) push(s step) {
	t.undo = append(t.undo, s)
	if over := len(t.undo) - maxUndo; over > 0 {
		t.undo = t.undo[over:]
	}
}

func stateOf(r *Row) State {
	switch {
	case r.Orig == nil:
		return Inserted
	case slices.Contains(r.Set, true):
		return Modified
	}
	return Unchanged
}

// SetCell stages v as a cell's value. Setting a cell back to its server
// value unstages it.
func (t *Table) SetCell(row, col int, v db.Value) error {
	r := t.rows[row]
	if r.State == Deleted {
		return ErrDeleted
	}
	before := r.clone()
	r.Values[col] = v
	r.Set[col] = r.Orig == nil || v != r.Orig[col]
	r.State = stateOf(r)
	if !r.equal(before) {
		t.push(step{at: row, before: before})
	}
	return nil
}

// InsertAfter adds a row below row (-1: at the top) with every cell left
// to its default and returns its index.
func (t *Table) InsertAfter(row int) int {
	at := min(max(row+1, 0), len(t.rows))
	r := &Row{Values: make([]db.Value, len(t.cols)), Set: make([]bool, len(t.cols)), State: Inserted}
	for i := range r.Values {
		r.Values[i].Null = true
	}
	t.rows = slices.Insert(t.rows, at, r)
	t.push(step{at: at})
	return at
}

// Delete marks a row for deletion; a new row is dropped instead. A row
// already marked stays as it is.
func (t *Table) Delete(row int) {
	r := t.rows[row]
	switch r.State {
	case Deleted:
	case Inserted:
		t.push(step{at: row, before: r, removed: true})
		t.rows = slices.Delete(t.rows, row, row+1)
	default:
		t.push(step{at: row, before: r.clone()})
		r.State = Deleted
	}
}

// Undo reverts the last staged change and returns the row it touched.
func (t *Table) Undo() (int, bool) {
	if len(t.undo) == 0 {
		return 0, false
	}
	s := t.undo[len(t.undo)-1]
	t.undo = t.undo[:len(t.undo)-1]
	switch {
	case s.before == nil:
		t.rows = slices.Delete(t.rows, s.at, s.at+1)
	case s.removed:
		t.rows = slices.Insert(t.rows, s.at, s.before)
	default:
		t.rows[s.at] = s.before
	}
	return min(s.at, max(len(t.rows)-1, 0)), true
}
```

```go
package edit

import (
	"github.com/shepherd-yun/sqlvim/internal/db"
	"github.com/shepherd-yun/sqlvim/internal/sqlx"
)

// KeyKind says how the rows of a table are located.
type KeyKind int

const (
	NoKey      KeyKind = iota // rows cannot be located: only new rows can be added
	PrimaryKey                // the primary key
	UniqueKey                 // a unique index over NOT NULL columns
	AllColumns                // MySQL without a key: every comparable column, LIMIT 1
	RowID                     // PostgreSQL without a key: ctid
)

// Key is how rows are located.
type Key struct {
	Kind    KeyKind
	Columns []string // PrimaryKey and UniqueKey: the key's columns
}

// ChooseKey picks how rows of a table are located: its primary key, else a
// unique index over NOT NULL columns, else ctid (PostgreSQL tables) or
// every column (MySQL). A PostgreSQL view without a key has none.
func ChooseKey(d sqlx.Dialect, cols []db.Column, idx []db.Index, view bool) Key {
	nullable := make(map[string]bool, len(cols))
	var pk []string
	for _, c := range cols {
		nullable[c.Name] = c.Nullable
		if c.PrimaryKey {
			pk = append(pk, c.Name)
		}
	}
	for _, ix := range idx {
		if ix.Primary && len(ix.Columns) > 0 {
			pk = ix.Columns
		}
	}
	if len(pk) > 0 {
		return Key{Kind: PrimaryKey, Columns: pk}
	}
	for _, ix := range idx {
		if ix.Unique && notNull(ix.Columns, nullable) {
			return Key{Kind: UniqueKey, Columns: ix.Columns}
		}
	}
	switch {
	case d == sqlx.Postgres && !view:
		return Key{Kind: RowID}
	case d == sqlx.MySQL:
		return Key{Kind: AllColumns}
	}
	return Key{}
}

// notNull reports names that are all known NOT NULL columns.
func notNull(names []string, nullable map[string]bool) bool {
	if len(names) == 0 {
		return false
	}
	for _, n := range names {
		if null, known := nullable[n]; !known || null {
			return false
		}
	}
	return true
}
```

```go
package edit

import (
	"errors"
	"fmt"
	"slices"
	"strings"

	"github.com/shepherd-yun/sqlvim/internal/db"
	"github.com/shepherd-yun/sqlvim/internal/sqlx"
)

// Target is the table staged changes are written to.
type Target struct {
	Dialect sqlx.Dialect
	Table   db.TableRef
	Key     Key
}

// ErrNoKey means a changed or deleted row cannot be located.
var ErrNoKey = errors.New("no primary key, unique NOT NULL index or row id: rows can only be added")

// incomparable types do not reliably match their text with =, so
// AllColumns leaves them out of the WHERE clause.
var incomparable = map[string]bool{"FLOAT": true, "DOUBLE": true, "REAL": true, "JSON": true, "GEOMETRY": true}

// Plan turns the staged changes into statements: deletes, then updates,
// then inserts, each in row order. Rows are located by the values read
// from the server. warnings explain a weak way of locating rows.
func Plan(t *Table, tg Target) (stmts, warnings []string, err error) {
	d := tg.Dialect
	name := sqlx.QualifiedName(d, tg.Table)
	var dels, upds, ins []string
	for _, r := range t.rows {
		switch r.State {
		case Deleted:
			where, err := tg.where(t.cols, r)
			if err != nil {
				return nil, nil, err
			}
			dels = append(dels, "DELETE FROM "+name+" WHERE "+where+tg.limit())
		case Modified:
			where, err := tg.where(t.cols, r)
			if err != nil {
				return nil, nil, err
			}
			var sets []string
			for i, c := range t.cols {
				if r.Set[i] {
					sets = append(sets, sqlx.QuoteIdent(d, c.Name)+" = "+sqlx.Literal(d, c.DatabaseType, r.Values[i]))
				}
			}
			upds = append(upds, "UPDATE "+name+" SET "+strings.Join(sets, ", ")+" WHERE "+where+tg.limit())
		case Inserted:
			ins = append(ins, tg.insert(name, t.cols, r))
		}
	}
	if len(dels)+len(upds) > 0 {
		if w := tg.warning(); w != "" {
			warnings = append(warnings, w)
		}
	}
	return slices.Concat(dels, upds, ins), warnings, nil
}

// where locates r by its server values.
func (tg Target) where(cols []db.ColumnInfo, r *Row) (string, error) {
	d := tg.Dialect
	var parts []string
	switch tg.Key.Kind {
	case RowID:
		if r.ID == "" {
			return "", ErrNoKey
		}
		return "ctid = " + sqlx.Literal(d, "", db.Value{Text: r.ID}), nil
	case PrimaryKey, UniqueKey:
		for _, name := range tg.Key.Columns {
			i := slices.IndexFunc(cols, func(c db.ColumnInfo) bool { return c.Name == name })
			if i < 0 {
				return "", fmt.Errorf("key column %s is not in the result", name)
			}
			parts = append(parts, match(d, cols[i], r.Orig[i]))
		}
	case AllColumns:
		for i, c := range cols {
			if !incomparable[sqlx.NormType(c.DatabaseType)] {
				parts = append(parts, match(d, c, r.Orig[i]))
			}
		}
	}
	if len(parts) == 0 {
		return "", ErrNoKey
	}
	return strings.Join(parts, " AND "), nil
}

func match(d sqlx.Dialect, c db.ColumnInfo, v db.Value) string {
	col := sqlx.QuoteIdent(d, c.Name)
	if v.Null {
		return col + " IS NULL"
	}
	return col + " = " + sqlx.Literal(d, c.DatabaseType, v)
}

func (tg Target) limit() string {
	if tg.Key.Kind == AllColumns {
		return " LIMIT 1"
	}
	return ""
}

func (tg Target) warning() string {
	switch tg.Key.Kind {
	case AllColumns:
		return tg.Table.Name + " has no primary key or unique NOT NULL index: rows are matched by all their values, one row at most (LIMIT 1)"
	case RowID:
		return tg.Table.Name + " has no primary key or unique NOT NULL index: rows are matched by their ctid"
	}
	return ""
}

// insert writes the columns given a value; the rest keep their defaults.
func (tg Target) insert(name string, cols []db.ColumnInfo, r *Row) string {
	d := tg.Dialect
	var names, vals []string
	for i, c := range cols {
		if r.Set[i] {
			names = append(names, sqlx.QuoteIdent(d, c.Name))
			vals = append(vals, sqlx.Literal(d, c.DatabaseType, r.Values[i]))
		}
	}
	switch {
	case len(names) > 0:
		return "INSERT INTO " + name + " (" + strings.Join(names, ", ") + ") VALUES (" + strings.Join(vals, ", ") + ")"
	case d == sqlx.Postgres:
		return "INSERT INTO " + name + " DEFAULT VALUES"
	}
	return "INSERT INTO " + name + " () VALUES ()"
}
```

```go
package edit

import (
	"context"
	"fmt"
	"time"

	"github.com/shepherd-yun/sqlvim/internal/db"
	"github.com/shepherd-yun/sqlvim/internal/sqlx"
)

const rollbackTimeout = 5 * time.Second

// StatementError is a statement that failed or did not change exactly one
// row; the transaction was rolled back.
type StatementError struct {
	Index int // 0-based
	SQL   string
	Err   error
}

func (e *StatementError) Error() string {
	return fmt.Sprintf("statement %d: %v · rolled back, nothing was changed", e.Index+1, e.Err)
}

func (e *StatementError) Unwrap() error { return e.Err }

// CountError is a statement that changed a number of rows other than one.
type CountError struct{ Affected int64 }

func (e *CountError) Error() string { return fmt.Sprintf("changed %d rows, expected 1", e.Affected) }

// Apply runs stmts in one transaction on s (a db.Session). Every statement
// must change exactly one row; otherwise, or when one fails, everything is
// rolled back and a *StatementError names the statement.
func Apply(ctx context.Context, s db.Querier, d sqlx.Dialect, stmts []string) error {
	if _, err := s.Exec(ctx, sqlx.BeginSQL(d)); err != nil {
		return fmt.Errorf("begin transaction: %w", err)
	}
	for i, q := range stmts {
		res, err := s.Exec(ctx, q)
		if err == nil && res.RowsAffected != 1 {
			err = &CountError{Affected: res.RowsAffected}
		}
		if err != nil {
			rollback(s)
			return &StatementError{Index: i, SQL: q, Err: err}
		}
	}
	if _, err := s.Exec(ctx, "COMMIT"); err != nil {
		rollback(s)
		return fmt.Errorf("commit: %w", err)
	}
	return nil
}

// rollback ends the transaction even when ctx was cancelled.
func rollback(s db.Querier) {
	ctx, cancel := context.WithTimeout(context.Background(), rollbackTimeout)
	defer cancel()
	_, _ = s.Exec(ctx, "ROLLBACK")
}
```

```go
package overlay

import (
	"strings"

	tea "charm.land/bubbletea/v2"

	"github.com/shepherd-yun/sqlvim/internal/db"
	"github.com/shepherd-yun/sqlvim/internal/ui/panes/editor"
	"github.com/shepherd-yun/sqlvim/internal/ui/textutil"
	"github.com/shepherd-yun/sqlvim/internal/ui/theme"
	"github.com/shepherd-yun/sqlvim/internal/ui/vimedit"
)

// CellEditor edits one cell value with the vim editor. It opens in INSERT
// mode at the end of the value; enter saves, ctrl+n saves NULL, and esc
// goes to NORMAL mode and, there, cancels.
type CellEditor struct {
	title  string
	ed     *editor.Model
	start  int // the editor's version when it opened
	submit func(db.Value) tea.Msg
}

// NewCellEditor opens an editor on v; submit turns the saved value into a
// message.
func NewCellEditor(title string, v db.Value, submit func(db.Value) tea.Msg) *CellEditor {
	ed := editor.New()
	ed.SetPlaceholder("")
	if !v.Null {
		ed.SetValue(v.Text)
	}
	ed.AppendAtEnd()
	return &CellEditor{title: title, ed: ed, start: ed.Version(), submit: submit}
}

func (c *CellEditor) HandleKey(msg tea.KeyPressMsg) (Overlay, tea.Cmd) {
	switch msg.String() {
	case "enter":
		if c.ed.Version() == c.start {
			return nil, nil // nothing was edited: the cell stays as it was
		}
		return nil, emit(c.submit(db.Value{Text: c.ed.Value()}))
	case "ctrl+n":
		return nil, emit(c.submit(db.Value{Null: true}))
	case "esc":
		if c.ed.Mode() == vimedit.Normal && c.ed.Pending() == "" {
			return nil, nil
		}
	}
	c.ed.Update(msg) // the "+ register and gt / gT mean nothing here
	return c, nil
}

// Mode is the editor's vim mode, for the status bar.
func (c *CellEditor) Mode() string { return c.ed.Mode().String() }

// Paste types a terminal paste in INSERT mode.
func (c *CellEditor) Paste(text string) { c.ed.Update(tea.PasteMsg{Content: text}) }

func (c *CellEditor) View(width, height int) string {
	w := max(min(width-4, 80), 24)
	lines := strings.Count(c.ed.Value(), "\n") + 1
	edH := textutil.Clamp(lines, 3, max(height-8, 3))
	c.ed.SetSize(w-2, edH)
	esc := "esc normal mode"
	if c.ed.Mode() == vimedit.Normal {
		esc = "esc cancel"
	}
	body := c.ed.View() + "\n\n" + theme.Muted.Render("enter save · ctrl+n NULL · "+esc)
	return theme.Box(c.title+" · "+c.Mode(), body, w, edH+4, true)
}
```

```go
import (
	"strings"

	tea "charm.land/bubbletea/v2"

	"github.com/shepherd-yun/sqlvim/internal/ui/textutil"

// Preview shows statements before they run: y runs them, n or esc
// cancels, j / k and ctrl+d / ctrl+u scroll.
type Preview struct {
	title  string
	lines  []string
	ok     tea.Msg
	offset int
}

// NewPreview builds the preview; y emits ok.
func NewPreview(title string, lines []string, ok tea.Msg) *Preview {
	return &Preview{title: title, lines: lines, ok: ok}
}

func (p *Preview) HandleKey(msg tea.KeyPressMsg) (Overlay, tea.Cmd) {
	switch msg.String() {
	case "y", "Y":
		return nil, emit(p.ok)
	case "n", "N", "esc", "q":
		return nil, nil
	case "j", "down":
		p.offset++
	case "k", "up":
		p.offset--
	case "ctrl+d":
		p.offset += 10
	case "ctrl+u":
		p.offset -= 10
	}
	return p, nil
}

func (p *Preview) View(width, height int) string {
	inner := max(min(width-4, 120), 10) - 2
	var lines []string
	for _, l := range p.lines {
		for _, part := range strings.Split(l, "\n") {
			lines = append(lines, textutil.Wrap(textutil.Sanitize(part), inner)...)
		}
	}
	return scrollBox(p.title+" · y submit · n cancel", lines, &p.offset, width, height, 120)
}
```

```go
package ui

import (
	"errors"
	"strings"

	"github.com/shepherd-yun/sqlvim/internal/db"
	"github.com/shepherd-yun/sqlvim/internal/sqlx"
)

// tableQuery is what a data tab shows: its filter and sort, the key that
// keeps pages stable and whether rows carry their ctid.
type tableQuery struct {
	where string   // the filter without WHERE; "" for every row
	sort  string   // the column sorted by; "" for key order
	desc  bool     // sort descending
	key   []string // ORDER BY after the sort column
	rowID bool     // PostgreSQL: select ctid::text first
}

var errBadFilter = errors.New("the filter must be a condition, like: name = 'x' AND id > 10")

// sql is the query without pagination. The filter is closed on its own
// line, so a trailing -- comment cannot swallow ORDER BY or LIMIT.
func (q tableQuery) sql(d sqlx.Dialect, ref db.TableRef) string {
	sel := "SELECT * FROM "
	if q.rowID {
		sel = "SELECT ctid::text, * FROM "
	}
	s := sel + sqlx.QualifiedName(d, ref)
	if q.where != "" {
		s += " WHERE (" + q.where + "\n)"
	}
	var order []string
	if q.sort != "" {
		o := sqlx.QuoteIdent(d, q.sort)
		if q.desc {
			o += " DESC"
		}
		order = append(order, o)
	}
	for _, k := range q.key {
		if k != q.sort {
			order = append(order, sqlx.QuoteIdent(d, k))
		}
	}
	if len(order) > 0 {
		s += " ORDER BY " + strings.Join(order, ", ")
	}
	return s
}

// check rejects a filter that turns the query into more than one SELECT.
func (q tableQuery) check(d sqlx.Dialect, ref db.TableRef) error {
	s := q.sql(d, ref)
	if len(sqlx.Split(s, d)) != 1 || sqlx.Analyze(s, d).Kind != sqlx.Read {
		return errBadFilter
	}
	return nil
}

// valueFilter matches rows whose col equals v.
func valueFilter(d sqlx.Dialect, col db.ColumnInfo, v db.Value) string {
	name := sqlx.QuoteIdent(d, col.Name)
	if v.Null {
		return name + " IS NULL"
	}
	return name + " = " + sqlx.Literal(d, col.DatabaseType, v)
}

// andFilter narrows the filter old with cond.
func andFilter(old, cond string) string {
	if old == "" {
		return cond
	}
	return "(" + old + ") AND " + cond
}
```

```go
// load reads page of q. q becomes the tab's query only once it loaded, so
// a failing filter leaves the rows on screen.
func (t *dataTab) load(page int, q tableQuery) tea.Cmd {
	t.loading = true
	id, b, conn, ref, size, d, known := t.id, t.backend, t.conn, t.ref, t.pageSize, t.dialect, t.known
	return func() tea.Msg {
		ctx, cancel := context.WithTimeout(context.Background(), queryTimeout)
		defer cancel()
		msg := pageLoadedMsg{tabID: id, conn: conn, page: page, query: q}
		msg.err = withConn(ctx, b, conn, ref.Database, func(c db.Conn) error {
			if !known {
				cols, err := c.Meta().Columns(ctx, ref)
				if err != nil {
					return err
				}
				msg.query.key = primaryKey(cols)
			}
			var err error
			msg.rs, msg.hasMore, err = fetchPage(ctx, c, d, ref, msg.query, page, size)
			return err
		})
		return msg
	}
}

func primaryKey(cols []db.Column) []string {
	var out []string
	for _, c := range cols {
		if c.PrimaryKey {
			out = append(out, c.Name)
		}
	}
	return out
}

func fetchPage(ctx context.Context, c db.Conn, d sqlx.Dialect, ref db.TableRef, q tableQuery, page, size int) (*db.ResultSet, bool, error) {
	rs, err := c.Query(ctx, c.Dialect().Paginate(q.sql(d, ref), size+1, page*size))
	if err != nil {
		return nil, false, err
	}
	hasMore := len(rs.Rows) > size
	if hasMore {
		rs.Rows = rs.Rows[:size]
	}
	return rs, hasMore, nil
}

func (t *dataTab) Update(msg tea.Msg) tea.Cmd {
	switch m := msg.(type) {
	case pageLoadedMsg:
		t.pageLoaded(m)
	case filterMsg:
		where := strings.TrimSpace(strings.TrimRight(strings.TrimSpace(m.text), ";"))
		return t.applyQuery(func(q *tableQuery) { q.where = where })
	}
	return nil
}

func (t *dataTab) pageLoaded(m pageLoadedMsg) {
	t.loading = false
	if m.err != nil {
		t.err = m.err.Error()
		return
	}
	t.err, t.page, t.hasMore = "", m.page, m.hasMore
	t.query, t.known = m.query, true
	t.grid.SetSort(t.query.sort, t.query.desc)
	t.grid.SetResult(m.rs)
	if t.wantColumn != "" {
		t.grid.SelectColumn(t.wantColumn)
		t.wantColumn = ""
	}
}
```

```go
func (t *dataTab) Handle(a keymap.Action) tea.Cmd {
	t.status = ""
	if cmd, ok := gridAction(t.grid, a); ok {
		return cmd
	}
	switch a {
	case keymap.NextPage:
		if t.hasMore && !t.loading {
			return t.load(t.page+1, t.query)
		}
	case keymap.PrevPage:
		if t.page > 0 && !t.loading {
			return t.load(t.page-1, t.query)
		}
	case keymap.Refresh:
		if !t.loading {
			t.known = false
			return t.load(t.page, t.query)
		}
	case keymap.FilterValue:
		col, v, ok := t.grid.Cell()
		if !ok {
			t.setStatus("no cell to filter by", true)
			return nil
		}
		cond := valueFilter(t.dialect, col, v)
		return t.applyQuery(func(q *tableQuery) { q.where = andFilter(q.where, cond) })
	case keymap.FilterPrompt:
		id := t.id
		return openOverlay(overlay.NewPrompt("Filter "+t.ref.Name, "WHERE … (empty shows every row)", t.query.where,
			func(s string) tea.Msg { return filterMsg{tabID: id, text: s} }))
	case keymap.SortColumn:
		col, ok := t.grid.Column()
		if !ok {
			return nil
		}
		return t.applyQuery(func(q *tableQuery) {
			switch {
			case q.sort != col.Name:
				q.sort, q.desc = col.Name, false
			case !q.desc:
				q.desc = true
			default:
				q.sort, q.desc = "", false
			}
		})
	}
	return nil
}

// applyQuery reloads the first page with a changed filter or sort, keeping
// the cursor's column.
func (t *dataTab) applyQuery(change func(*tableQuery)) tea.Cmd {
	if t.loading {
		return nil
	}
	q := t.query
	change(&q)
	if err := q.check(t.dialect, t.ref); err != nil {
		t.setStatus(err.Error(), true)
		return nil
	}
	if col, ok := t.grid.Column(); ok {
		t.wantColumn = col.Name
	}
	return t.load(0, q)
}
```

```go
func (t *dataTab) statusLine() string {
	switch {
	case t.loading:
		return theme.Muted.Render("loading…")
	case t.err != "":
		return theme.Error.Render("✗ " + textutil.Sanitize(t.err))
	case t.status != "":

		if t.statusErr {

		}

	}

// pageInfo describes the rows shown: their numbers, filter, sort and paging.
func (t *dataTab) pageInfo() string {
	var parts []string
	if n := t.grid.RowCount(); n == 0 {
		parts = append(parts, "no rows")
	} else {
		first := t.page*t.pageSize + 1
		parts = append(parts, fmt.Sprintf("rows %d–%d", first, first+n-1))
	}
	parts = append(parts, fmt.Sprintf("page %d", t.page+1))
	if t.query.where != "" {
		parts = append(parts, "where "+oneLine(t.query.where))
	}
	if t.query.sort != "" {
		dir := "asc"
		if t.query.desc {
			dir = "desc"
		}
		parts = append(parts, "sorted by "+t.query.sort+" "+dir)
	}
	if t.hasMore {
		parts = append(parts, "] next")
	}
	if t.page > 0 {
		parts = append(parts, "[ prev")
	}
	return strings.Join(parts, " · ")
}
```

```go
// tableMeta is what editing needs from the catalog.
type tableMeta struct {
	cols []db.Column
	key  edit.Key
}

func readTableMeta(ctx context.Context, m db.MetaReader, d sqlx.Dialect, ref db.TableRef) (*tableMeta, error) {
	cols, err := m.Columns(ctx, ref)
	if err != nil {
		return nil, err
	}
	idx, err := m.Indexes(ctx, ref)
	if err != nil {
		return nil, err
	}
	view := false
	if d == sqlx.Postgres && len(primaryKey(cols)) == 0 {
		tables, err := m.Tables(ctx, ref.Namespace)
		if err != nil {
			return nil, err
		}
		for _, tb := range tables {
			if tb.Name == ref.Name {
				view = tb.Kind == db.TableKindView
			}
		}
	}
	return &tableMeta{cols: cols, key: edit.ChooseKey(d, cols, idx, view)}, nil
}

// order is the columns that keep pages stable: the key's, if it has any.
func (tm *tableMeta) order() []string {
	if tm.key.Kind == edit.PrimaryKey || tm.key.Kind == edit.UniqueKey {
		return tm.key.Columns
	}
	return nil
}
```

```go
// fetchPage reads one page; with q.rowID the leading ctid column is split

func fetchPage(ctx context.Context, c db.Conn, d sqlx.Dialect, ref db.TableRef, q tableQuery, page, size int) (*db.ResultSet, []string, bool, error) {
	rs, err := c.Query(ctx, c.Dialect().Paginate(q.sql(d, ref), size+1, page*size))
	if err != nil {
		return nil, nil, false, err
	}
	hasMore := len(rs.Rows) > size
	if hasMore {
		rs.Rows = rs.Rows[:size]
	}
	var ids []string
	if q.rowID && len(rs.Columns) > 0 {
		ids = make([]string, len(rs.Rows))
		for i, row := range rs.Rows {
			ids[i] = row[0].Text
			rs.Rows[i] = row[1:]
		}
		rs.Columns = rs.Columns[1:]
	}
	return rs, ids, hasMore, nil
}
```

```go
import (
	"fmt"
	"strings"

	tea "charm.land/bubbletea/v2"

// cellEditedMsg is a value saved in the cell editor.
type cellEditedMsg struct {
	tabID    int
	table    *edit.Table // the page the edit was made on
	row, col int
	value    db.Value
}

func (m cellEditedMsg) TabID() int { return m.tabID }

// plural is "1 change", "2 changes".
func plural(n int, noun string) string {
	if n == 1 {
		return "1 " + noun
	}
	return fmt.Sprintf("%d %ss", n, noun)
}

// changes counts the rows with staged changes.
func (t *dataTab) changes() int {
	if t.table == nil {
		return 0
	}
	return t.table.Changes()
}

// mark is how the grid draws a cell of the page.
func (t *dataTab) mark(row, col int) grid.Mark {
	if t.table == nil || row >= t.table.Len() {
		return grid.MarkNone
	}
	r := t.table.Row(row)
	switch {
	case r.State == edit.Deleted:
		return grid.MarkDeleted
	case r.State == edit.Inserted && r.Set[col]:
		return grid.MarkInserted
	case r.State == edit.Inserted:
		return grid.MarkDefault
	case r.Set[col]:
		return grid.MarkChanged
	}
	return grid.MarkNone
}

// editBlocked says why the page cannot be changed now ("" when it can);
// existing is set for changes to rows read from the server.
func (t *dataTab) editBlocked(existing bool) string {
	cfg, _ := t.backend.Connection(t.conn)
	switch {
	case t.table == nil || t.loading:
		return "wait for the rows to load"
	case cfg.IsReadOnly():
		return "read-only connection · :set noreadonly allows changes for this session"
	case existing && t.key.Kind == edit.NoKey:
		return t.ref.Name + " has no primary or unique key: rows can only be added"
	}
	return ""
}

// showChanges redraws the page after a staged change, keeping the cursor.
func (t *dataTab) showChanges() { t.grid.ReplaceResult(t.table.Result()) }

func (t *dataTab) editCell() tea.Cmd {
	if t.table == nil || t.table.Len() == 0 {
		t.setStatus("no row here · o adds one", true)
		return nil
	}
	row, col := t.grid.Position()
	r := t.table.Row(row)
	if msg := t.editBlocked(r.State != edit.Inserted); msg != "" {
		t.setStatus(msg, true)
		return nil
	}
	if r.State == edit.Deleted {
		t.setStatus(edit.ErrDeleted.Error(), true)
		return nil
	}
	c := t.table.Columns()[col]
	id, table := t.id, t.table
	return openOverlay(overlay.NewCellEditor(t.columnTitle(c), r.Values[col], func(v db.Value) tea.Msg {
		return cellEditedMsg{tabID: id, table: table, row: row, col: col, value: v}
	}))
}

// columnTitle is "name · type", the type as the catalog spells it.
func (t *dataTab) columnTitle(c db.ColumnInfo) string {
	typ := strings.ToLower(c.DatabaseType)
	for _, mc := range t.cols {
		if mc.Name == c.Name {
			typ = mc.Type
		}
	}
	if typ == "" {
		return c.Name
	}
	return c.Name + " · " + typ
}

func (t *dataTab) cellEdited(m cellEditedMsg) {
	if m.table != t.table || m.row >= t.table.Len() {
		return // the page was reloaded meanwhile
	}
	if err := t.table.SetCell(m.row, m.col, m.value); err != nil {
		t.setStatus(err.Error(), true)
		return
	}
	t.showChanges()
}

func (t *dataTab) insertRow() {
	if msg := t.editBlocked(false); msg != "" {
		t.setStatus(msg, true)
		return
	}
	row, col := t.grid.Position()
	if t.table.Len() == 0 {
		row = -1
	}
	at := t.table.InsertAfter(row)
	t.showChanges()
	t.grid.SetCursor(at, col)
}

func (t *dataTab) deleteRow() {
	if t.table == nil || t.table.Len() == 0 {
		t.setStatus("no row here", true)
		return
	}
	row, _ := t.grid.Position()
	r := t.table.Row(row)
	if msg := t.editBlocked(r.State != edit.Inserted); msg != "" {
		t.setStatus(msg, true)
		return
	}
	if r.State == edit.Deleted {
		t.setStatus("already marked for deletion · u undoes that", false)
		return
	}
	t.table.Delete(row)
	t.showChanges()
}

func (t *dataTab) undoEdit() {
	if t.table == nil {
		return
	}
	row, ok := t.table.Undo()
	if !ok {
		t.setStatus("no changes to undo", false)
		return
	}
	_, col := t.grid.Position()
	t.showChanges()
	t.grid.SetCursor(row, col)
}

func (t *dataTab) undoAll() {
	n := t.changes()
	if n == 0 {
		t.setStatus("no changes to discard", false)
		return
	}
	t.table.Reset()
	t.showChanges()
	t.setStatus("discarded "+plural(n, "change"), false)
}
```

```go
	submitConfirmedMsg struct{ tabID, gen int }

	editsAppliedMsg struct {

		conn  string

func (m editsAppliedMsg) TabID() int    { return m.tabID }

// submit previews the staged changes as SQL after the safety checks.
func (t *dataTab) submit() tea.Cmd {
	switch {
	case t.submitting:
		t.setStatus("submitting changes…", true)
		return nil
	case t.changes() == 0:
		t.setStatus("no changes to submit", false)
		return nil
	}
	stmts, warnings, err := edit.Plan(t.table, edit.Target{Dialect: t.dialect, Table: t.ref, Key: t.key})
	if err != nil {
		t.setStatus(err.Error(), true)
		return nil
	}
	cfg, _ := t.backend.Connection(t.conn)
	batch := make([]sqlx.Statement, len(stmts))
	for i, s := range stmts {
		batch[i] = sqlx.Statement{Text: s}
	}
	policy := runner.Policy{ReadOnly: cfg.IsReadOnly(), Prod: cfg.Env == config.EnvProd}
	if chk := runner.Guard(batch, t.dialect, policy); chk.Verdict == runner.Reject {
		t.setStatus(chk.Reason, true)
		return nil
	}
	title := "Submit " + plural(t.changes(), "change") + " to " + t.ref.Name
	if policy.Prod {
		title = "PROD · " + title
	}
	var lines []string
	for _, w := range warnings {
		lines = append(lines, "! "+w)
	}
	if len(lines) > 0 {
		lines = append(lines, "")
	}
	for _, s := range stmts {
		lines = append(lines, s+";")
	}
	t.gen++
	t.pendingSQL = stmts
	return openOverlay(overlay.NewPreview(title, lines, submitConfirmedMsg{tabID: t.id, gen: t.gen}))
}

// apply runs the confirmed statements in one transaction on a session of
// their own. It never retries: a dropped connection may or may not have
// committed.
func (t *dataTab) apply(stmts []string) tea.Cmd {
	t.submitting = true
	t.setStatus("submitting…", false)
	id, b, st, conn, ref, d := t.id, t.backend, t.store, t.conn, t.ref, t.dialect
	return func() tea.Msg {
		ctx, cancel := context.WithTimeout(context.Background(), queryTimeout)
		defer cancel()
		msg := editsAppliedMsg{tabID: id, conn: conn, n: len(stmts)}
		c, err := b.Conn(ctx, conn, ref.Database)
		if err != nil {
			msg.err = err
			return msg
		}
		s, err := c.Session(ctx)
		if err != nil {
			if db.IsConnLost(err) {
				b.Reset(conn)
			}
			msg.err = err
			return msg
		}
		start := time.Now()
		msg.err = edit.Apply(ctx, s, d, stmts)
		_ = s.Close()
		if db.IsConnLost(msg.err) {
			b.Reset(conn)
		}
		entry := history.Entry{
			Time: start, Conn: conn, Database: ref.Database,
			SQL: strings.Join(stmts, ";\n") + ";", Duration: time.Since(start),
		}
		if msg.err != nil {
			entry.Err = errorText(msg.err)
		}
		if err := st.AddHistory(entry); err != nil {
			slog.Warn("save history", "err", err)
		}
		return msg
	}
}

// applied reloads the page after a submit, or keeps the changes staged
// when it failed. The staged changes are dropped before reloading so a
// failed reload can never submit them twice.
func (t *dataTab) applied(m editsAppliedMsg) tea.Cmd {
	t.submitting = false
	if m.err != nil {
		t.retrySubmit = errors.Is(m.err, session.ErrPasswordRequired)
		// "changes kept" first: the tab's status line is narrow.
		t.setStatus("✗ changes kept · "+errorText(m.err), true)
		return nil
	}
	t.table.Reset()
	t.showChanges()
	t.setStatus("submitted "+plural(m.n, "change"), false)
	return t.load(t.page, t.query)
}
```

```go
func (m *Model) requestQuit(force bool) tea.Cmd {
	open, edits := m.openTransactions(), m.unsavedTables()
	if force || len(open)+len(edits) == 0 {
		return m.quit()
	}
	if len(edits) == 0 {
		m.overlay = overlay.NewConfirm("Open transactions", []string{
			"Uncommitted transactions in: " + strings.Join(open, ", ") + ".",
			"Quitting rolls them back.",
		}, "", quitConfirmedMsg{})
		return nil
	}
	lines := []string{"Unsaved changes in: " + strings.Join(edits, ", ") + "."}
	if len(open) > 0 {
		lines = append(lines, "Uncommitted transactions in: "+strings.Join(open, ", ")+".")
	}
	m.overlay = overlay.NewConfirm("Unsaved changes", append(lines, "Quitting discards them."), "", quitConfirmedMsg{})
	return nil
}
```

```go
func (m *Model) canChange(conn string) bool {
	for _, t := range m.tabs {
		switch t := t.(type) {

			}

	}
	return true
```
