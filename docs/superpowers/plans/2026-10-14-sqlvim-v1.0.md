# sqlvim v1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 sqlvim v1.0「打磨与发布」：`~/.config/sqlvim/keymap.toml` 自定义按键与 leader（启动时校验冲突并指出位置），`config.toml` 的 `[theme]` 自定义颜色；界面里所有按键提示跟随实际 keymap；README（中英文）配演示动图与 Ghostty 配置片段；CONTRIBUTING、Issue/PR 模板；GoReleaser 打包、Homebrew tap 发布；在 GitHub 创建公开仓库 `shepherd-yun/sqlvim`、CI 通过后打 `v1.0.0` tag 并完成发布与 `brew install` 验证。

**Architecture:** `config` 只负责把 `keymap.toml` 解析成原始结构 `config.KeymapFile`、把 `config.toml` 的 `[theme]` 读成 `map[string]string`，不 import UI 包。`ui/keymap` 新增 `ParseKeys`（`Display` 的逆运算）与 `Custom(leader, overrides)`（在默认绑定上删除 / 覆盖 / 新增，再走已有的 `New` 校验），以及 `KeysFor` 供提示文案使用。`ui/theme` 把包级样式变量改为由 `Apply(overrides)` 一次性重建（默认值在 `init` 里应用，现有调用点不变）。`cmd/sqlvim` 在启动时构建 keymap 与主题，出错即带文件名退出（spec §8 唯一允许退出的错误）；`ui.Model.SetKeymap` 注入 keymap，并传给之后创建的 tab。发布部分是纯配置：`.goreleaser.yaml`、`.github/workflows/release.yml`、VHS tape 与 docker 演示库。

**Tech Stack:** v0.6 全部依赖，`go.mod` 不变。发布工具（本机 brew 安装，不进 go.mod）：GoReleaser v2（`homebrew_casks`，v2.10 起取代已废弃的 `brews`；已用 Context7 核对 `repository.token`、`hooks.post.install` 去 quarantine 的写法）、`goreleaser/goreleaser-action@v7`、charmbracelet VHS（tape 语法 `Output` `Set` `Type` `Sleep` `Hide` `Show` `Env` `Require` `Screenshot`，已用 Context7 核对）、gitleaks、Docker（OrbStack）、`gh`（已登录 `shepherd-yun`，scope 含 `repo` `workflow`）。

**Spec:** `docs/superpowers/specs/2026-10-13-sqlvim-design.md`（§2 发布选型、§3.1 `config/` 含按键与主题、§6.4 keymap 实现与 Ghostty 片段、§7 本地数据路径、§8 配置解析失败的报错、§9 测试与 CI、§10 v1.0 行、§11 开源规范）；前几版计划 `docs/superpowers/plans/2026-10-13-sqlvim-v0.1.md` … `2026-10-14-sqlvim-v0.6.md`、`2026-10-14-table-filter-ux.md`（约定继续有效）。

## Global Constraints

- v0.1–v0.6 计划的 Global Constraints 全部继续有效（模块路径 `github.com/shepherd-yun/sqlvim`、XDG 目录、密码不落盘、日志不含密码、英文 UI 文案、UI 层不做 IO、Conventional Commits + attribution、集成测试 build tag `integration`、`Ctrl-c` 不退出、测试绝不碰真实系统剪贴板）。
- `go.mod` 不变；不新增 Go 依赖。
- `internal/config` 不 import `internal/ui/...`；`ui/keymap`、`ui/theme` 不做 IO。
- `keymap.toml` 格式（spec §6.4）：顶层可选 `leader`；表 `[global]` `[tree]` `[grid]` `[structure]` `[console]` `[results]`，键为按键序列（与 `?` 帮助里显示的写法相同：`gg`、`<leader>s`、`<ctrl+d>`、`f<`），值为动作 ID（如 `"filter.eq"`），空串 `""` 表示解绑。同一上下文里绑定已有按键 = 替换；绑定新按键 = 新增，默认按键保留。
- 校验失败的报错格式：`<文件路径>: [<上下文>] "<按键>": <原因>`（如 `…/keymap.toml: [grid] "f": unknown action "sort"`）；前缀 / 重复冲突沿用 `keymap.New` 的文案并加文件路径前缀。未知表名、类型错误由 go-toml 报 `文件:行:列`。
- 主题：`config.toml` 的 `[theme]` 表，键为下表的槽名，值为 ANSI 色号 `"0"`–`"255"` 或 `"#rgb"` / `"#rrggbb"`；未知槽名、非法颜色启动报错 `<config.toml 路径>: theme.<槽>: …`。不提供内置配色方案（默认使用终端 16 色，随终端配色变化）。

  | 槽 | 默认 | 用途 |
  |---|---|---|
  | `border` | `8` | 边框、次要文字、NULL、注释 |
  | `focus` | `12` | 焦点边框、关键字、schema / database 标签 |
  | `error` | `9` | 错误、prod、删除行 |
  | `accent` | `14` | 强调、活动 tab、table 标签 |
  | `on_error` | `15` | prod 模式块的前景 |
  | `visual_bg` / `visual_fg` | `8` / `15` | VISUAL 选区 |
  | `changed` | `11` | 改过的单元格、column 标签 |
  | `inserted` | `10` | 新增行、routine 标签 |
  | `view` | `13` | view 标签 |
  | `builtin` `string` `number` `operator` | `6` `2` `3` `5` | SQL 高亮 |

- 界面里提到 keymap 管辖的按键时，一律经 `Keymap.KeysFor` 取实际绑定（vimedit 自己的按键 `i` `v` `u` `y d c` 等不受 keymap 管辖，保持原文）。

## Review Focus

1. **改了 leader 后提示仍写 `<space>`**：`leader = ","` → 欢迎页、底栏 `<space> leader`、表数据「`<space>w` submit」、控制台提示、`<space>n add one`、搜索失败的 `<space>r retries` 都显示 `,`（Task 4 `TestHintsFollowCustomLeader`）。
2. **leader 被控制台编辑器吃掉**：`leader = ","`（vim 里 `,` 是反向重复 f/t）→ 控制台 NORMAL 模式下按 `,` 仍进入 leader 序列、which-key 出现；编辑器有挂起命令（如 `f` 之后）时 `,` 仍交给编辑器（Task 4 `TestConsoleLeaderIsNotTakenByEditor`）。
3. **自定义绑定与默认绑定成前缀冲突**：`[grid] "f" = "sort.column"`（默认有 `ff` `fs`…）、`leader = "g"`（与 `gg` `gt` 冲突）→ 启动报错指出文件、按键与冲突的另一方，而不是 panic 或静默遮蔽（Task 2 `TestCustomReportsConflicts`，Task 3 `TestRunReportsKeymapErrors`）。
4. **非法输入**：未知动作、未知上下文表 `[gird]`、`"<ctrl+d"` 未闭合、`leader = "ab"`、颜色 `"bleu"` `"#12345"` `"256"`、未知槽 `focsu` → 启动报错带文件名与位置，程序不启动 TUI（Task 1 `TestApplyRejectsBadColors`，Task 2 `TestParseKeys`、`TestCustomRejectsBadInput`，Task 3 `TestLoadKeymapErrors`）。

```go
import (
	"fmt"
	"image/color"
	"maps"
	"regexp"
	"slices"
	"strconv"
	"strings"
	// 原有 import
)

// defaults are the theme slots and their colors: ANSI indexes, so the
// terminal's own palette decides what they look like.
var defaults = map[string]string{
	"border": "8", "focus": "12", "error": "9", "accent": "14", "on_error": "15",
	"visual_bg": "8", "visual_fg": "15", "changed": "11", "inserted": "10", "view": "13",
	"builtin": "6", "string": "2", "number": "3", "operator": "5",
}

var (
	ColorBorder, ColorFocus, ColorError, ColorAccent color.Color

	Muted, Error, Prod, ProdMode, Accent, Title, Selected, Visual, SelectedDim, Mode,
	Null, Changed, Inserted, Deleted, Header, ActiveTab lipgloss.Style

	syntax   map[highlight.Class]lipgloss.Style
	kindTags map[string]lipgloss.Style
)

func init() {
	if err := Apply(nil); err != nil {
		panic(err) // defaults are valid; covered by TestApplyNilRestoresDefaults
	}
}

// Slots lists the keys config.toml's [theme] accepts.
func Slots() []string { return slices.Sorted(maps.Keys(defaults)) }

var hexColor = regexp.MustCompile(`^#([0-9a-fA-F]{3}|[0-9a-fA-F]{6})$`)

func parseColor(s string) (color.Color, bool) {
	if hexColor.MatchString(s) {
		return lipgloss.Color(s), true
	}
	if n, err := strconv.Atoi(s); err == nil && n >= 0 && n <= 255 && strconv.Itoa(n) == s {
		return lipgloss.Color(s), true
	}
	return nil, false
}

// Apply rebuilds every style from the default colors with overrides on top
// (slot name -> ANSI index "0"–"255" or "#rgb" / "#rrggbb"). Nothing changes
// when an override is invalid. Call it before the program starts.
func Apply(overrides map[string]string) error {
	c := make(map[string]color.Color, len(defaults))
	for slot, v := range defaults {
		c[slot], _ = parseColor(v)
	}
	for _, slot := range slices.Sorted(maps.Keys(overrides)) {
		v := overrides[slot]
		if _, ok := defaults[slot]; !ok {
			return fmt.Errorf("theme.%s: unknown key (want one of %s)", slot, strings.Join(Slots(), ", "))
		}
		col, ok := parseColor(v)
		if !ok {
			return fmt.Errorf("theme.%s: invalid color %q (want 0–255 or #rrggbb)", slot, v)
		}
		c[slot] = col
	}
	build(c)
	return nil
}

func build(c map[string]color.Color) {
	ColorBorder, ColorFocus, ColorError, ColorAccent = c["border"], c["focus"], c["error"], c["accent"]

	Muted = lipgloss.NewStyle().Foreground(ColorBorder)
	Error = lipgloss.NewStyle().Foreground(ColorError)
	Prod = lipgloss.NewStyle().Foreground(ColorError).Bold(true)
	ProdMode = lipgloss.NewStyle().Bold(true).Foreground(c["on_error"]).Background(ColorError)
	Accent = lipgloss.NewStyle().Bold(true).Foreground(ColorAccent)
	Title = lipgloss.NewStyle().Bold(true)
	Selected = lipgloss.NewStyle().Reverse(true)
	Visual = lipgloss.NewStyle().Background(c["visual_bg"]).Foreground(c["visual_fg"])
	SelectedDim = lipgloss.NewStyle().Underline(true)
	Mode = lipgloss.NewStyle().Bold(true).Reverse(true)
	Null = lipgloss.NewStyle().Foreground(ColorBorder).Italic(true)
	Changed = lipgloss.NewStyle().Bold(true).Foreground(c["changed"])
	Inserted = lipgloss.NewStyle().Foreground(c["inserted"])
	Deleted = lipgloss.NewStyle().Foreground(ColorError).Strikethrough(true)
	Header = lipgloss.NewStyle().Bold(true)
	ActiveTab = lipgloss.NewStyle().Bold(true).Foreground(ColorAccent)

	syntax = map[highlight.Class]lipgloss.Style{
		highlight.Keyword:  lipgloss.NewStyle().Bold(true).Foreground(ColorFocus),
		highlight.Builtin:  lipgloss.NewStyle().Foreground(c["builtin"]),
		highlight.String:   lipgloss.NewStyle().Foreground(c["string"]),
		highlight.Number:   lipgloss.NewStyle().Foreground(c["number"]),
		highlight.Comment:  lipgloss.NewStyle().Italic(true).Foreground(ColorBorder),
		highlight.Operator: lipgloss.NewStyle().Foreground(c["operator"]),
	}
	kindTags = map[string]lipgloss.Style{
		"table":    lipgloss.NewStyle().Foreground(ColorAccent),
		"view":     lipgloss.NewStyle().Foreground(c["view"]),
		"column":   lipgloss.NewStyle().Foreground(c["changed"]),
		"routine":  lipgloss.NewStyle().Foreground(c["inserted"]),
		"schema":   lipgloss.NewStyle().Foreground(ColorFocus),
		"database": lipgloss.NewStyle().Foreground(ColorFocus).Bold(true),
	}
}
```

注意：`lipgloss.Color` 在 lipgloss v2 返回 `color.Color`；若 `ColorBorder` 原类型不是 `color.Color` 导致编译错误，按编译器给出的类型调整声明（`go doc charm.land/lipgloss/v2 Color` 核对）。`Frame` 里 `lipgloss.NewStyle().Foreground(ColorBorder)` 每次渲染时读取变量，无需改动。

```go
package keymap

import (
	"errors"
	"fmt"
	"strings"
	"unicode/utf8"
)

// ParseKeys reads a key sequence written the way Display shows it: "gg",
// "<leader>s", "<ctrl+d>", "f<". A "<" that does not start a "<name>" is
// the key "<" itself.
func ParseKeys(s string) ([]string, error) {
	if s == "" {
		return nil, errors.New("empty key sequence")
	}
	var out []string
	for i := 0; i < len(s); {
		if s[i] == '<' && i+1 < len(s) && s[i+1] >= 'a' && s[i+1] <= 'z' {
			end := strings.IndexByte(s[i+1:], '>')
			if end < 0 || !isKeyName(s[i+1:i+1+end]) {
				return nil, fmt.Errorf("unterminated or malformed <name> in %q", s)
			}
			name := s[i+1 : i+1+end]
			if name == "leader" {
				name = LeaderToken
			}
			out = append(out, name)
			i += end + 2
			continue
		}
		r, size := utf8.DecodeRuneInString(s[i:])
		out = append(out, string(r))
		i += size
	}
	return out, nil
}

// isKeyName accepts Bubble Tea key names: "ctrl+d", "shift+tab", "f12".
func isKeyName(n string) bool {
	if len(n) < 2 || strings.HasSuffix(n, "+") {
		return false
	}
	for _, r := range n {
		if !(r >= 'a' && r <= 'z' || r >= '0' && r <= '9' || r == '+' || r == '-') {
			return false
		}
	}
	return true
}

// parseLeader accepts one key: "," or "space" or "<space>"; "" is space.
func parseLeader(s string) (string, error) {
	if s == "" {
		return "space", nil
	}
	if utf8.RuneCountInString(s) == 1 {
		return s, nil
	}
	name := strings.TrimSuffix(strings.TrimPrefix(s, "<"), ">")
	if isKeyName(name) && name != "leader" {
		return name, nil
	}
	return "", fmt.Errorf("leader %q must be one key, like \",\" or \"space\"", s)
}
```

```go
package keymap

import (
	"fmt"
	"maps"
	"slices"
)

// Contexts lists the tables keymap.toml may contain.
func Contexts() []Context { return []Context{Global, Tree, Grid, Structure, Console, Results} }

// KnownActions maps every bindable action to its description.
func KnownActions() map[Action]string {
	out := map[Action]string{Quit: "Quit"}
	for _, b := range DefaultBindings() {
		if out[b.Action] == "" {
			out[b.Action] = b.Desc
		}
	}
	return out
}

// Custom is the default keymap with another leader and keymap.toml's
// overrides: per context, key sequence -> action, "" unbinds the keys.
func Custom(leader string, overrides map[Context]map[string]string) (*Keymap, error) {
	leader, err := parseLeader(leader)
	if err != nil {
		return nil, err
	}
	known := KnownActions()
	expand := func(keys []string) []string {
		out := slices.Clone(keys)
		for i, k := range out {
			if k == LeaderToken {
				out[i] = leader
			}
		}
		return out
	}
	bindings := DefaultBindings()
	for _, ctx := range slices.Sorted(maps.Keys(overrides)) {
		if !slices.Contains(Contexts(), ctx) {
			return nil, fmt.Errorf("[%s]: unknown context (want one of global, tree, grid, structure, console, results)", ctx)
		}
		for _, ks := range slices.Sorted(maps.Keys(overrides[ctx])) {
			keys, err := ParseKeys(ks)
			if err != nil {
				return nil, fmt.Errorf("[%s] %q: %w", ctx, ks, err)
			}
			action := Action(overrides[ctx][ks])
			if action != "" && known[action] == "" {
				return nil, fmt.Errorf("[%s] %q: unknown action %q", ctx, ks, action)
			}
			want := expand(keys)
			bindings = slices.DeleteFunc(bindings, func(b Binding) bool {
				return b.Context == ctx && slices.Equal(expand(b.Keys), want)
			})
			if action != "" {
				bindings = append(bindings, Binding{ctx, keys, action, known[action]})
			}
		}
	}
	return New(leader, bindings)
}
```

```go
// KeymapFile is keymap.toml: an optional leader and, per context, key
// sequence -> action ID ("" unbinds). ui/keymap validates the contents.
type KeymapFile struct {
	Leader    string            `toml:"leader"`

	Tree      map[string]string `toml:"tree"`
	Grid      map[string]string `toml:"grid"`
	Structure map[string]string `toml:"structure"`
	Console   map[string]string `toml:"console"`
	Results   map[string]string `toml:"results"`
}

// Overrides returns the tables present in the file, keyed by context name.
func (f KeymapFile) Overrides() map[string]map[string]string {
	out := map[string]map[string]string{}
	for name, m := range map[string]map[string]string{
		"global": f.Global, "tree": f.Tree, "grid": f.Grid,
		"structure": f.Structure, "console": f.Console, "results": f.Results,
	} {
		if m != nil {
			out[name] = m
		}
	}
	return out
}
```

```go
package ui

import (
	"strings"

	"github.com/shepherd-yun/sqlvim/internal/ui/keymap"
```

```go
// keyHint is "<keys> label" for the keys that trigger a in ctx, or "" when
// keymap.toml left a unbound there.
func keyHint(k *keymap.Keymap, ctx keymap.Context, a keymap.Action, label string) string {
	keys := k.KeysFor(ctx, a)
	if keys == "" {
		return ""
	}
	return keys + " " + label
}

// joinHints joins the non-empty hints with " · ".
func joinHints(parts ...string) string {
	var out []string
	for _, p := range parts {
		if p != "" {
			out = append(out, p)
		}
	}
	return strings.Join(out, " · ")
}
```
